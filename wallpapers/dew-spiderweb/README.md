# 晨露蛛网 · 逆光修补

逆光清晨，一张挂在草茎之间的圆网。丝细到 0.5–1px，几乎看不见；是露珠把它显影——两百多颗水珠沿着对数螺旋排队，每一颗都有自己的高光、暗边和一点环境倒影。虫撞上来，整张网抖出一圈从撞击点向外跑的波，露珠被弹落，破洞张开；蜘蛛从网心沿辐丝爬过去，把捕虫丝一圈一圈补回来。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「晨露蛛网」并预览、应用。`preview.png` 是实际渲染截图。

- 轻点画面：一只虫撞上网。撞击点传出一圈高频振动（弹簧波），附近的露珠被弹落，蛛丝松弛后重新绷紧，一个破洞随之张开。
- 按住拖动：改变风向。整张网与两根草茎顺着拖动方向偏转；松手后约 60 秒内衰减回自动的晨风。
- 右下角「蛛网设置」：暂停、全屏、自动破损、焦点呼吸、催一次补丝、换一张网。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 13 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 系统启用「减少动态效果」时默认静止，可手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，自动破损、蜘蛛巡网补丝、露珠的三分钟生长循环和每 20–40 秒一阵的晨风照常运行，画面依然完整。

## 蛛网规则

- **辐丝**：24 根，半径从 0.13R 到 R，间隔 15°，带 ±2° 的种子化抖动与 3 个亮度等级；每根按 4 段折线随振动节点变形，总计 96 段。
- **捕虫丝**：一条 15 圈的对数螺旋（`r = R · 0.15^(u)`，按弧长重采样成 780 个点），用二次曲线平滑；相邻两圈在外缘约 43px、在内缘约 6px，像真网一样外疏内密。整体再加三层缓慢的半径起伏（±1.8% / ±1.0% / ±0.5%）、每圈间距 ±4.5% 的不均匀，以及相邻辐丝之间 0.65%R 的下垂。
- **吊丝**：6 根，从两根草茎连到外圈锚点，透明度只有蛛丝的六成，永远不抢戏。
- **丝段总数**：780（捕虫丝）+ 96（辐丝）+ 12（吊丝）= 888 段，硬上限 900。
- **逆光显影**：每段丝根据它背后的背景亮度决定明暗——压暗背景上的丝是亮丝（`#fcfae6`），亮天空前的丝是暗丝（`#1a2212`）。背景亮度来自一张 56×32 的烘焙亮度图，因此网的上缘会自然“消失”在亮处，下缘在下垂的阴影里发亮。
- **露尘**：丝上还有一层虚线高光（1.0px 实、3.4px 空），让每一根丝读起来都像串着细小的露珠；这是丝线的纹理，不占露珠预算。

## 露珠规则

- 214 颗：196 颗落在捕虫丝上（外圈更密、更大），12 颗挂在辐丝上，6 颗停在草茎上。
- 每颗有自己的周期（168–204 秒）：先长大到满径，滑落 8–16px 后消失，再从最小重新凝结。周期各不相同，所以整张网不会一起闪。
- 尺寸分三档：14% 是 13–20px 的主珠，38% 是 5–10px，其余是 2–5px 的碎珠；主珠底下多画一层加色辉光。
- 珠体是预渲染 sprite：亮心、暗下缘、左下暗边、右上硬高光、一点环境反光。两种色温（冷白 / 暖金）轮换。
- 撞击时，撞击点 0.55R 内的珠子里约四成会被弹开：按抛物线飞出去，2.2 秒内淡出，然后再按各自的周期重新凝结。
- 破洞里的珠子随丝一起消失；补好的丝重新记录露珠，等下一轮生长。

## 修补规则

- **周期**：480–720 秒（8–12 分钟）。每个周期在第 22–126 秒之间随机撞一次网，位置、破洞大小都由种子决定。
- **破洞**：半径方向的半宽 8.5–14.5%R，角向半角 0.38–0.68 rad，横跨 3–6 圈捕虫丝；破损边缘有 4 根松松垂下的断丝。
- **蜘蛛**：先在网心附近巡网（268 秒一个来回），撞击后 5–12 秒醒来，沿破洞所在的辐丝向外爬 26–48 秒（合计 31–60 秒抵达），补丝 55–95 秒，再花 42 秒爬回网心。补丝时从破洞内缘向外推进，补过的丝在 78 秒内带一点暖白的新丝光。
- **排队**：同一时刻只修一个洞；如果连续撞击，后来的破洞会等蜘蛛把手上的活干完。
- **不重置**：时间线是种子与时间的函数，没有整体重播；同一个种子每次都会在同一分钟破同一个位置。

## 风与镜头

- **晨风**：基础风向缓慢摆动（431 秒一个来回），强度 0.30–1.50；每 20–40 秒一阵 5–9 秒的阵风，把网吹得更高频地抖。
- **节点振动**：96 个节点（24 个外圈锚点 + 3 圈关键节点：0.30R / 0.55R / 0.80R）承载所有形变；捕虫丝的每个采样点从这四个环带双线性插值得到位移。撞击波是闭式的阻尼行波（波速 ≈ R/0.135，27 rad/s，1.45 秒衰减），所以任意时刻都能直接算出这一帧。
- **机位**：微距平视、正交，焦点落在网心；不推拉。横向漂移是 95 秒 / 137 秒两个正弦的合成，峰值约 0.07mm/s（按 1920 宽、网径 96mm 计），不超过条目要求的 0.2mm/s。
- **焦点呼吸**：每 120 秒一次 rack focus，峰值只持续十几秒：网的清晰笔画变淡、0.42× 辉光变宽，同时前景那颗大露珠从柔版换成锐版——焦点从网心挪到前景，再落回网心。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数和设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 蛛网种子；固定后复现辐丝角度、露珠分布、破损位置与时间 |
| `t=60` | 起始时间，单位秒；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=8` | 播放态启动前额外回溯多少秒（0–30）；静止态忽略 |
| `damage=0` | 关闭自动破损，只保留手动点击 |
| `focus=0` | 关闭焦点呼吸，网心始终合焦 |

静态海报：`wallpaper.html?still=1&t=60&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

固定种子的纯壁纸：`wallpaper.html?seed=20261110&hud=0&damage=0`

## 运行预算

- 动画目标 30 FPS（按 26ms 阈值渲染，30Hz 屏不会隔帧丢帧）；软件离屏实测：1920×1080 与 390×844 为 30 FPS（不加阈值时渲染能力约 41 / 60 FPS），3440×1440 约 28 FPS，3840×2160 约 24 FPS。GPU 合成或更小的窗口会更快；4K 是唯一低于 30 FPS 的尺寸，已在设计文档里注明。
- 每张画布最多约 260 万渲染像素，`devicePixelRatio` 上限 1.5，并按面积回退。
- 丝 888 段（上限 900）；露珠 214（上限 220）；振动节点 96（上限 120）；bokeh sprite 12 张轮换，20 块里 15 块烘焙进背景、5 块每帧漂移。
- 背景、bokeh、前景虚化、暗角、颗粒与暖色镜头薄雾在尺寸变化时烘焙；0.42× 柔光缓冲只画蛛丝；每帧只更新节点、蛛丝采样、露珠、风与镜头。
- 无累积型全屏缓冲，也没有逐帧全画布回读，连续运行不会越跑越亮，也不会越来越慢。
- 页面隐藏时 `cancelAnimationFrame`；恢复时重置时间戳；暂停或减少动态效果时仍响应缩放并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-dew-spiderweb.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-dew-spiderweb.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查丝段 / 露珠 / 节点数量上限、坐标有限、像素预算、阵风节奏、破损事件、蜘蛛位置、确定性复现、点击振动与衰减、修补闭环、自动破损开关、风向覆盖与回落、焦点呼吸、暂停、隐藏页面、缩放与 URL 开关。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度与露珠高光、动画推进、指针撞击、补丝闭环、拖动风向、暂停与缩放、HUD 与面板、减少动态效果、无网络请求、无控制台错误，以及 `scanWallpapers` 识别且无问题项。截图写入系统临时目录 `lumen-dew-spiderweb-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动破损与蜘蛛巡网是必要的保底。

设计文档见 [`docs/design/dew-spiderweb.md`](../../docs/design/dew-spiderweb.md)。
