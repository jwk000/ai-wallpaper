# 8 幅独立动态壁纸

八幅独立的程序艺术动态壁纸。所有图像由 Canvas 2D 实时绘制，文件本身无需联网、素材库或额外运行时。

每幅作品有独立的文件夹、HTML、预览图与壁纸库条目，可单独播放、应用和分发。每个 HTML 只绘制对应的一幅作品。

| 山河呼吸 | [打开](../wallpapers/breathing-shanshui/wallpaper.html) | 七层山脊缓慢呼吸、河道游移、松林与纸纹；每 165 秒有一次雁群穿行 |

## 播放与设置

在仓库根目录运行 `npm start`，在本机壁纸库搜索各自的作品名，即可预览或应用。也可以直接用浏览器打开相应 HTML。每个目录自带 `meta.json`、`preview.png` 和说明。

- **H**：打开 / 关闭设置。右下角设置入口在鼠标经过时显现。
- **空格**：暂停 / 继续；**E**：触发特殊事件；**R**：变换构图。
- 设置可选择 0.5 / 1 / 2 倍流速和精细 / 节能画质。
- 暂停时触发特殊事件会展示其中段，播放时触发会从头开始。
- 系统减少动态效果默认显示静帧，可手动继续。页面隐藏时停止绘制；暂停或静帧状态下调整窗口仍会重绘。
- 月球时钟在暂停时冻结读数，继续后同步系统时间。

琥珀只累计活跃播放的真实时间。调速不改变沉积速度，暂停、隐藏和关闭期间不计时。累计秒数及最近 240 层保存在当前浏览器或宿主资料中的 localStorage；重新构图不会清空。存储被禁用或容量不足时仍可播放，设置中会显示保存不可用。重新定位文件或更换宿主资料可能形成独立记录。

## 源码与生成

`scripts/dream-atlas/runtime.js` 管理画布分辨率、动画调度、交互与可访问设置；同目录八个同名 JS 分别实现艺术场景。构建时把它们内联成每个作品目录唯一的一份 HTML，因此分发时无需携带 scripts。

```powershell
npm run build:dream-atlas
npm run verify:dream-atlas
# 更新实机预览、在线馆图片与清单、文档中的合集
npm run verify:dream-atlas -- --capture
npm run build:site
```

构建会更新这八个目录的 HTML、元数据和 README，不修改其他作品。修改作品时应编辑上述 authoring 源码后构建。

可复现画面参数示例：`?seed=42&t=30&still=1&hud=0&quality=low`。`t` 为动画秒数；`still=0` 明确启用动画。琥珀的历史和月球的本地时钟仍来自各自数据，不由 `t` 覆盖。

## 验证范围

验证脚本使用独立的临时 Electron 资料，避免测试污染真实琥珀记录。覆盖真实离线 file 页面、渲染报错与网络请求监测、动画像素变化、特殊事件、重新构图、流速画质控件、暂停恢复、隐藏页调度、减少动态效果及其实时变更。

窗口覆盖 1920×1080、390×844、3440×1440、3840×2160。以多个时间点（最远至 10,000,000 动画秒）检查绘制坐标是否有限；这是时间跳转检查，不代表连续运行相同时长。琥珀另检验累积、刷新恢复、记录上限、无效记录及保存失败。

每帧按经过时间推进，目标 30 FPS；画布像素预算为精细 260 万、节能 120 万。高分辨率屏幕会相应降低内部渲染分辨率。性能报告中的数值为测试机器上 Canvas 绘制调用耗时，不等同于所有设备的完整显示帧耗时。

在线馆清单与素材已本地准备好，`build:site` 会生成八幅对应的 `live.html`；发布仍通过项目已有部署流程进行。
