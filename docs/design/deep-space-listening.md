# 深空监听站 — 设计文档

> 对应 `TODO.md` 中「深空监听站」条目。本文把相机、美术、层次、构图、色彩、交互、循环展开成可实现、可验收的约束，再据此实现 `wallpapers/deep-space-listening/`。
>
> 状态：实现完成 · 2026-11-10

---

## 1. 一句话概念

荒原尽头的一座射电监听站：抛物面天线朝着天顶缓慢扫过，星轨绕着天极转；每隔几分钟，某一段噪声忽然有了形状，天线转过去，前景接收机的波形亮起来。

它首先是一张能一直看下去的夜景照片：低机位、广角、几乎全黑的地平线，银河从左上的空天斜下来，主天线在右三分之一处形成唯一的复杂剪影。其次才是一台会扫描、会捕获、会归位的机器。

### 设计原则

1. **先是一张夜景，才是一台设备。** 任意时刻截屏都要成立：地平线、银河、主天线、站房与钠灯的位置固定，HUD 不压主体。
2. **运动是机械的，不是特效的。** 天线方位/俯仰有加减速，星轨来自天球转动，波形来自真实的状态机；没有凭空的光爆、粒子雨或镜头抖动。
3. **慢。** 8 分钟一次扫描、2–5 分钟一次信号、10 分钟一次曝光；不做秒级闪烁，不做整屏重置。
4. **暗。** 画面 85% 以上接近黑；高光只允许出现在星点、钠灯和波形三处。
5. **小体量、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

- **镜头**：约 24mm 广角感；地平线轻微桶形不模拟，只用低机位与近大远小表现空间。

## 3. 天空模型

### 3.1 投影

- 天极固定在 `(0.66w, 0.15h)`，用极坐标把星表投影到屏幕上：

```
skyUnit = 0.64h
screen = pole + Rot(θ) · (x0, y0) · skyUnit + cameraOffset
```

- `(x0, y0)` 是种子化星表在「天极坐标」中的位置；`θ = t · 360° / 4h`，即 4 小时转一圈（`0.025°/s`）。这个速度比真实星空快 6 倍，是为了在 10 分钟曝光里得到约 15° 的可读星轨，而不是一条 2.5° 的短线。
- 视野约 74°（24mm 全画幅水平视角），相机偏航 `yaw = ±0.8° · sin(2πt/1800)`，俯仰呼吸 `pitch = ±0.12° · sin(2πt/600)`；只作用于天空、银河与星轨，前景保持固定，避免画面边缘露出空白。
- 星点按 `y < horizon` 裁切；靠近地平线的星点透明度乘 0.55，模拟大气消光。

### 3.2 星表

- 2000 颗种子化星点：约 1400 颗均匀分布，600 颗聚在银河带附近。
- 亮度按幂律分布，95% 为 0.6–1.4px 的暗星，约 62 颗为 1.8–2.4px 的亮星；亮星叠加极轻的闪烁（`sin` 双频，周期 7–19s），暗星不闪。
- 颜色只在 `#b9d4ff` → `#e4efff` 之间取值，不出现暖色星。
- 银河用低分辨率离屏画布烘焙：多层宽窄不同的斜向渐变带 + 暗尘带 + 1200 颗细小星点，按 `skyUnit` 放大后随天球旋转；因为本身是弥散结构，低分辨率不会露馅。细星另外用解析星点补在最上层。

### 3.3 星轨

- 取亮度最高、且当前可见的 280 颗星画星轨。
- 每条星轨是 `[t-600s, t]` 曝光窗内的一段圆弧，分成 12 段，尾端透明度 0.015 递增到头端 0.32；线宽 0.85–1.3px，颜色 `#b9d4ff`。
- 星轨绘制在 `0.5 × dpr`、上限 `960×540` 的半分辨率缓冲画布上，每 0.25s 重绘一次，再整体合成到主画布；星点本身仍是全分辨率的点。
- 曝光窗始终是滚动的 600s，不做整屏清空：`EXPOSURE` 读数从 `00:00` 走到 `10:00` 后归零，但画面中的星轨是连续滚动的，不会出现跳变。
- **与 TODO 的差异**：条目写「最老的点每帧按 0.4% 衰减」。逐帧累积在 8 位画布上会因 alpha 量化在几分钟内过曝，0.4%/帧也会让星轨只剩几秒。实现改为「600s 解析曝光窗 + 4Hz 重绘到半分辨率缓冲」，视觉上等价于长曝光，且完全可复现。这里记录为实现差异。

## 4. 主天线

### 4.1 指向

- 天线由方位角 `az`（屏幕左负右正，−90°…+90°）与俯仰角 `el`（0° 地平，90° 天顶）描述。
- 指向单位向量投影到屏幕：

```
n = normalize(cos(el)·sin(az), −sin(el))
u = perpendicular(n)              // 抛物面长轴
v = n                             // 短轴
```

- 抛物面中心 `C`，长半径 `R`，短半径 `0.42R–0.66R`（随俯仰变化）；顶点 `V = C − n·0.34R`，馈源 `F = C + n·1.02R`。
- 边缘点 `P(θ) = C + u·R·cosθ + v·R·squash·sinθ`，24 根径向肋连接 `V` 与 `P(θ)`，3 圈同心环连接肋的中点。骨架总段数上限 160。
- 指向变化使用临界阻尼平滑，最大角速度 26°/s，转向时带 0.3s 的轻微过冲回正。

### 4.2 绘制顺序

1. 基座、俯仰叉臂、配重、后部拉索；
2. 抛物面内腔（近黑渐变 + 极淡的冷色反射）；
3. 径向肋、同心环、边缘圆环；
4. 三根馈源支撑杆与馈源本体；
5. 边缘光：左上冷色轮廓光、右下极淡的钠灯暖边；
6. 基座检修梯、栏杆、电缆。

### 4.3 自动扫描

- 8 分钟一个周期：

```
az = −20° + 55°·sin(2πt/480)
el = 38° + 28°·(0.5 − 0.5·cos(2πt/480 + 0.8))
```

- 方位在 `−75°…+35°` 之间往返，俯仰在 `38°…66°` 之间呼吸；t=0 时指向 `(−20°, 42°)`，抛物面开口朝左上，进入构图。
- 不做 360° 连续旋转：真实射电望远镜的电缆与限位不允许无限转，画面里也不需要天线背对观众的时刻。

## 5. 信号与波形

### 5.1 事件表

- 信号事件由 `seed` 决定，间隔 `120–300s`，每次持续 24s：
  - `0–6s` 转向（CAPTURE / 转向）；
  - `6–18s` 解码（DECODE / 解码），波形最亮，SNR 最高；
  - `18–24s` 归位并淡出（RETURN / 归位），波形 6s 内衰减。
- 方位来源偏向天线工作天区（`az −70°…−10°`，`el 45°…78°`），让多数捕获把抛物面转向左上的银河；约四分之一的事件来自右侧，避免机械重复。
- 事件表在初始化时按 `seed` 顺序生成，与运行时长无关；任意 `t` 可以直接解析到同一个事件。

### 5.2 波形

- 前景接收机内是一块约 4:1 的冷青屏幕，基线噪声 2px；解码时叠加 3 个不同频率的正弦与种子化脉冲，振幅在 1.5s 内升起、结束时 6s 内落下。
- 波形只画 1px 折线 + 6px 的 `shadowBlur`，亮度不超过钠灯；屏幕玻璃有极淡的扫描线与反光。
- 馈源顶端有一枚数像素的冷青接收指示，捕获时呼吸，归位后熄灭。
- HUD 同步显示 `SIGNAL −72.4 dB` 与状态；这是同一状态的文字回声，不是第二套模拟。

### 5.3 锁定与手动

- 拖动：水平拖动改变方位（`0.18°/px`），垂直拖动改变俯仰（`0.14°/px`），松手后保持 2.5s，再用 6s 回到自动扫描。
- 「锁定 30s」：冻结当前指向，期间忽略自动扫描与信号转向，按钮变成倒计时；再按一次提前解除。
- 键盘 `←/→` 每次微调方位 2°，`↑/↓` 微调俯仰 1.5°；微调同样进入 2.5s 手动保持。
- 桌面宿主收不到指针时，自动扫描与自动信号照常运行；所有交互都有自动对应行为。

## 6. 循环与时间

| 周期 | 内容 |
| --- | --- |
| 8 min | 自动扫描一个完整往返 |
| 2–5 min | 一次信号捕获 |
| 24 s | 一次捕获的转向 / 解码 / 归位 |
| 10 min | 星轨曝光窗滚动一轮 |
| 30 min | 相机偏航 ±0.8° 的极缓往返 |
| 10 min | 相机俯仰 ±0.12° 呼吸 |
| 4 h | 天球转一圈 |

- 不做整体重置：星轨、天线指向、信号表都连续；`EXPOSURE` 归零只是读数循环。
- 页面隐藏时停止调度；恢复时重置时间戳，`t` 继续连续，不跳帧。
- 减少动态效果时默认停在 `t` 对应的静止帧，设置面板与浮动按钮提供手动播放。

## 7. 渲染与性能

### 7.1 缓存

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 天顶 / 地平辉光 | `skyCanvas`（全分辨率） | 尺寸变化时重建 |
| 银河 / 暗尘 / 细星 | `mwCanvas`（1024×1024，随天球旋转） | 一次生成 |
| 星轨 | `trailCanvas`（0.5×，≤960×540） | 每 0.25s 重绘 |
| 远山 / 地面 / 碎石 | `terrainCanvas`（全分辨率） | 尺寸变化时重建 |
| 站房 / 栏杆 / 草丛 / 离焦叶 / 暗角 / 颗粒 | `fgCanvas`（全分辨率） | 尺寸变化时重建 |
| 主天线 | 每帧路径 | 约 120 段 |
| 钠灯光晕 / 波形 | 每帧少量渐变与折线 | — |

### 7.2 预算

- 目标 30 FPS；`dt` 上限 0.1s；静止时不调度 RAF。
- 主画布渲染像素 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退（4K 时约 0.56）。
- 星点 2000、星轨 280×12 段、银河细星 1200（烘焙）、碎石 420、草 90；全部数量固定，不随时间增长。
- 每帧绘制调用约：3 次 `drawImage`（天空、地形、前景）+ 1 次星轨合成 + 2000 个星点（按亮度分 5 批）+ 1 条银河 `drawImage` + 天线约 120 段 + 2 个渐变 + 1 条波形。
- 页面隐藏时 `cancelAnimationFrame`，恢复时重置时间戳；`prefers-reduced-motion` 默认静止。
- 所有随机数来自种子化 PRNG；星点、银河、山脊、碎石、草、信号时刻都由 `seed` 决定。

### 7.3 可复现

- `t` 是唯一时间源；`seed` 是唯一随机源。
- 同一 `?still=1&seed=…&t=…` 两次加载的像素哈希必须一致。
- 静止帧的星轨在初始化时按曝光窗解析绘制，不依赖「先跑多少秒」。

## 8. 交互与可访问性

| 操作 | 行为 |
| --- | --- |
| 指针拖动 | 手动调整方位 / 俯仰，松手 2.5s 后回到自动扫描 |
| `←` / `→` | 方位 −2° / +2° |
| `↑` / `↓` | 俯仰 +1.5° / −1.5° |
| `Space` | 暂停 / 继续 |
| `H` | 隐藏 / 显示 HUD |
| `L` | 锁定当前指向 30s / 解除 |

- 减少动态效果时 HUD 保持可见、默认静止，并提供「播放」按钮。
- 画面文字只承担标题与读数，不承载唯一信息；状态同时由天线指向、波形与 HUD 表达。

## 9. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 星表、山脊、信号表的种子 |
| `t=95` | 起始时间（秒） |
| `signal=0` | 关闭自动信号；`signal=1` 默认开启 |
| `scan=0` | 关闭自动扫描（天线保持当前位置） |
| `az=-38` / `el=46` | 固定初始指向（仍受自动扫描与信号影响，除非 `scan=0`） |
| `capture=1` | 在 `t` 处强制进入解码态，用于海报与验证 |
| `detail=0.6` | 降低碎石与草的密度（0.5–1） |
| `warm=600` | 星轨曝光窗长度，默认 600s，范围 120–900 |

静态海报：`wallpaper.html?still=1&seed=20261110&t=95&capture=1&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 11. 实现结构

```text
wallpapers/deep-space-listening/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 天空/天线/信号模型）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、天空模型、交互、URL 参数、验证说明

docs/design/deep-space-listening.md   本设计文档
scripts/verify-listening.cjs          Node 模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、工具、布局与构图；
2. 星表、银河、山脊、碎石、草的种子化生成；
3. 静态层烘焙（天空、银河、地形、站房、前景、暗角、颗粒）；
4. 天空投影与星轨曝光窗；
5. 天线几何、指向平滑、自动扫描；
6. 信号状态机、波形、钠灯；
7. 每帧合成、HUD 更新、输入、主循环；
8. `window.__lumenListening` 调试入口。

运行时暴露调试入口 `window.__lumenListening`（快照、推进、渲染、拖拽、锁定、重新播种、审计），供 `scripts/verify-listening.cjs` 使用；不参与视觉，不影响普通播放。

## 12. 验证计划

1. **Node 模拟**：`node scripts/verify-listening.cjs`
   - 四种尺寸各模拟 10 分钟，检查坐标有限、星数 / 段数 / 信号事件在上限内、曝光窗滚动、指向平滑、暂停与隐藏。
   - 检查确定性、信号间隔、`signal=0`、拖动 / 键盘 / 锁定、缩放、减少动态效果与 URL 开关。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏 / 4K 截图，检查非空、尺寸、亮度分布、无控制台错误与网络请求。
   - 验证动画推进、暂停与缩放、拖动、锁定、键盘、HUD、信号事件、减少动态效果、种子复现。
   - `--write-preview` 时输出 `preview.png`，其余截图写入临时目录供人工复核。
3. **视觉复核**：逐张查看四种尺寸与捕获态，确认地平线、银河、天线开口、站房钠灯、波形与 HUD 的关系；必要时只调构图参数，不改模型。
