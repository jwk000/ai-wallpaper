# 不可能建筑 · 循环小镇

一张摊在米色纸面上的等距小镇模型。广场中央立着一座由奶油石、砖红与青灰组成的**彭罗斯三角**，它的三条臂在画面里首尾相接；三角脚下是一圈会自己往上走的阶梯，四个小小的人影绕着它一圈圈攀登。镇子的水渠从低处一级级爬向高处，两列电车沿着闭环街道绕行，每隔一会儿就有一栋建筑原地转身九十度，街巷与轨道被它轻轻挤开，又重新合拢。

所有画面都由 Canvas 2D 程序绘制，没有图片、视频、字体或网络依赖，也没有音频。

## 不可能的四条规则

1. **彭罗斯三角**：广场中央的主景按经典不可能三角的比例重绘，三条臂在二维里互相穿插；它站在砖石基座上，影子落向同一方向，只有连接处不成立。
2. **首尾相接的阶梯**：基座外圈是四段低矮阶梯，每段都朝同一个方向上升；它们在转角处被矮墙与铜栏杆遮住，四个攀登者绕行一圈后回到起点。阶梯中央的井里是深色的水面。
3. **往高处流的水**：西侧运河有一段四级水梯，水面一级比一级高；白色流线顺着水梯**向上**爬，在阶沿翻出小水花，最后没入运河桥洞。水梯上有一块黄铜小牌 `AQUA ADVERSA`。
4. **会转身的街区**：点击建筑，它会绕竖轴旋转 90°（0.6 秒，末端带一点回弹）；转到侧面时宽度压扁，再以新的长宽比重建轮廓。每次转身后，附近的路点会向外偏移，电车与行人沿新的路线滑过去。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「不可能建筑 · 循环小镇」并预览、应用。`preview.png` 是实际渲染截图（1920×1080，关闭 HUD）。

| 操作 | 行为 |
| --- | --- |
| 点击建筑 | 该建筑原地转身 90°，轨道与步行路线重排 |
| 拖动 | 平移模型台，限制在 ±1 格内 |
| 滚轮 | 缩放 0.8–1.2× |
| `Space` | 暂停 / 继续 |
| `H` | 隐藏 / 显示界面 |
| `F` | 进入 / 退出全屏 |
| 方向键 | 选中建筑（铜色虚线框） |
| `Enter` | 让选中的建筑转身 |
| `Esc` | 取消选择 |

右下角「镇上设置」可以暂停、全屏、复位视角，开关「建筑自动转身」。自动模式每 45–90 秒随机挑一栋非地标建筑转身；地标（钟塔、教堂、市场、天文台、市政厅、水磨）与车站只响应点击，不参与自动轮转。

系统启用「减少动态效果」时默认静止，可点击「继续」手动播放；`?still=0` 可以显式覆盖。

## 自动行为与循环

- 电车：2 列 × 2 节，90 秒一圈，在车站停 4 秒；两列相位差 45 秒。
- 行人：12 个，分两条环形步道走动；转身事件后部分行人换道。
- 阶梯攀登者：4 个，40 秒一圈；在转角被矮墙遮住，不出现瞬移。
- 水梯流线：6 秒一轮；喷泉 6 秒一轮；旗帜与鸽子由解析相位驱动，不累积粒子。
- 晨昏：10 分钟在清晨与黄昏之间往返，通过一层很薄的色温与窗光变化实现，不做硬切。
- 建筑自动转身：45–90 秒一次，种子固定时可复现。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数与设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` | 静止画面 |
| `still=0` | 显式播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 小镇种子；固定后建筑细节、窗光与转身序列可复现 |
| `t=113` | 初始时间，单位秒；默认 113，范围 0–86400 |
| `auto=0` | 关闭自动转身 |
| `zoom=1` | 初始缩放 0.8–1.2，仍可用滚轮调整 |

静态海报：`wallpaper.html?still=1&t=113&hud=0`。

纯壁纸：`wallpaper.html?hud=0`。

固定 4K 取景：在 3840×2160 窗口下打开 `wallpaper.html?still=1&t=113&hud=0`，页面会自动按 16:9 重新构图。

## 运行预算

- 动画目标为 30 FPS，实际帧率取决于设备与宿主。
- 单张主画布最多约 260 万渲染像素；DPR 上限 1.5，并按视口面积反算。
- 建筑精灵按「编号 + 朝向 + 缩放档」缓存；转身时只重烘一栋，静止时复用。
- 纸面、铺地、水渠、轨道枕木、建筑阴影烘焙到离屏画布；每帧只重绘轨道、水面、电车、行人、攀登者、喷泉与前景。
- 建筑 37 栋（含车站）+ 超宽屏 6 栋卫星屋；电车 4 节、行人 12、攀登者 4、喷泉粒子 100。
- 页面隐藏时取消 `requestAnimationFrame`；恢复后重置时钟，避免后台时间造成跳跃。暂停时仍响应尺寸变化与缩放。
- 任何累积效果都由当前相位解析计算，不保留历史；水梯、旗帜、鸽子不会越积越亮。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-impossible.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-impossible.cjs --write-preview
```

脚本会：

1. 在 1920×1080、390×844、3440×1440、3840×2160 四种尺寸下各模拟 10 分钟，检查建筑/电车/行人/粒子上限、坐标有限、路线闭合、水梯高度递增、转身状态机、晨昏相位与暂停/隐藏调度。
2. 用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸、动画推进、暂停与恢复、真实指针点击建筑、轨道改写、HUD、设置面板、自动转身开关、减少动态效果、窗口缩放、离线运行，以及壁纸库的元数据与预览识别。
3. `--write-preview` 额外把 1920×1080 的横屏截图写入 `preview.png`。

Electron 截图写入系统临时目录 `lumen-impossible-town-check/`。这些检查不等同于 Windows 原生 WebView2 桌面挂载测试。

## 实现说明

- 单文件 `wallpaper.html`，Canvas 2D；所有几何、排线、网点、屋檐与猫都是程序绘制。
- 彭罗斯三角的几何比例参考公开的 Penrose 三角示意图（Wikimedia Commons, `Penrose-dreieck.svg`），在本作中按纸面模型的配色重新绘制，不加载任何外部文件。
- 小镇基座、水渠与广场的构图刻意保持「建筑模型」的静止感：纸面网格不随镜头移动，只有模型台轻微摆动。
