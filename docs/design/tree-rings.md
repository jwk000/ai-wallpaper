## 1. 一句话概念

一段锯开的树干横截面占满画面。年轮从髓心一圈圈长出来：旱年窄、丰年宽，某几年带着火灾留下的黑疤；木射线像星芒射出，一道主裂纹从髓心斜向右下作引导线。侧光在一昼夜里极慢地换角度，光里的尘埃一直在翻。

它不是年轮示意图，也不是一张静态的木头贴图，而是一页**还在继续写的编年史**：每一次截面都从日期里派生，每一圈都能读出年份。

### 设计原则

1. **先是一张标本照，才是一个年轮生成器。** 任何时刻截屏都要成立：髓心、主裂纹、树皮、热斑四件事各就各位；暗部干净，木纹不糊成一团。
2. **明度分层，不靠颜色。** 木材只在 `#2a1a10`–`#c9a878` 之间走，暖褐、低饱和；年轮可读性完全交给明度、材质与侧光。
3. **慢，且不重置。** 6 小时一圈、24 小时一次推近、45 秒检查一次跨天；没有硬重置，截面到顶时用 2.6 秒交叉淡入换段。
4. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

- **横向 16:9**：髓心在 `(0.50w, 0.42h)`，年轮同心扩散；截面外半径取 `0.452 × w`，因此上下被画幅裁掉、左右各留约 5% 的工作台与黄铜标尺，形成「微距贴脸」的取景。主裂纹从髓心斜向右下，指向画面右下角。
- **竖向 390×844**：改为半圆裁切，髓心偏左 `(0.17w, 0.47h)`，外半径 `0.94 × w`。画面右侧是被放大的年轮弧线，树皮弧在上、下与右侧掠过；工作台与标尺只在右上 / 右下角露出。
- **超宽 3440×1440**：沿用横向构图，截面外半径 `0.452 × w`，左右各露出约 120px 的深色工作台与竖向黄铜标尺；构图重心仍在 `0.50w`，但年轮在左右两侧拉出更长的弧。
- **不裁切**：三种比例的半径、髓心位置、标尺方向分别计算，而不是把 16:9 画面拉伸或裁边。

| 用途 | 色值 | 说明 |
| --- | --- | --- |

| 早材 | `#a8794c` | 每圈内侧 55–70%，丰年更浅 |
| 晚材 | `#2a1a10` | 每圈外侧 25–40% 的深带 |
| 木射线 | `#c9a878` | 92–154 条，透明度 5–22% |
| 裂纹 | `#120c08` | 锥形暗楔，带一侧受光唇线 |
| 树皮 | `#211610` – `#5a4030` | 外圈 3–4%，带径向裂缝 |
| 工作台 | `#070504` – `#1d140e` | 只在画幅边缘出现 |
| 黄铜标尺 | `#c9a15b` | 虚焦，竖向（竖屏改为横向） |
| 强调色（meta） | `#a8743f` | 与 HUD、库内强调色一致 |

- **三种树种**：夏栎（英格兰 · 萨里，环孔材、导管粗、射线亮）、落叶松（大兴安岭 · 呼中，晚材致密、窄轮、偏红）、山毛榉（白神山地 · 青森，散孔材、射线宽而亮）。三者的早材/晚材/树皮/射线色板各不相同，换段时能看出「换了一棵树」。
- **光**：一盏偏左上的侧光。方位在 24 小时内按 `-2.30 + 0.55·sin(2π·day − 1.9)` 缓慢摆动，再叠加 300 秒、±0.09 弧度的呼吸。阴影侧用 `multiply` 压暗并偏冷（`#141113`），受光侧用 `soft-light` 加暖，再叠一条斜向高光（`lighter`，10% 处 12–20%）和一块灯下热斑（`screen`，34%），保证亮部真的到达高光值。
- **明度分布**：实测预览约 23% 暗部（`L < 0.16`）、75% 中间调、1.8% 高光，暖色像素约 90%。高光只出现在受光侧的纤维、孔口和树皮唇线上。

| 背景 | 深色工作台、灯下的暖光池、木纹、虚焦黄铜标尺、接触阴影、灰尘 | 尺寸变化时烘焙 |
| 中景 | 树干截面（树皮 + 年轮 + 孔 + 射线 + 裂纹 + 火灾疤 + 锯痕），占画面 85–90% | 年轮与树皮烘焙；最外 3 圈、射线、裂纹每帧 |

- 中景是唯一清晰层；背景全部虚焦、只留黄铜的一线反光；前景树皮压住左下约 12%，不遮挡髓心与主裂纹。
- 截面比画幅大：上下被裁掉，让年轮从画幅外「长进来」，而不是一个漂在背景上的圆盘。

## 3. 截面模型

### 3.1 坐标

- 以髓心为原点、当前外半径为单位长度：每圈年轮存 `cum[i]`（累计宽度）与归一化半径 `R_i = cum[i] / cum[count-1]`，屏幕半径再乘 `fitR`。
- 每圈有一个缓慢漂移的中心：`center_i = 髓心 + drift · fitR · (i/(count-1))^1.25`，`drift ∈ ±2.75%`，让年轮不完全同心。
- 轮廓弯曲 `wobble(a, i)` 由三个整片共享的低频波（2、3、7 次）加两个逐圈微扰（13、23 次）组成，低频项带 `0.55/0.42/0.28 · ln(1 + 0.33i)` 的径向相移，所以纹路平行而缓慢扭转；髓心旁再乘 `1 + 1.8/(i+1.5)`，让幼年轮更不规则。

### 3.2 气候与年轮宽度

```
wet_i = 0.40·a + 0.21·b + 0.39·hash1(i·12.9898 + seed·0.0173 + φ)
        a = (sin((i + φ·9.1)·0.412) + 1) / 2
        b = (sin(i·1.137 + φ·3.7 + 1.9) + 1) / 2
        若 sin(i·0.233 + φ·4.4) > 0.74：wet_i -= (epoch - 0.74)·0.95
juvenile_i = 1.42 - 0.58·(i/(cap-1))^0.72
width_i   = juvenile_i · (0.30 + 2.30·wet_i) · (0.84 + 0.32·hash1((i+1)·7.13 + seed·0.0029))
```

- `φ` 由种子决定；干旱段成簇出现，因此会看到「连续几年窄轮」的段落。
- 每圈宽度的视觉权重由晚材带与渐变决定：`lateStart = 0.68 − 0.10·dry + 0.06·jit`，晚材带占外圈约 30–40%。
- 约 20% 的年轮带「断轮」：在某一段 8–29° 的扇形里，晚材带被早材色轻轻盖住，像真实树轮在某一侧缺失。

### 3.3 材质细节

| 元素 | 数量 | 做法 |
| --- | --- | --- |
| 导管孔 | 4000 | 按年轮宽度加权撒点，82% 落在早材带；深褐椭圆 + 14% 的朝光亮点 |
| 木射线 | 92–154（≤160） | 髓心附近到树皮，5 段折线，受光侧更亮 |
| 射线斑 | 90 | 浅色短弧，随机落在年轮内 |
| 裂纹 | 3–6 | 主裂纹从髓心出发、锥度 0.30→2.8，干旱年加宽；软阴影 + 暗楔 + 受光唇 + 3 个短分支 |
| 火灾疤 | 0–2 | 平滑随机边界的焦楔，浅色愈合脊 + 34 粒炭屑 |
| 纤维 / 径向纹 | 1200 / 520 | 切向短弧与径向细线，透明度 1–5% |
| 锯痕 | 4 弧 + 3 直线 | 透明度 2–5%，只在暗部可见 |
| 尘埃 / 木屑 | 210 / 60 | 解析式漂移，周期 40–250 秒 |

### 3.4 烘焙与每帧

1. **烘焙**（载入、尺寸变化、每闭合一圈、换段时）：
   - 年轮渐变 → 一次 0.6px 的镜头柔化（整块盘）；
   - 再叠清晰的纤维、孔、射线斑、锯痕、火灾疤、边材、树皮、髓心；
   - 最后按半径做浅景深（`blur(4px)`，从 0.62R 起渐强到 1.02R）。
2. **每帧**：背景 blit → 木盘 blit → 最外 3 圈（径向渐变）→ 生长前沿与边材 → 射线 → 裂纹 → 光（3 次全屏 + 热斑）→ 尘埃 → 覆盖层（前景树皮、暗角、颗粒）→ 年份刻度。

- 年轮 240 圈硬上限、每圈 256 点；一段截面的 `cap = age0 + 46..103`，`age0 = 52..73`，所以实际 98–176 圈。
- 最外 3 圈和全部射线、裂纹是矢量重绘，因此生长前沿始终清晰；里面所有圈只在烘焙时画一次。

## 4. 生长与换段

- 当前年轮数 `grown = age0 + floor((t − epoch) / ringSeconds)`，`ringSeconds = pace × 3600`（默认 6 小时，可调 1–24）。
- 最外圈是「半圈」：`front = (cum[grown-2] + width·phase) / cum[grown-1]`，`phase = fract(...)`。它从早材浅色逐渐过渡到晚材深色；`front` 到树皮之间是半透明的浅色边材。
- 每闭合一圈：重新烘焙、镜头做 1.4% 的 1.1 秒回收，读数的树龄 +1。
- 到达 `cap`（或手动「换一段截面」、跨天）时：镜头拉远 4.5%、2.6 秒交叉淡入下一段截面，`sectionIndex + 1`，换树种与产地；新段从 `age0` 重新开始。
- 年轮不再增长时（`grow=0`），把 epoch 随时间前移，冻结在当前相位，光与尘埃继续。

## 5. 交互

| 操作 | 行为 |
| --- | --- |
| 指针移动 | 命中最近的年轮 → 极淡的年份圆环 + 13 条刻度 + 年份数字，3 秒后淡出 |
| `←` / `→` | 逐圈翻年，HUD 年份卡片同步；选中态 3.4 秒后淡出，`Esc` 清除 |
| 单击画面 | 导出 1920×1080 明信片 PNG（日期、seed、标题、强调色四行 + 色块） |
| `Space` | 暂停 / 继续；暂停时仍响应悬停、翻年与缩放 |
| `H` | 隐藏 / 显示 HUD；开场 14 秒后自动淡出 |
| `F` | 全屏 / 退出全屏 |
| 设置面板 | 暂停、全屏、自动生长、年轮刻度、换一段截面、导出明信片、生长节律 |

- 命中检测用屏幕坐标反推：`r = |p − 髓心| / (fitR · zoom)`，再按累计宽度二分找年轮；`r > 1.012` 视为树皮外。
- 桌面宿主收不到鼠标时，生长、日签、光线与尘埃照常运行；年份刻度只是加法。
- 单击导出不会暂停播放；导出走 `canvas.toDataURL` + `a[download]`，不发网络请求。

## 6. 循环与时间

- `6h`：一圈年轮闭合（`pace=1` 或 `24` 时可改）；镜头 1.4% 回收。
- `24h`：镜头 1.00 → 1.06 的极慢推近（余弦，午夜 1.00、正午 1.06、再回 1.00，不跳变）；光方位 ±0.55 弧度的摆动。
- `300s`：光线的细微呼吸。
- `92s` / `40–250s`：生长前沿的明暗脉动 / 尘埃的漂移周期。
- `2.6s`：换段交叉淡入；`14s`：HUD 自动淡出；`3s`：年份刻度淡出。
- `45s`：检查一次本地日期；跨天时换 seed 与年份标签，2.6 秒交叉淡入。
- 页面隐藏时取消调度；恢复时重置时间戳，时间本身连续。

## 7. 运行预算

- 目标 30 FPS；主循环两次渲染间隔不足 29ms 就跳过，模拟用真实秒数。
- 画布像素 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退（4K 下 0.56）。
- 年轮 ≤ 240（截面 ≤ 176）、每圈 256 点；孔 ≤ 4000；射线 ≤ 154；裂纹 ≤ 6；火灾疤 ≤ 2；尘埃 210；木屑 60。
- 每帧约 400 次绘制：1 背景、1 木盘、3 年轮渐变、约 130 射线、3–6 裂纹楔、2 边材弧、3 次全屏光、1 热斑、270 尘埃、1 覆盖层。
- 烘焙只在载入 / 尺寸变化 / 闭圈 / 换段时发生；每次约 13k 次绘制（年轮、孔、纤维、树皮、两次全盘模糊）。
- 不累积任何全屏缓冲：光、尘埃、生长前沿都是每帧重算，长时间运行不会越跑越亮。
- 页面隐藏时 `cancelAnimationFrame`；`prefers-reduced-motion` 默认静止。

## 8. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、翻年、清除选中、开关生长与刻度、换段、导出。
- 减少动态效果时默认静止；HUD 保持可见，`Space` 或面板可手动播放。
- 年份信息同时出现在画布刻度与 HUD 卡片里，不只依赖一种呈现。

## 9. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |

| `ticks=0` | 关闭悬停年份刻度 |

## 11. 实现差异与降级（务必阅读）

1. **24 小时推近用余弦，而不是线性 1.00 → 1.06 后归零。** 线性会在午夜从 1.06 跳回 1.00；余弦让午夜恰为 1.00、正午 1.06、再平滑回落，周期仍是 24 小时、幅度仍是 1.06，不产生硬切。
2. **光角不做 360° 旋转。** 规格说「光的角度缓慢移动」；为了让凌晨三点不会从地板打光，实现改为在左上 ±0.55 弧度内摆动的侧光（24 小时），再加 300 秒的细微呼吸。侧光的可读性与「标本摄影」都更好。
3. **「长满画面后镜头拉远」被拆成两级。** 截面从第一帧就占满画面（否则违反「相机：截面占满画面」），因此「拉远」落在两处：每闭合一圈的 1.4% 回收，以及换段时 4.5% 的拉远 + 2.6 秒交叉淡入。没有为了露出整个圆盘而把截面缩小到画面中央。
4. **生长在单次观看里几乎是静止的。** 6 小时一圈意味着 10 分钟内最外圈只走 2.8%。这是规格本身的时间尺度；观看时真正的主角运动是侧光、尘埃和生长前沿的脉动。想看到换段，可用面板「换一段截面」或等跨天；想快进用 `?pace=1`。
5. **材质是「程序化微距」，不是照片扫描。** 在 240 圈 × 256 点、单画布 260 万像素、30 FPS 的预算内，实现用径向渐变年轮、两次烘焙模糊（0.6px 柔化 + 4px 浅景深）、孔/纤维/射线/裂纹的分层，以及 multiply + soft-light + screen 的三段光照，尽力逼近木材微距的质感；它仍是一张画出来的标本照，而不是照片。降级的上限来自「每圈 256 点 + 年轮允许 240 圈」这条硬预算。
6. **年份标签与几何解耦。** 气候序列以 `(seed, 年轮序号)` 为自变量，默认 seed 由日期派生，因此同一 `seed` 与 `t` 在任何一天都渲染同一像素；`day` 只移动年份标签（`startYear = 日签年份 − age0 + 1`）。这样「同一 seed 与 t 确定性复现」与「气候由真实日期派生」两条要求同时成立。
7. **明信片固定 1920×1080。** 与 `preview.png` 同尺寸，四行档案信息 + 一枚强调色块；没有做多尺寸导出。

## 12. 实现结构

```text
wallpapers/tree-rings/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 年轮）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、年轮规则、URL 参数、运行预算、验证

docs/design/tree-rings.md   本设计文档
scripts/verify-tree-rings.cjs   模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、日期派生、工具函数；
2. 树种与标本生成：气候、宽度、射线、裂纹、火灾疤、孔；
3. 构图与几何：髓心、外半径、年轮轮廓、命中检测；
4. 背景 / 覆盖层 / 木盘烘焙（含柔化与浅景深）；
5. 每帧绘制：最外 3 圈、生长前沿、射线、裂纹、光、尘埃、年份刻度；
6. 生长、换段、跨天；
7. HUD、输入、主循环、验证钩子。

运行时暴露调试入口 `window.__lumenTree`（快照、审计、推进、快进、悬停、翻年、导出、换段、节律、开关、渲染），供 `scripts/verify-tree-rings.cjs` 使用；不参与视觉，不影响普通播放。

## 13. 验证计划

1. **Node 模拟**：`node scripts/verify-tree-rings.cjs`
   - 四种尺寸各 10 分钟，检查年轮/孔/射线/裂纹数量、每圈点数、坐标有限、像素预算、生长节律、自动生长开关、到顶换段、手动换段、一月龄时钟。
   - 确定性复现（同 seed/t 同快照）、`day` 只动年份标签、日签派生与跨天交叉淡入。
   - 悬停 3 秒淡出、左右翻年、明信片构图、暂停、隐藏、缩放、减少动态效果、URL 开关。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏 / 4K 截图，检查非空、尺寸正确、亮度分布、无控制台错误与网络请求。
   - 验证动画推进、悬停刻度与年轮卡片、翻年、点击导出 PNG、暂停、暂停时缩放、HUD 自动淡出、减少动态效果、种子复现、壁纸库识别。
   - `--write-preview` 时输出 `preview.png`，其余截图写入临时目录供人工复核。
3. **视觉复核**：逐张查看四种尺寸与悬停构图，确认髓心位置、主裂纹方向、树皮、工作台与标尺、热斑与暗部成立。
