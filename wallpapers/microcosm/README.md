# 一滴 · 浮生

一滴水里的微型生态。浅青色透射光下，藻细胞拖着鞭毛游动，纤毛虫摆动纤毛、寻找食物，变形虫形态的捕食者缓慢追逐。细胞膜、细胞核、胞质颗粒和食物泡均由 Canvas 2D 绘制。微生物形态、尺寸、时间尺度和食物链经过艺术化处理，不是定量生物学模型。

## 打开

直接用浏览器打开 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「一滴 · 浮生」并预览、应用。整个场景封装在一个 HTML 中，无外部字体、图片、脚本、网络或音频依赖。`preview.png` 为实际渲染截图。

## 生态细节

- 游动：转向带惯性，叠加缓慢水流；纤毛与鞭毛持续摆动，靠近捕食者时会逃离。
- 捕食：纤毛虫吃藻细胞，大型捕食者吃纤毛虫；吞食后可见食物泡逐渐移入体内、缩小消化。
- 分裂：能量充足时，细胞先伸长、收腰，再分成两个个体。
- 死亡：寿命耗尽或饥饿会死亡，膜逐渐裂成弧段，细胞颗粒随水流散开，18 秒内淡出。
- 持续循环：藻细胞获得能量，消费者通过捕食获得能量。种群较低时会缓慢补充个体，经过 6 秒淡入，避免长时间播放后空场。
- 焦平面：部分细胞保持清晰，其他细胞呈柔和失焦；焦点可手动调整。
- 所有个体都在同一片水域内运动。竖屏裁切观察区域，不会重新生成或拉伸微生物。

## 操作

- 右下角「观察设置」：时间流速（0.25–2 倍）、焦平面、透射光、暂停和全屏。
- 点击水面：制造轻柔水流，推动附近个体。
- `Space`：暂停 / 继续；`H`：隐藏 / 显示界面；`F`：全屏。
- 标题约 14 秒后淡出，设置按钮保持低亮度。
- 系统开启减少动态效果时，默认静止，可手动继续。
- 页面隐藏时停止动画，恢复后不追赶后台时间。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏全部界面，按 H 恢复 |
| `still=1` | 静止；`still=0` 显式播放，覆盖系统减少动态效果设置 |
| `speed=1` | 时间流速，0.25–2 |
| `focus=0.5` | 焦平面，0–1 |
| `light=1` | 透射光，0.6–1.3 |
| `seed=7319` | 随机种子，相同种子生成相同初始生态 |

设置仅在当前页面有效。长期预设可写入 URL，例如 `wallpaper.html?speed=0.75&focus=0.4&hud=0`。

## 性能与验证

主画布限制约 240 万像素，像素倍率不超过 1.5；内部颗粒使用小纹理缓存，失焦细胞合成到低分辨率图层。模拟采用 1/60 秒固定步长，后台停止调度，前台长帧最多推进 0.1 秒以避免跳跃。个体与食物泡数量均有上限，死亡残骸和已消化食物会及时移除。实际帧率取决于设备与宿主。
