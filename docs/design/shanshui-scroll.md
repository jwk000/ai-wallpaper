## 1. 一句话概念

一卷会自己展开的水墨山水：远山从雾里一层层推近，松、寺、瀑、舟都长在同一套笔法里；春的青绿、夏的石青、秋的赭石、冬的冷灰在一轮 24 分钟里缓慢换过，雨雪只是天气，不是另一个世界。

它不是动画贴图，而是一张可以长时间挂在桌面上的**会呼吸的卷轴**。任何一帧截下来都应当像一幅完整的画。

### 设计原则

1. **先是一幅画。** 主峰、留白、题款、印章与前景压角必须在第一眼成立；季节与天气是第二层。
2. **一笔到底。** 山、树、舟、鸟、雨、雪都用同一套墨色与笔触参数生成，不混入照片、贴图、发光滤镜或塑料高光。
3. **慢到忘记它在动。** 镜头以每秒几个像素展开，季节以分钟计，天气以 90 秒为最短停留；没有闪烁和强提示。
4. **可离线、可复现、可静止。** 单 HTML、Canvas 2D、无外部字体与网络；相同 `seed` 与 `t` 得到同一帧。

## 2. 画面

### 2.1 构图

```
┌────────────────────────────────────────────────────────────────────┐
│  LUMEN —— 山水档案                                      春 · 晴    │
│  山水长卷 / FOUR SEASONS IN INK                                    │
│  四时流转                                                          │
│                                                                    │
│        · 远山 15%       ___                                        │
│              ___      _/   \__          ____                       │
│        ____/   \____ /         \______ /    \____                  │
│    ___/  雾带  · · · · · · · · · · · · · · · · · · · · ·  ·       │
│   /  主峰 60–75%    寺观      瀑布                                 │
│  /       松林       ____       ||        ____                      │
│ /__________________/    \______||_______/    \_________________    │
│ ~~~~~~~~~~~~~~~ 江面 · 舟 · 水纹 ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  │
│ ▓▓ 岸石 / 芦苇 / 斜松 90% ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
└────────────────────────────────────────────────────────────────────┘
```

- **横向展卷**：正交、无透视。镜头以 `7 px/s` 向右平移；每 5 分钟叠加一次 ±2.2% 的极缓推拉。天空与江面合计留白不少于 35%。
- **竖屏立轴**：镜头锁在一座主峰上，不再横移；以 `0.35 world-px/s` 自上而下缓移，主峰居中偏上，前景压住下缘。只保留一座主峰、一道瀑布、一叶舟。
- **超宽屏**：保持平远，江面拉长，左右各多出一层低矮远山；主峰仍在左或右三分之一。
- **压角**：右下一段岸石与斜松，占画面约 1/6；左上或右上留给题款，不放主体。

### 2.2 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 宣纸 | `#e9dfc9` | 纸的底色，随昼夜轻微冷暖 |
| 墨 | `#1d1b18` | 以 12% / 20% / 35% / 55% / 75% / 95% 六档使用 |
| 春 · 青绿 | `#7c9a6a` | 新叶、浅草、远山淡染 |
| 夏 · 石青 | `#5a7f8c` | 浓荫、水气、雨后山骨 |
| 秋 · 赭石 | `#a8642f` | 枫叶、夕照、崖壁暖赭 |
| 冬 · 冷灰 | `#8d9297` + 留白 | 雪、冻水、月光 |
| 朱砂 | `#9c5643` | 只用于印章与极少的秋叶 |
| 强调色（meta） | `#8a5a3b` | 与 HUD、库内强调色一致 |

- 四季颜色以高斯权重在 18–30 秒内交叉淡化，不出现硬切；所有彩色再叠一层 `multiply` 墨色，整体饱和度压在 25% 以下。
- 昼夜：一轮 24 分钟中白天 16 分钟、夜晚 8 分钟。夜晚不是黑屏，而是“墨色更重、纸色偏冷”的月夜。
- 季节与昼夜按同一轮 24 分钟走：春（0–6 分）与夏（6–12 分）为昼，秋（12–18 分）由午后入暮，冬（18–24 分）为月夜并在末尾回到黎明。这样一整天正好读出四时。

### 2.3 层次

| 层 | 内容 | 墨度 | 更新 |
| --- | --- | --- | --- |
| 背景 | 纸纹、天色、日/月、3 层远山（12 峰） | 15% / 25% / 40% | 纸纹与山体缓存；天色每帧 |
| 中景 | 主峰、山脊、松林、寺观、瀑布、远岸 | 60–75% | 主峰缓存；瀑布、雾每帧 |
| 江面 | 水色、横水纹、倒影、舟、涟漪、水鸟 | 20–95% | 每帧 |
| 前景 | 岸石、芦苇、斜松、落花/落叶/雪 | 90% | 每帧，数量固定 |

- 远山之间夹 2–3 条雾带，雾带随风偏移；雾带是“空气透视”的唯一手段，不使用高斯模糊滤镜。
- 主峰受光侧用较干的短线（披麻皴），背光侧用更湿、更重的积墨；轮廓线只在受光侧提亮，避免描边感。
- 水面只画几根提亮的横线，不画镜面反射。倒影用极淡的倒置山影加横向错位。

### 2.4 笔法

- **起笔 / 行笔 / 收笔**：每一笔由 2–3 段折线组成，起笔加重、行笔略提、收笔用短虚线留出飞白；线宽 `0.55–2.2px`，同一笔内随机抖动 ±0.25px。
- **积染**：山体先铺一层 8–15% 的淡墨，再在崖脚、山脊交界叠 2–3 层更深的湿边；每层边缘比内部深 5–8%，形成“水痕”。
- **皴法**：受光侧用短、干、斜向的披麻皴；背光侧用长、湿、纵向的斧劈皴。每座山体 ≤ 220 笔，全卷缓存。
- **点苔**：山脊与石缝处 1–3px 的横点，越靠近画面前景越大。
- **树**：松树为“一干三曲、五出枝”，针叶用 12–24 根短放射线；远处树只画墨点与一两条竖线。
- **舟**：两笔船身、一笔篷、一笔篙，宽不过 34px；不画人物面部。
- **水鸟**：两笔“人”字翼，起飞时三帧不同张角，随后化为一个墨点。

## 3. 世界与镜头

- 世界为 `4800 × 1280` 的横向卷轴，横向坐标以卷长取模；地形由整数周期的正弦与周期性山峰叠加，首尾无缝。
- 横向镜头：`camX = (seedOffset + 7·t) mod 4800`；缩放 `zoom = 1 + 0.022·sin(2πt/300)`，以画面中心为锚点。
- 竖向镜头：`camX` 固定在一座主峰中心；`camY` 在 `0.03H–0.15H` 之间以 8 分钟为周期往返。竖屏的缩放由宽度决定，世界高度略大于视口，留出下移空间。
- 相机不做旋转、俯仰与自由拖动；壁纸的稳定优先于交互。
- 季节/天气/鸟/舟的位置都是 `t` 的纯函数或确定性的有限状态，因此 `?t=...` 可复现。

## 4. 季节、昼夜与天气

### 4.1 季节

- 一轮 1440 秒，每季 360 秒。
- 季节权重为循环高斯：`w_i ∝ exp(-0.5·(d_i/75)²)`，`d_i` 为到该季中心的循环距离；相邻两季在边界附近自然交叠。
- 季节影响：天色、山体淡染、树叶/落花、雪量、雾的浓度、水色、鸟的出现概率。地形与主峰位置不变，保证“同一座山，四时不同”。

### 4.2 昼夜

- 白天 `0–960s`，夜晚 `960–1440s`；在 840–960s 与 1360–1440s 做 120 秒的晨昏过渡。
- 日/月为纸上的淡墨圆盘，不加辉光；月亮只比纸亮半档，出现时把墨色整体压深 8%。
- 夜间保留纸的暖灰，不做纯黑；星点不超过 80 个，且只在冬季月夜出现。

### 4.3 天气状态机

- 状态：`clear` / `mist` / `rain` / `snow`，每段最短 90 秒，段间 12 秒交叉淡化。
- 由 `seed` 预生成一条 24 分钟循环的天气表；季节约束：春多雾/雨，夏多雨/晴，秋多晴/雾，冬多雪/晴。
- 雨丝 400 条、雪片 400 片，均为屏幕空间粒子；只画当前可见的，生命周期固定，不累积。
- 雨落在江面时，每 0.35 秒在随机位置生成一个小涟漪；雪不生成涟漪。
- `?weather=` 可强制天气，便于截图与验证。

## 5. 交互

| 操作 | 行为 |
| --- | --- |
| 指针划过江面 | 生成 3 圈同心涟漪，并惊起一只水鸟；0.6 秒冷却，避免刷屏 |
| 按住拖动 | 改变风向（左右为主，上下为辅），芦苇、雾带、雨丝、落花随之偏移；松手后 12 秒回到自然风 |
| 轻点（未拖动） | 切到下一季；若落点在江面，同时留下涟漪 |
| `Space` | 暂停 / 继续；暂停时仍响应缩放与季节切换 |
| `H` | 隐藏 / 显示 HUD；开场 14 秒后标题与读数自动淡出 |
| `F` | 全屏 / 退出全屏 |
| 设置面板 | 季节、天气、风、暂停、全屏、减少动态效果 |
| `←` / `→` | 上一季 / 下一季 |

- 桌面层收不到鼠标时，全部自动行为照常：镜头展开、季节流转、天气切换、水鸟偶发、舟缓行。
- 水鸟自动出现：每 85–150 秒一次，从江面起飞后飞出画面；不依赖交互。
- 季节切换有 1.2 秒的纸色过渡提示，不闪白、不切黑。

## 6. 循环与时间

- 镜头横移 4800 / 7 ≈ 11.4 分钟一圈；缩放 5 分钟一次；竖屏下移 8 分钟往返。
- 季节 24 分钟一轮；昼夜与季节同周期；天气表 24 分钟循环。
- 舟 3 叶，沿江面以不同速度缓行，出画后从对侧回来；单叶周期 3–5 分钟。
- 水纹相位 40 秒一循环，落花/落叶 12 秒一循环，雨雪粒子 6 秒一循环；所有循环首尾可接，不做整体重置。
- 页面隐藏时停止调度；恢复时重置时间戳，时间继续但不跳帧。

## 7. 渲染与性能

### 7.1 分层缓存

- **静态卷轴缓存** `bg`：4800×1280 透明画布，包含 3 层远山、主峰、松林、寺观、瀑布墨骨、远岸与江面底色。只在初始化和 `resize`/种子变化时重绘一次。
- **前景缓存** `fg`：4800×520 透明画布，包含岸石、坡脚、固定松干；芦苇、松针、舟、水纹、天气粒子每帧绘制。
- **纸纹**：视口尺寸的离屏画布，一次生成 16k 根纤维与 2k 个墨点；`resize` 时重建。
- 主画布每帧只做：纸底、静态卷轴裁切绘制、季节淡染、雾带、江面动态、前景裁切绘制、天气粒子、HUD。

### 7.2 预算

- 目标 30 FPS；`dt` 上限 0.1s，累积器固定 1/30s。
- 渲染像素 = `min(devicePixelRatio, 1.5)`，并保证 `w·h·dpr² ≤ 2.6M`；超出时自动降低后备分辨率（4K 下约 0.56×）。
- 远山 3 层 × 12 峰；山体皴笔全卷 ≤ 2400；树 60；舟 3；雨/雪各 400；水鸟 ≤ 3；涟漪 ≤ 24。
- 所有纹理、笔触、粒子都来自种子化 PRNG；不在每帧 `createLinearGradient`/`createRadialGradient` 超过 12 次。
- 页面隐藏时 `cancelAnimationFrame`；恢复时 `last=0`，不补帧。

### 7.3 可访问性与静态

- `<canvas role="img" aria-label="...">`；HUD 按钮可键盘聚焦，焦点有可见描边。
- 减少动态效果时默认静止在 `t=150`，提供“播放”按钮；`?still=0` 显式播放。
- `prefers-reduced-motion` 下不自动淡出 HUD，避免用户找不到控制。
- 静态海报：`?still=1&hud=0&t=...`；`t` 可取 0–86400 并自动取模。

## 8. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数与设置按钮 |
| `still=1` / `still=0` | 强制静止 / 强制播放 |
| `seed=20261110` | 山形、树、天气表的种子 |
| `t=760` | 场景时间（秒），默认 150；可超过 1440，自动按轮取模 |
| `season=spring|summer|autumn|winter` | 跳到该季中心，便于截图 |
| `weather=clear|mist|rain|snow` | 强制天气 |
| `wind=-1..1` | 初始风向 |
| `quality=0.6..1` | 细节密度倍率，默认 1 |

静态示例：`wallpaper.html?still=1&hud=0&t=780`。

## 10. 实现结构

```text
wallpapers/shanshui-scroll/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、四季规则、URL 参数、验证说明

docs/design/shanshui-scroll.md   本设计文档
scripts/verify-shanshui.cjs      模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、数学与颜色工具；
2. 山形、树、舟、雾、纸纹的生成器；
3. 静态卷轴与前景缓存；
4. 季节/昼夜/天气状态；
5. 每帧动态（水、雾、雨雪、鸟、芦苇、松枝、涟漪）；
6. 主循环、输入、HUD、验证钩子 `window.__lumenShanshui`。

## 11. 验证计划

1. **Node 模拟**：`node scripts/verify-shanshui.cjs`
   - 四尺寸各模拟 10 分钟，检查时间、季节权重、天气段长、粒子与对象上限、像素预算。
   - 检查交互 API：切季、涟漪、水鸟、风向、暂停、隐藏、减少动态效果、静态 resize。
   - 检查同 `seed` + `t` 的两次快照一致，以及 4800 取模后地形首尾差 < 1e-6。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏、竖屏、超宽屏、4K 截图，检查非空、尺寸正确、无控制台错误与网络请求。
   - 检查动画推进、暂停、切季、指针涟漪、拖动风向、HUD、设置面板、减少动态效果、窗口缩放。
   - 检查 `scanWallpapers()` 识别与无问题项；`--write-preview` 输出 `preview.png`。
3. **视觉复核**：逐张查看四季、雨/雪、横竖屏截图，确认山形、留白、压角、题款清楚，笔触不糊成块。
