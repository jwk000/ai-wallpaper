# 克拉尼之沙 · 无声的频率

一块拉丝黄铜板斜放在深色工作台上，板上铺着薄薄一层细沙。板在响，人听不见；沙沿着看不见的坡面排队，停在严格对称的节线上。板不动，动的只有沙。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「克拉尼之沙 · 无声的频率」并预览、应用。`preview.png` 是实际渲染截图。

- 移动指针：指针位置就是一次「调频」——横向调 `m`、纵向调 `n`，模态以 2.2 秒的时间常数跟过去，像拧一个带惯性的旋钮。
- 点击画面：敲一下板。给一次冲激，沙粒被震起来，两秒内重新排回节线。
- `↑` / `↓`：在预设模态表里前进 / 后退一格，手动优先保持 90 秒，之后交回自动。
- 右下角「调频台」：暂停、全屏、自动换模态、指针调频、敲一下板、换一块板。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 16 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 系统启用「减少动态效果」时默认静止，可手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，模态照常每 44–62 秒自动换一次，沙照常迁移、收敛，画面依然完整。

## 沙的规则

- **模态场**：方板、自由边界，`f(u,v) = cos(nπu)·cos(mπv) − cos(mπu)·cos(nπv)`。节线即 `f = 0`；两条对角线 `u = ±v` 对任何模态都是节线，所以画面里总有一个「X」。
- **场表**：模态函数预计算成 96×96 的网格，存 `f` 与 `∂f/∂u`、`∂f/∂v`。沙粒每帧只做双线性查表，不重算三角函数。
- **受力**：`a = −K·(|f| − f₀)·∇f`，`f₀ = 0.055`。这是真实的克拉尼条件——局部振幅低于阈值的地方板不动，沙就停住；所以节线有宽度，沙不会永远抖。
- **摩擦**：速度低于 0.012 单位/秒时额外压一次阻尼；停下来 24 帧的沙粒进入休眠，跳过积分。稳定态下约 99% 的沙在休眠，模态一变立刻全部唤醒。
- **邻居**：板面分成 160×160 的空间桶，每粒沙只和同格与右、上、右上三格的沙互推，避免堆成一点、也让密处略微压暗。
- **浮尘**：约 6% 的沙粒几乎不动（`mobility = 0.05`），散在板的各处。沙密处读作灰面，稀处是散点。
- **收敛**：换模态后 8–10 秒内沙基本归位，12 秒后平均 `|f|` 从 0.27 落到 0.12 并保持，画面接近静止，只剩环境光在呼吸。10 分钟里约八成的时间处于收敛态。
- **竖屏**：不缩小板，而是把板放大 1.36 倍后裁取它的一角，节线从四边弯出画面，下方露出板边与桌面。

## 光与镜头

- **镜头**：30° 斜俯视、正交投影；板面在屏幕上压成 `sin 30° = 0.5`，再在板平面内转 30°，于是方板呈菱形（投影外接框 2:1）。
- **呼吸**：倾角 `±1°`、周期 96 秒；推近 `1.00 → 1.02 → 1.00`、周期 180 秒。除此之外机位不动。
- **材质**：黄铜板在离屏画布上一次画好——沿 `u` 方向的 1150 条拉丝、26 道深划痕、8 处抛光磨损、3200 个铜锈麻点、上左受光的渐变、两条后边的倒角高光与两条前边的暗边。全部程序生成，不用贴图。
- **层次**：背景是深灰绿工作台、失焦的旋钮与仪器指示灯、光柱里的尘埃；中景是板、板的黄铜侧面与沙；前景是右下角一条离焦线缆、板外散落的几粒沙与暗角颗粒。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数和按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 种子；固定后复现沙的初值、明度、相位与每段模态的停留时间 |
| `t=240` | 起始时间，单位秒；同一 `seed` 与 `t` 渲染同一帧 |
| `auto=0` | 关闭自动换模态，只保留手动与指针 |
| `tune=0` | 关闭指针调频（点击仍然有效） |
| `detail=0.6` | 沙粒数量比例（0.5–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=240&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

固定种子的纯壁纸：`wallpaper.html?seed=20261110&hud=0&auto=0`

## 运行预算

- 动画目标 30 FPS；四种尺寸的单帧耗时实测 0.95 / 0.96 / 0.96 / 1.23 ms（`render()`，离屏、无硬件加速），30 FPS 有余量。
- 每张画布最多约 260 万渲染像素，像素倍率上限 1.5（1920×1080 → 1.12，4K → 0.56）。
- 沙粒 9000（硬上限）；空间桶 160×160；模态表 96×96×3；尘埃 sprite 11 个。
- 每帧绘制：1 次背景、1 次板（变换后的单次 `drawImage`）、2 个黄铜侧面四边形、4 条沙的批量路径（1 条晕光 + 3 档明度，只有 4 次 `fill`，而不是 9000 次 `fillRect`）、1 次环境光、1 次覆盖层、11 个尘埃。实测 `render()` 0.95–1.23 ms。
- 场表只在模态变化超过 0.0035 时重建，稳定后完全不重建；板、背景、覆盖层在尺寸变化时烘焙一次；板的离屏画布按设备分辨率烘焙，避免 4K 下每帧重采样一张满分辨率的板。
- 主循环用真实经过时间推进模拟，只在间隔超过 12 ms 时才更新与重绘，避免时间戳抖动造成的空转；在 60 Hz 屏幕上画面以显示刷新率推进，在 30 Hz 屏幕上稳定 30 FPS。
- 页面隐藏时取消动画调度；恢复后重置时间戳，避免后台时间造成跳帧。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-chladni-sand.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-chladni-sand.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查沙粒数量与坐标、速度上限、板内边界、休眠比例、平均 `|f|` 的收敛、模态切换次数、两条路线是否都走到、指针调频、敲板冲激、暂停、隐藏页面、缩放与确定性复现。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度分布、暖色占比、动画推进、指针调频、敲板、设置面板、HUD、减少动态效果、无网络请求和无控制台错误。截图写入系统临时目录 `lumen-chladni-sand-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动换模态是必要的保底。
