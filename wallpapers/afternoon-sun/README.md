# 午后 · 与真实太阳同步

一间极简的房间，一束带窗格形状的阳光落在木地板上。光斑按窗外真实的太阳位置移动——不是循环动画，是此刻的太阳：它用本地时钟、时区和经度算出方位角与高度角，于是正午的窗影短而偏左，四点以后被拉成一条长斜线，日落后整个房间转成蓝色，台灯自己亮起来。尘埃只在光里显形，窗帘被指针拨动时会改变光斑的形状。

它知道现在几点。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「午后」并预览、应用。`preview.png` 是实际渲染截图（1920×1080，`?still=1&t=54720`）。

- 移动指针：拨动窗帘的 8 条正弦带，帘子被推开的多少直接决定哪几格窗格透光，地板上的光斑随之改变形状；松手后约 10 秒回到自然摆动。
- 点击画面：开 / 关台灯。不点它也完全正常——日落后台灯自己亮，天亮自己灭。
- 右下角「日光设置」：暂停、全屏、台灯、指针拨动窗帘，以及今天的日出、日落、日照时长与当前相位。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 12 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 系统启用「减少动态效果」时默认静止在当前时刻，可手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，太阳照常走，尘埃照常漂，窗帘照常摆，画面依然完整。

## 日光规则

- **它知道几点**：太阳位置用 NOAA 简化算法从本地时间、时区、经度（默认由时区反推，`lon` 可覆盖）与纬度（默认 31.2°N）算出赤纬、时差、真太阳时、高度角与方位角。日出、日落、日照时长同样由当日赤纬解出，所以十一月与六月的画面本来就不同——不是切换季节贴图。
- **不做人工加速**：`tOfDay` 与真实时间 1:1 前进，24 小时一轮，没有人为循环，也没有回放。
- **窗与光斑**：房间是一台固定的针孔相机（35mm 感，略低，横向俯角 8.3°，机身 0.95 m，距后墙 4.6 m）。窗开在后墙左侧，1.0 m 宽、0.55–1.43 m 高，3×4 格。光斑由此算出：窗格的每个顶点按太阳高度角抛出射线（水平位移 = 高度 / tan 高度角），落到地板平面上，再经同一台相机投回屏幕，得到 12 个四边形。没有 3D，只有 2D 阴影投影。
- **光斑的形状**：窗格的每一格单独绘制，格与格之间留出窗棂的缝，柔化用一层 0.22× 的离屏缓冲加 blur，所以边缘柔和、窗格形状仍然读得出来。玻璃上的三列四行与地板上完全对应。
- **落点**：15:12 的十一月太阳把光斑中心放在 (0.37w, 0.73h)（条目要求 0.35w / 0.70h）。随太阳西斜，光斑向右滑、并朝镜头方向拉长；正午时它短、靠墙，日落前被拉成一条长斜线。
- **色温**：墙面、地板、光、天光五个量在 9 个「太阳高度」色标之间插值——正午 `#f2e6d0` 冷白、黄昏 `#e8a860` 暖橙、蓝调时刻转紫蓝、夜间 `#1a2033`。墙 `#d8cbb8`、地板 `#8a5f3c` 是基准值，靠一层层明度与色偏推到现在这一刻。
- **尘埃**：200 枚，位置是时间的纯函数（几组周期 27–41 秒的正弦），只在光斑里被点亮；被点亮时暖白、略大，光斑外几乎不可见。另有 5 枚离焦的前景光斑。尘埃的初始分布沿光斑一天的行走路径撒点（每枚随机取一个时刻，落在那一刻的光斑里），所以任何时段光里都有尘埃。
- **窗帘**：8 条正弦带，每条有自己的振幅、频率与相位；帘子的右缘由它们的和决定，指针的推动是一个会衰减的偏移量（时间常数 3.4 秒），并且被 clamp 在 ±1。
- **台灯**：`amb < 0.42` 时自动亮（约在太阳落到地平线附近），点击则进入手动状态并保持到页面重载。灯罩是暖白纸，夜间在墙上投出一圈暖光，地板上有一道光池。
- **镜头**：不动。没有推拉摇移，只有光、尘埃与窗帘在动。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数与设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 种子；固定后复现尘埃初值、窗帘相位与灰阶 |
| `t=54720` | 起始时刻，单位秒（从当天 00:00 起算）；同一 `seed`、`t`、`day` 渲染同一帧 |
| `day=2026-11-11` | 日期，决定赤纬与日照时长；缺省取系统当天 |
| `lat=31.2` | 纬度；默认 31.2°N |
| `lon=120` | 经度；缺省由时区反推（东八区 → 120°E） |
| `lamp=1` / `lamp=0` / `lamp=auto` | 强制台灯开 / 关 / 跟随太阳（缺省） |
| `curtain=0` | 关闭指针拨动窗帘，帘子只按自己的正弦摆动 |

静态海报：`wallpaper.html?still=1&t=54720&day=2026-11-11&hud=0`

纯壁纸：`wallpaper.html?hud=0`

正午：`wallpaper.html?still=1&t=43200&hud=0`

蓝调时刻：`wallpaper.html?still=1&t=61500&hud=0`

## 运行预算

- 目标 30 FPS（`requestAnimationFrame` 里用 33.3 ms 的帧闸门限速，`dt` 取真实经过时间，上限 0.12 s）；30 FPS 是验收线，低于它算失败。
- 每张画布最多约 260 万渲染像素，`devicePixelRatio` 上限 1.5；3840×2160 时倍率回退到 0.56。
- 尘埃 200、离焦光斑 5、窗帘 8 条正弦带、光斑 12 个四边形（20 个顶点）、家具 1 组（台面 + 2 条腿 + 台灯）。都是硬上限，不随运行时长增长。
- 每帧只做：墙面/地板几笔渐变、一张预先烘好的纹理、窗、光斑（0.22× 缓冲 + 一次 blur + 两次合成）、家具、尘埃（按 3 档亮度批量成路径）、窗帘、离焦光斑、暗角。两次全屏合成，没有全屏累积缓冲，长时间运行不会越跑越亮。
- 静态层（灰泥颗粒、木纹、板缝、踢脚线、暗角、胶片颗粒）只在尺寸变化时烘焙一次。
- 太阳位置每帧重算（一次三角函数多项式，成本可忽略）；光斑几何每帧重投影 20 个顶点。
- 页面隐藏时取消动画调度；恢复后重置时间戳，避免后台时间造成跳帧。暂停或减少动态效果时仍响应窗口尺寸变化并重绘。
- 同一 `seed`、`t`、`day` 两次加载渲染完全相同的像素（验证脚本用 `toDataURL` 的 SHA-256 比对）。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-afternoon-sun.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-afternoon-sun.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏、4K 各 10 分钟，检查尘埃/窗帘/光斑的对象数量、顶点数、坐标有限、像素预算、时钟 1:1、15:12 的落点、确定性复现、一天的太阳扫掠（高度角 −76°–42°、日照 10.5 小时、午夜无光斑、台灯自动亮）、台灯手动/自动、窗帘推动与衰减、暂停、隐藏页面、缩放与 URL 开关。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度与色温分布、动画推进与 30 FPS 闸门、点击开关台灯、暂停、暂停时缩放、HUD、减少动态效果、无网络请求和无控制台错误。截图（横屏、竖屏、超宽屏、4K、黄金时刻、蓝调、黎明）写入系统临时目录 `lumen-afternoon-sun-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此台灯自动开关与窗帘自动摆动是必要的保底。

设计文档见 [`docs/design/afternoon-sun.md`](../../docs/design/afternoon-sun.md)。
