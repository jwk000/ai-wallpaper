# 水母群 · Parametric Medusozoa

直接用浏览器打开 `wallpaper.html` 即可播放，无需联网、安装依赖或外部素材。在流光壁纸的本机壁纸库中选择「水母群」可预览或应用到桌面。

九只水母按远近分层，以青绿、淡金和浅紫发光。伞盖周期收缩，触须随波摆动，水母沿缓慢上升的海流漂游；完整游出画面后从下方重新进入。背景包含海面光束、焦散和悬浮微粒。

## 操作

- `Space`：暂停或继续。
- `H`：隐藏或显示说明文字；开场文字约 20 秒后自动淡出。
- `F`：进入或退出浏览器全屏；也可按 `Esc` 退出全屏。
- 系统启用「减少动态效果」时默认静止；在地址后添加 `?still=0` 可显式启用动画。

纯壁纸模式：`wallpaper.html?hud=0`。

静态取景：`wallpaper.html?still=1&t=7.2&hud=0`，其中 `t` 为动画时间（秒）。

## 数学绘制

所有水母均实时通过 Canvas 2D 绘制，未使用水母图片或视频。

- 伞盖横坐标：`x(s,t) = s W(t) (1 + 0.055 |s|⁵)`，`s ∈ [-1,1]`。
- 伞盖纵坐标：`y(s,t) = -H(t) (1-s²)^0.62`。
- 收缩系数：`c(t) = [0.5 + 0.5 sin(2π f t + φ)]³`，控制 `W(t)=1-0.115c(t)` 与 `H(t)=0.760+0.085c(t)`。
- 伞缘使用不同频率的余弦叠加；触须由沿长度衰增的正弦波、漂移项和卷曲项构成。
- 位置由匀速上升、低频正弦海流和各自的缓慢摆动共同决定。

画布适配横屏、竖屏及高分辨率显示器，渲染像素预算约为 380 万像素；帧率偏低时自动减少细节，页面不可见时跳过绘制。
