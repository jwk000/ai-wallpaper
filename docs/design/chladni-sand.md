## 1. 一句话概念

一块拉丝黄铜板上铺着一层细沙。板在响，人听不见；沙沿着看不见的坡面排队，停在严格对称的节线上。板不动，动的只有沙。

它不是粒子演示，也不是屏保图案，而是一张**会自己重新排队的科学仪器照片**。

### 设计原则

1. **先是一张照片，才是一段模拟。** 任何一帧截屏都要能当海报：黄铜板是唯一焦点，左侧留白给标题，右下角有一小片失焦的前景把画面收住。
2. **沙的秩序来自场，不来自贴图。** 每一粒沙都被同一个 96×96 的模态场推动、被空间分桶的邻居排斥、被阻尼按住；花纹是这三次作用的结果，不是画上去的。
3. **慢，且不重播。** 模态每 44–62 秒换一次，迁移 6–10 秒；沙收敛后画面接近静止，只剩环境光在呼吸。两条路线交替走，8 分钟一轮，画面不会按同一顺序重演。
4. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

## 2. 相机

- **视角**：正面 30° 斜俯视，正交投影，没有透视。板面在屏幕上被压扁为 `sin 30° = 0.5`，再在板平面内转 30°，于是方形板在画面里呈**菱形**（投影后外接框 2:1）。
- **机位**：固定，不做自由运镜。只有两项极缓的呼吸：
  - **倾角呼吸**：`±1.0°`，周期 96 s，`θ(t) = 30° + 1° · sin(2πt/96 + φ)`；板、沙、侧面厚度一起动。
  - **推近呼吸**：`1.00 → 1.02 → 1.00`，周期 180 s（每 3 分钟一次 2% 推近）。用余弦而不是锯齿，避免回跳。
- **投影公式**（板坐标 `u,v ∈ [-1,1]`，`s` 为板半边长，`z` 为推近系数）：

```
sx = cx + s·z·(u·cosθ − v·sinθ)
sy = cy + s·z·0.5·(u·sinθ + v·cosθ)
```

- **竖屏**：不缩板，而是把板放大后裁取它的一角——`s = 0.62h`，板心移到 `(0.50w, 0.36h)`。于是节线从四边弯出画面，画面下方露出板边（黄铜侧面）与工作台。
- **超宽屏**：板按高度定尺寸（`s = 0.515·min(w,h)`），左右各让出约 20% 给失焦的仪器，不拉伸不裁切。

- 中景是唯一清晰层；背景与前景都不与节线争夺注意力。
- 板面材质不用任何贴图：拉丝靠 1150 条 0.5–2.0 px 的横向细线加 26 道深划痕，磨损靠 8 处径向渐变的抛光痕，麻点靠 3200 个确定性斑点，全部在烘焙时画进板的离屏画布；两条后边是亮倒角，两条前边是暗边，再叠一块黄铜侧面。

## 4. 算法：模态场与沙

### 4.1 模态函数

方形板、自由边界，两个模态数 `m, n`：

```
f(u,v) = cos(nπu)·cos(mπv) − cos(mπu)·cos(nπv)        u,v ∈ [-1,1]
```

节线即 `f = 0`。取 `m = n` 时 `f ≡ 0`（板整体不振），所以交互与路线都避免 `m ≈ n`，指针映射时若 `|m − n| < 0.45` 会把 `n` 推开。

### 4.2 场表

- 预计算 **96×96** 网格，存三张 `Float32Array`：`f`、`∂f/∂u`、`∂f/∂v`。
- 建表时先算 4 条 1D 表（`cos mπx`、`cos nπx`、`sin mπx`、`sin nπx`，各 96 项），再在 9216 个格点上做乘加。一次重建约 0.1 ms。
- 粒子**只查表**：用双线性插值读 `f` 与梯度，不在每帧重算三角函数。
- 重建条件：`|m − gridM| + |n − gridN| > 0.0035`。模态迁移期间大约每帧重建一次，稳定后完全不重建。

### 4.3 沙的受力

```
d  = sign(f) · max(0, |f| − f₀)             f₀ = 0.055，低于阈值板是静的
a  = −K · d · ∇f · mobility                 （沿 |f| 下降方向爬向节线）
v ← (v + a·dt) / (1 + dt/τ)                 τ = 0.75 s，过阻尼
|v| ≤ 0.22 单位/秒，|a| ≤ 1.5
```

- `K = 0.07`。`f₀` 是真实的克拉尼条件：局部振幅低于阈值的地方板根本不动，所以沙会「滑过去、停住」，节线有确定的宽度，而不是一个永远在抖的奇异点。
- 每粒沙有 `mobility ∈ [0.5, 1.0]`，另有约 6% 的「浮尘」沙粒 `mobility = 0.05`，它们几乎不动，散在板的各处——这就是「稀处是散点」。
- 邻域排斥：板面 `[-1,1]²` 分成 **160×160** 空间桶（格边 0.0125，大于排斥半径 0.0062）。每粒沙只检查自己与右、上、右上三个格子里的沙，两两互推；同时把邻居数记为局部密度，用于微调沙的明度（密处压暗一点，读作灰面）。
- 撞击：点击 = 敲板。`vibration` 跳到 1，按 1.4 s 时间常数衰减；冲击点 0.35 单位内的沙按距离衰减得到一次速度冲量，整块板同时叠加高频微颤（正弦，用每粒沙的相位，不消耗随机数）。
- 休眠：速度低于 0.005 单位/秒连续 24 帧的沙粒进入休眠，速度清零并跳过积分；模态变化、撞击或邻居挤压时唤醒。稳定态下 99% 的沙在休眠（实测 8984/9000），每帧只剩一次扫描与绘制。

### 4.4 初始帧（确定性）

静止帧不能靠「从 0 积分到 t」，那会变成几秒的白屏。做法是把已收敛的图形**直接采样出来**：

- 对每粒沙，用精确三角函数在**当前目标模态**的势场里做拒绝采样（接受 `|f| < 0.085`），得到节线附近的落点；最多试 48 次，取最接近的一次兜底。
- 若 `t` 落在一次迁移中间（`since < 10 s`），再在**上一模态**的势场里采一个起点，按 `s = smoothstep(clamp((p − d)/(1 − d)))` 把两段位置插值；`d` 是每粒沙的 0–0.45 延迟，所以迁移是错开的、有先后，而不是整体平移。
- 因此 `wallpaper.html?still=1&seed=…&t=…` 在任何时刻都能立刻给出一帧成立的照片；播放态再从这一帧继续积分。

## 5. 交互

| 操作 | 行为 |
| --- | --- |
| 指针移动 | 指针对应「相邻模态的连续插值」：`m = 1 + 6.2·(x/w)`，`n = 1 + 6.2·(y/h)`；横向扫过即一次调频。目标值直接跟随指针，实际模态以一阶滞后 2.2 s 逼近，于是扫过去像拧旋钮，有惯性 |
| 点击 | 敲一下板：冲激 + 高频微颤 + 局部速度扰动，2 s 内衰减 |
| `↑` / `↓` | 在预设模态表里前进 / 后退一格，保持 90 s 的手动优先，然后交回自动 |
| 无输入 | 每 44–62 秒自动换一次模态；指针离开或 8 秒不动后自动接管，绝不留在指针位置 |
| `Space` | 暂停 / 继续；暂停时仍响应缩放、敲击（敲击会推进 0.6 s 让沙动一下再停） |
| `H` | 隐藏 / 显示 HUD；开场 16 s 后淡出 |
| `F` | 全屏 / 退出全屏 |
| 面板 | 暂停、全屏、自动换模态、指针调频、敲一下板、换一块板（重新播种） |

桌面宿主收不到鼠标时，路线遍历、沙的迁移、环境光呼吸照常运行，画面依然完整。

## 6. 循环与时间

- **路线 A**（4 段）：`(1,2) → (2,3) → (3,5) → (4,7)`
- **路线 B**（5 段）：`(4,7) → (6,4) → (5,3) → (3,2) → (1,2)`
- 两条路线首尾相接（A 的末模态 = B 的首模态，B 的末模态 = A 的首模态），衔接处自动跳过一次重复模态，不产生空转。
- 第偶数轮按 `A → B` 走，第奇数轮按 `B → A` 走；每段的停留时间用种子化随机数（44–62 s），所以 8 分钟一轮之后画面的顺序与节拍都不会原样重演。
- 单次迁移 6–10 s（由 2.2 s 一阶滞后自然给出，实测 95% 在 7 s 内完成）。
- 环境光呼吸 96 s；倾角呼吸 96 s；推近呼吸 180 s；三者互质程度足够，画面在数十分钟内不重复。
- 页面隐藏时 `cancelAnimationFrame`；恢复时重置时间戳，时间本身连续。

## 7. 运行预算

- 动画目标 30 FPS。主循环用真实经过时间推进，间隔不足 12 ms 的帧直接跳过，`dt` 上限 0.1 s；60 Hz 屏幕上按显示刷新率推进，30 Hz 屏幕上稳定 30 FPS。
- 单画布渲染像素 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退（1920×1080 → dpr 1.12；4K → 0.56）。
- **沙粒 9000**（硬上限，`detail` 可降到 0.5 → 4500）；空间桶 160×160；模态表 96×96×3。
- 每帧绘制：1 次背景、1 次板（变换后的一次 `drawImage`）、2 个黄铜侧面四边形、4 条沙的批量路径（1 条晕光 + 3 档明度，共 9000 × 4 个 1–2 px 小矩形，但只有 4 次 `fill`）、1 次环境光、1 次覆盖层、11 个尘埃 sprite。实测 `render()`：1920×1080 0.95 ms、390×844 0.96 ms、3440×1440 0.96 ms、3840×2160 1.23 ms。
- 板的离屏画布按设备分辨率烘焙（`k = clamp(dpr × 1.06, 0.5, 1)`）。最初按 CSS 尺寸烘焙，4K 下每帧要把 2025² 的板按 0.56 倍旋转重采样，单这一项就要 27 ms；改按设备分辨率烘焙后 4K 每帧总耗时从 44.6 ms 降到 1.4 ms。
- 稳定态下沙粒休眠，物理更新只剩一次 9000 次的分支扫描；迁移期间全部唤醒，约 9000 次查表 + 9000 次邻居检查。
- 板、背景、覆盖层在尺寸变化时烘焙一次；沙与场表每帧更新。
- 所有随机数来自 `mulberry32(seed ⊕ salt)`；沙的初值、明度、相位、路线停留时间都由 `seed` 决定，模态与呼吸相位由 `t` 决定。

## 8. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面：黄铜板上细沙停成对称节线的俯视图。
- 面板按钮有 `aria-expanded` / `aria-controls`；开关用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、换模态、开关自动与指针调频、敲板与重新播种。
- 减少动态效果时默认静止，HUD 保持可见，面板里有「继续」入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 9. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 种子；固定后复现沙的初值、明度、路线停留时间 |
| `t=240` | 起始时间（秒）；同一 `seed` 与 `t` 渲染同一帧 |
| `auto=0` | 关闭自动换模态，只保留手动与指针 |
| `tune=0` | 关闭指针调频（点击仍然有效） |
| `detail=0.6` | 沙粒数量比例（0.5–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=240&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 10. 实现结构

```text
wallpapers/chladni-sand/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 模态场与沙）
├─ meta.json          标题、副题、描述、标签、强调色、排序 6.1
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、物理与循环、URL 参数、验证说明

docs/design/chladni-sand.md   本设计文档
scripts/verify-chladni-sand.cjs   模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 常量、参数、种子、工具函数；
2. 布局与相机（四种尺寸的板心与半边长、投影矩阵、呼吸）；
3. 模态场：1D 表 → 96×96 的 `f / ∂u / ∂v`，双线性采样；
4. 路线与时间表：两条路线、44–62 s 停留、首尾衔接；
5. 沙：拒绝采样初值、迁移插值、受力积分、空间桶排斥、休眠；
6. 烘焙：背景 / 板 / 覆盖层 / 尘埃 sprite；
7. 每帧绘制（板、侧面、沙、环境光、覆盖层、尘埃）；
8. 主循环、输入、HUD、`window.__lumenChladni` 验证钩子。

## 14. 实现记录（2026-11-11）

- 相机、构图、色彩、层次、交互、循环均按上文实现，没有静默降级。
- 两处与条目的字面出入，写在这里：
  1. **「菱形边与画面成 30°」**：按字面（菱形两条边都成 30°）在 2:1 的投影里不可行——`sin 30°` 的压缩使两组边只能分别落在 30° 与 23.4°，看上去是平行四边形而不是菱形。实现取的是「板面内旋转 30°」，投影后两组边分别约 41° 与 16°，读起来才是菱形。
