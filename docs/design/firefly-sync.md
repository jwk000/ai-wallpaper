## 1. 一句话概念

夏夜草坡上，两千多个萤火各闪各的。它们只和身边一小圈同伴、以及整片草坡的平均相位打交道，谁也不听指挥；可耦合一旦升起来，整片山坡会先亮一下、再像潮水一样从一侧漫到另一侧，然后散开——十五分钟后，同样的呼吸再来一次。

它不是粒子烟花，也不是"同步率仪表盘"，而是一张**会自己继续呼吸的夏夜长曝光**。

### 设计原则

1. **先是一张好壁纸，才是一群振子。** 任何时刻截屏都要成立：天空只在上四分之一，草坡占住下半部，萤火聚在 (0.55w, 0.55h) 附近，左右下角有失焦的草收边。
2. **同步必须是算出来的，不是排出来的。** 波前来自 `θ = φ - lag` 这一个相位差，而不是把亮度按 x 坐标乘一条正弦。
3. **永远不完美。** 固有周期相差 ±29%，耦合增益 0.55–1.0，指针随时会打散一小片；R 在 0.4–0.95 之间浮动，不会到 1。
4. **慢，且不重复。** 个体 40–90 秒一轮生命，耦合 15 分钟一次呼吸，镜头只有 1% 的漂移；没有全局重置。

## 3. 相位场

### 3.1 Kuramoto，带空间网格

每个萤火一个相位 `θ_i ∈ [0, 2π)` 与固有角频率 `ω_i = 2π / T_i`，`T_i ∈ [5.3, 9.7]s`。演化：

```
dθ_i/dt = ω_i + K · coup_i · calm_i · [ 0.72·r_cell·sin(ψ_cell − φ_i)
                                     + 0.28·R·sin(Ψ − φ_i) ]
φ_i = θ_i + lag_i
```

- `coup_i ∈ [0.55, 1.0]`：个体耦合增益，模拟"有的虫比较固执"。
- `calm_i ∈ [0.05, 1]`：被惊扰后的耦合抑制，时间常数 2.6 秒回到 1。
- 网格按尺寸取 `26×15`（竖屏 `13×28`，上限 390 格），1920×1080 下每格约 74×72px。每格先累加 `Σsinφ, Σcosφ`，再做 3×3 加权模糊（权重 1/2/1 × 1/2/1），得到局部平均场 `r_cell·e^{iψ_cell}`。
- 全局场 `R·e^{iΨ}` 只占 28% 权重，负责让整片草坡不至于分裂成互不相干的几团。

### 3.2 去滞后相位（关键一步）

`lag_i = lagAmp · (proj_i − 0.5)`，`proj_i` 是位置在一条缓慢旋转的轴上的归一化投影，`lagAmp ∈ [0.4, 2.4]rad` 随耦合呼吸。

如果直接把 `θ` 拿去求平均，一道漂亮的波前在局部平均场里看起来就是"一片混乱"，局部耦合会把波抹平。所以网格平均的是 **去滞后相位 `φ = θ + lag`**：波前是 `φ` 空间里的整体同步，`θ` 空间里的相位梯度则原样保留。锁定后 `θ_i ≈ Ψ − lag_i`，闪光的时刻由 `lag_i` 决定——**波前自然从 lag 小的一侧扫向 lag 大的一侧**，不需要任何额外动画。

### 3.3 耦合呼吸与波

```
nightness(t) = 0.5 − 0.5·cos(2πt/900 + 1.9)
K(t)         = 0.40 + 0.50·nightness            // 0.40 → 0.90 → 0.40，15 分钟
lagAmp(t)    = (0.55 + 1.85·nightness) · (0.72 + 0.28·sin(2πt/311))
```

- K 高时全场连贯（实测 R ≈ 0.91），波前在 2–3 秒内扫过整幅画面；K 低时散成几团（R ≈ 0.43），只剩稀稀落落的局部同闪。
- 波的方向由 `waveAngle = 0.55·sin(2πt/433) + 0.30·sin(2πt/197) + 风` 决定，所以有时从左到右、有时从右下往左上，不会变成一条固定的斜线。

### 3.4 自动微风（交互兜底）

`breeze=1`（默认）时，一个双正弦气流让 `windOffsetX/Y` 在 ±0.75% 画面宽度内摆动，并每 70–160 秒来一次 1.8 倍阵风；风同时推动个体位置与 `waveAngle`。因此**桌面层完全收不到鼠标时，同步波依然会被吹歪、画面依然在动**。

## 4. 个体

- **数量**：横向/超宽/4K 2200，竖屏 980，`detail` 再乘 0.5–1；恒定不变。
- **分布**：`u < 0.40` 高斯核 `(0.55w, 0.55h)`，`σ = 0.27w / 0.17h`；`0.40 ≤ u < 0.74` 沿草坡脊线上方 0.01–0.13h 漂成一条斜带；其余均匀撒在草坡上。全部个体被夹在第二重山脊线以下，不会飘到天上。
- **景深**：远层 26%（5–11px，α 0.46）、中层 56%（16–33px，α 1.0）、近层 18%（34–72px，α 0.46，读作大光斑）。
- **闪光**：`f = clamp((cosθ − 0.52)/0.48, 0, 1)³`，亮度 `α = peak·(0.07 + 0.93f)·env + kick`。立方曲线让闪光只占周期的约 18%，其余时间是 7% 的余辉小点。
- **生命周期**：40–90 秒；淡入 2.5 秒、最后 4 秒淡出；寿终就地换一只（位置、尺寸、颜色、漂移相位重抽，固有频率与耦合增益一并重抽），总数不变。
- **运动**：位置是时间的解析函数 `base + Σ A·sin(2πt/P + φ)`（A = 3–15px，P = 19–128 秒），再叠加风与拖拽位移。因此**同一 `seed` 与 `t` 必然得到同一帧**，静止帧不需要预热。
- **拖尾**：闪光个体的光斑沿漂移反方向再画两份（0.26 / 0.09 透明度），读作短拖尾。
- **颜色**：`mix[i] > 0.52` 用暖色 sprite，其余用黄绿；两套 sprite 各自带白色亮芯。

## 5. 初始帧与确定性

- 启动时 `θ_i = wrap(φ0 − lag_i + jitter_i)`，`φ0 = 2π·t/7.5`，`jitter_i ∈ ±0.35` 由 `seed` 决定。于是任何 `t` 下第一帧就已经是一道完整的同步波，不需要预热，也不会开局黑屏。
- `t=75`（10 个名义周期）时全场几乎同时亮起，`t≈76.4` 时是一道从一侧进入的波前；`verify` 的预览用 `t=75`。
- 静止帧不跑积分，只按 `t` 求位置与亮度；播放态在同样初值上继续积分，所以同一 `seed`/`t` 两次加载逐像素一致。

## 6. 交互

| 操作 | 行为 | 自动兜底 |
| --- | --- | --- |
| 指针靠近 | 150px 内的个体相位被随机打散，耦合降到 `calm ≥ 0.05`，约 3–6 秒恢复 | 无输入时不出现；同步波本身就在动 |
| 按住拖动 | 位移场被推开（±7% w / ±6% h），`waveAngle` 最多偏 ±0.9rad，把波推歪；松手后 20 秒衰减 | 自动微风每 70–160 秒做一次同类扰动 |
| 轻点 | 230px 内相位归零并给 0.1–0.72 的 `kick`，一小片立刻同时亮 | 全场同步闪光本身就是这件事的自动版本 |
| `Space` | 暂停 / 继续；暂停时仍响应缩放与交互重绘 | — |
| `H` | 隐藏 / 显示 HUD；16 秒后自动淡出 | — |
| `F` | 全屏 / 退出 | — |
| 设置面板 | 暂停、全屏、自动微风、指针惊扰、换一片草坡、重新聚拢 | — |

- 指针只在真正有输入时出现光晕；没有指针时不画任何光标环。

## 7. 循环与时间

- 不做整体重置：相位、生命周期、风向都是连续状态。
- `5.3–9.7s`：单只萤火的闪光周期。
- 时间尺度以「一次呼吸」为单位：单只萤火 5–10 秒闪一次，但一只虫要 40–90 秒才轮到下一次明显亮起，整片草坡 15 分钟才走完一轮耦合。通用规格里「避免秒级闪烁」在这里有意让位于生物原型——闪光包络用三次曲线压到周期的约 18%，高光像素只占 0.1–0.5%，读起来是明灭呼吸而不是频闪。
- `40–90s`：个体寿命，淡入淡出替换，总数恒定。
- `15min`：耦合呼吸 0.40 → 0.90 → 0.40；同步波的跨度同时变化。
- `70–160s`：自动阵风；`197s`：镜头 ±1% 横向漂移；`95s`：焦点呼吸。
- `311s / 433s / 197s`：波方向与波幅的三重调制，组合周期远大于一次观看时长。
- 页面隐藏时停止调度；恢复时重置时间戳（时间本身连续）。

## 8. 渲染与性能

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 夜空 / 星 / 远山 / 草坡 / 草叶 / 灌木 | `bgCanvas`（全分辨率） | 尺寸变化时重建 |
| 前景失焦草 / 散景 / 暗角 / 颗粒 | `overlayCanvas`（全分辨率） | 尺寸变化时重建 |
| 辉光 | `glowCanvas`（约 115 万像素，0.30–0.58 倍） | 每帧重画 |
| 单元场 | `Float32Array(390×2)` + 3×3 模糊 | 每帧重建 |
| 萤火 | 13 个 `Float32Array(2200)` | 每帧更新相位 / 亮度 / 位置 |

- 目标 30 FPS；`dt` 上限 0.05s；画布像素预算 ≤ 260 万，`devicePixelRatio` 上限 1.5 并按面积回退。
- 每帧绘制调用实测 2800–5000：单元辉光 ≤ 390、萤火光斑 ≤ 2200、闪光拖尾 ≤ 2×闪光个体、亮核 ≤ 高亮个体、两次整屏合成 + 背景 + 前景。
- 单帧无全屏累积缓冲，所以长时间播放不会越来越亮。
- 实测离屏渲染：1920×1080 / 390×844 / 3440×1440 为 30 FPS，3840×2160（dpr 0.56）约 26–28 FPS。
- 所有随机数来自种子化 PRNG；网格、个体、风吹与初始抖动都由 `seed` 决定，`t` 决定相位与漂移。

## 9. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、开关微风与指针惊扰、换草坡、重新聚拢。
- 减少动态效果时默认静止；HUD 保持可见，提供手动播放入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 10. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 夏夜种子；固定后复现个体分布、尺寸、色彩与漂移相位 |
| `t=75` | 起始时间（秒）；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=6` | 播放态启动前额外回溯多少秒（0–8）；静止态直接用完整构图 |
| `breeze=0` | 关闭自动微风 |
| `touch=0` | 关闭指针惊扰与点按闪光 |
| `detail=0.6` | 降低萤火、星点与草叶密度（0.5–1） |

静态海报：`wallpaper.html?still=1&t=75&seed=20261111&hud=0`

## 12. 实现结构

```text
wallpapers/firefly-sync/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + Kuramoto 场）
├─ meta.json          标题、副题、描述、标签、强调色、排序

docs/design/firefly-sync.md   本设计文档
scripts/verify-firefly-sync.cjs  Node 模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、三角函数查表、工具函数；
2. 构图：三重山脊、谷口、草坡脊线、四个尺寸的布局常量；
3. 个体：分层采样、生命周期、解析漂移；
4. 相位场：网格累加、3×3 模糊、去滞后耦合、耦合呼吸、自动微风；
5. 静态层烘焙：夜空、星、远山、草坡、草叶纹理、灌木、前景、暗角、颗粒；
6. 每帧绘制：单元辉光、萤火光斑、拖尾、亮核、两次合成；
7. 主循环、指针交互、HUD、验证钩子。

运行时暴露调试入口 `window.__lumenFirefly`（快照、审计、推进、惊扰、点按、拖动、微风开关、重新聚拢、换草坡），供 `scripts/verify-firefly-sync.cjs` 使用；不参与视觉，不影响普通播放。

## 13. 验证计划

1. **Node 模拟**：`node scripts/verify-firefly-sync.cjs`
   - 四种尺寸各模拟 10 分钟：数量、网格上限、相位范围、绘制调用、生命周期替换、像素预算、镜头漂移上限。
   - 确定性复现（seed / t）、耦合呼吸（t=178 → K 0.40，t=628 → K 0.90）、R 随 K 起落。
   - 指针惊扰与恢复、点按闪光、拖动风与衰减、`breeze=0`、自动微风、暂停、隐藏、缩放、减少动态效果、URL 开关。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏 / 4K 截图，检查非空、尺寸、暗部比例、亮斑比例、暖色萤火比例、平均亮度。
   - 验证动画推进、指针惊扰、点按、暂停、缩放、面板、HUD、换草坡与重新聚拢、减少动态效果、种子复现。
   - `--write-preview` 时输出 `preview.png`，其余截图写入临时目录供人工复核。
3. **视觉复核**：逐张查看四种尺寸与静止构图，确认草坡脊线可读、谷口地平线可见、萤火聚在 (0.55w, 0.55h)、前景不遮挡主体。
