# 口袋乐园 · 昼夜嘉年华

一座可旋转观看的真实 3D 微缩游乐园。薄荷绿地台、中央水上乐园、珊瑚色设施和迎宾入口组成一枚桌面上的游乐场模型。园内不绘制道路，游客和花车依靠不可见的行为路线活动。所有模型与招牌均由程序生成，Three.js 随目录提供，不需要联网。

## 场景

- 摩天轮：十二个吊舱保持竖直，逐舱停靠底部上下客，乘客随原吊舱完成一圈。
- 过山车：四节载客车厢沿闭合起伏轨道行驶，车身跟随轨道坡度。每次运行 28 秒完成两圈，巡航速度约为初版的三倍，进出站平滑加减速。
- 旋转木马：条纹顶棚下的木马随平台旋转并上下起伏。
- 海盗船：带游客、船帆和弧形船身的往复摇摆设施。
- 大摆锤：摆臂往复运动，环形座舱同时旋转。
- 跳楼机：停站上下客后缓慢升高、顶部停留、快速下降，再回到底部。
- 水上滑梯：开放式弯曲滑道、楼梯、滑行泳圈、游客和落水处涟漪。
- 中央造浪池：56 位水中游客、彩色泳圈、起伏的水面和波峰线，游客随浪浮动；池畔有躺椅、遮阳伞和「造浪海湾」标牌。
- 表演花车：沿园内中部围绕水上乐园绕行，远离外围边界。车上有旋转舞台、跳舞小人、星形装饰、气球和彩灯。
- 环园小火车：独立外围轨道和三节载客车厢。
- 120 位园内游客在排队、上车、乘坐、离场、漫游、逛店和观看花车之间转换，采用固定人数的持续模拟；不是隐藏排队人物后另生成乘客。
- 八项载客设施各有一条单列先进先出短队，初始每队 4 人，最多 5 人；队满时游客先去别处活动。座位占用和停站上下客继续保留。花车附近的部分游客会停下、转向花车挥手，观看后继续活动。
- 9 家带中文招牌的小店：冰淇淋、棉花糖、柠檬茶、热狗屋、纪念品、爆米花、甜甜圈、咖啡屋、泳具店。
- 加宽的大门带摩天轮图形 logo、「口袋乐园」中文名称和英文副标题。
- 门前小广场有两位彩衣、红鼻子、尖帽子的小丑挥手迎宾，旁边配气球。
- 三台验票闸机配扫描提示和旋转闸杆；新到访游客共用一条短队，依次分配空闲闸机，停留验票后入园。少量游客游玩后回到接待区，使入口持续有人活动。
- 已移除园外公路、人行道、汽车和街边行人。
- 夜间分批发射烟火，包含升空、彩色绽放、下坠拖尾和淡出；白天不显示烟火。

这是用于壁纸的风格化模拟，已实现上下客、队列与座位归属，地面游客会绕开造浪池；不包含完整购票经济或全场景物理碰撞系统。

## 打开

直接打开本目录的 `wallpaper.html`。请保留旁边的 `three.min.js`。也可以在流光壁纸的本机壁纸库中找到「口袋乐园」后预览或应用。`preview.png` 来自实际渲染。

右下角「乐园设置」可选择昼夜流转、晴朗午后、落日时分和星灯夜游。默认 6 分钟完成一个昼夜，可切换 3 或 12 分钟；夜晚路灯、设施彩灯及局部照明逐渐亮起。游乐节奏只改变设施与游客的速度，不影响昼夜周期。

- 鼠标拖动：旋转视角与俯仰。
- 滚轮：缩放；「复位视角」恢复默认构图。
- 空格：暂停 / 继续。
- H：隐藏 / 显示界面。
- F：全屏 / 退出全屏。
- 标题在 14 秒后淡出；系统设置减少动态效果时默认暂停。

设置仅对当前页面生效。桌面宿主是否透传鼠标和键盘由宿主决定；可在预览窗口操作。

## URL 参数

| 参数 | 用途 |
| --- | --- |
| `light=auto` | `auto`、`day`、`sunset`、`night` |
| `cycle=360` | 昼夜周期，单位秒，60–3600 |
| `speed=1` | 游乐节奏，0.25–1.75 |
| `t=18` | 初始设施和昼夜时钟，0–86400 秒，默认 55；游客最多预演 180 秒以限制加载开销 |
| `still=1` | 暂停；`still=0` 显式播放并覆盖减少动态效果 |
| `hud=0` | 隐藏标题和控件，H 可恢复 |

例如 `wallpaper.html?light=night&hud=0` 为纯夜游壁纸。

## 运行与验证

需要 WebGL 和硬件加速。目标 30 FPS，像素倍率不超过 1.5，总渲染像素不超过约 260 万；页面隐藏时停止动画调度。静态几何按材质合并，重复的动态人物和车厢零件使用实例绘制。当前默认视角约 270 次主画面绘制调用。烟火使用固定 500 粒子池，游客人数固定；性能仍取决于设备和宿主。

```powershell
node scripts/verify-pocket-fairground.cjs --write-preview
```

验证使用 Electron 实际加载离线 `file://` 页面，覆盖白天、黄昏、夜晚、竖屏、超宽屏，完整昼夜周期、各设施位置变化、暂停继续、设置、静止时缩放窗口、减少动态效果和壁纸库扫描。另模拟六分钟检查排队、上车、离场、购物与花车观看事件、人物唯一性、座位与队列归属、单列队伍及每队五人的上限、验票入园持续发生、造浪池边界、花车内圈路线、过山车速度、夜间烟火和白天禁用烟火。截图写入 `temp/pocket-fairground/`（临时目录，不纳入版本控制）。这些检查不代表已在 Windows WebView2 桌面层实际挂载测试。
