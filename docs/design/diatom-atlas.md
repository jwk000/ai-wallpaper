## 1. 一句话概念

暗场显微镜下的一滴海水。八枚硅质骨架悬在圆形视场里，边缘被冷凝器的侧光擦出一圈冷光，内部半透明、孔阵精确；焦平面每八分钟走一个往返，孔洞随之忽而清晰、忽而化成光斑。偶尔有一枚从中间裂开，变成两枚更小的，小的再慢慢长回去。

它不是粒子 demo，也不是荧光屏保，而是一张**会自己继续观察的暗场铜版图鉴**。

### 设计原则

1. **先是一张图鉴，才是一个模拟。** 任何时刻截屏都要成立：圆形视场、黑底、中央一枚主角、两枚副个体、下缘两枚失焦前景。
2. **光只来自骨架。** 视场本身几乎全黑；所有亮度都长在壳缘、孔洞和气泡的膜上。没有体积光、没有泛光滤镜、没有塑料高光。
3. **清晰度是唯一的叙事。** 每枚个体只有一个 `z`，焦平面只有一个数值；两者之差决定它清晰、半虚还是化成光斑。观者看到的是"对焦"这件事本身。
4. **种群守恒，不重置。** 分裂只把一枚换成两枚更小的，总数封顶 8；漂移、旋转、对焦、分裂都是连续状态，没有"重播"。
5. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

### 唯一焦点与最惊艳的一秒

- **唯一焦点**：视场中央那枚中心辐射硅藻——最大的骨架、最完整的孔阵、最亮的一圈冷光。
- **最惊艳的那一秒**：它从中间裂开。亲本化成一枚正在消散的残影，两枚小壳沿随机轴分开，分裂点起一圈 1.6 秒的冷白闪光，然后整个视场回到安静。

### 2.2 色彩与光

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 视场外 | `#030405` | 纯黑，不画任何东西 |
| 视场底 | `#0b171c` → `#040708` | 中心略亮，边缘入暗 |
| 冷凝器光环 | `rgba(159,216,232,…)` | 视场边缘 0.86–1.0R 的一圈散射光 |
| 骨架冷光 | `#9fd8e8` | 壳缘与肋的主体光 |
| 骨架高光 | `#e8fbff` / `#ffffff` | 只出现在壳缘与孔的亮芯 |
| 骨架内部 | `#2a4a55` | 半透明硅质，加色叠加后读作暗青 |
| 暖黄个体 | `#d8a45e` / 高光 `#ffe0a8` | 全画唯一一处暖色 |
| 尘埃 / 划痕 | `#c8e4ec` @ 1–5% | 只比黑亮一点 |
| 强调色（meta） | `#7fb6c9` | 与 HUD、库内强调色一致 |

- **亮度分布**（1920×1080 实测）：暗部（L < 0.18）93–94%，中间调约 6%，高光（L > 0.55）0.3%，其中暖色像素 0.03%。高光只存在于壳缘、孔阵亮芯、气泡膜与分裂闪光。
- **暗场成像**：视场是一张中心略亮的径向渐变，加一圈贴着视场边的冷凝器光环；所有个体用 `lighter` 加色画在上面，因此"亮"是加出来的，不会把黑底洗灰。
- **色差**：每枚骨架的壳缘在 sprite 里多画两笔——一笔向 `+0.75%R` 偏移的红、一笔向 `−0.75%R` 偏移的蓝，透明度 17%，像一枚不完美的消色差物镜。
- **铜版感**：视场内最多 14000 粒 1px 颗粒（约 `w·h/210`，2–9% 不透明度）、26 条极淡划痕、144 条刻环刻度、罗马数字与 50 µm 比例尺。这些都在尺寸变化时一次性烘焙，不参与逐帧。

| 前景 | 2 枚大幅失焦个体（横屏 0.46R / 0.30R，竖屏 0.33R / 0.22R，清晰度上限 0.12）+ 一颗气泡 | 每帧变换 + 合成 |

- 中景是唯一可能清晰的层；远景与前景被强制虚化，即使焦平面扫过它们的 `z` 也不完全清晰——这是"景深分层"的手段，不是 bug。
- 前景两枚中较大的一枚直径约 0.9 个视场半径，被圆形视场裁掉一截，压住下缘两角。
- 覆盖层永远在最上面，所以刻环与比例尺不会被骨架盖住。

## 3. 骨架几何

### 3.1 五类硅质壳

每枚个体的形状由 `species` 与种子化随机数决定，全部在归一化极坐标里生成，再缩放到 `rFrac × fieldR`：

| 类型 | 轮廓 | 内部结构 | Path2D 命令数 |
| --- | --- | --- | --- |
| `centric` 中心辐射 | 近似正圆，半径带 3/5/9 次谐波扰动 | 12 条壳缘短肋、6 条辐条、36 条径向孔行 + 3 圈同心孔环 | 153 |
| `pennate` 羽纹 | 两端收尖的船形，宽长比 0.34–0.41 | 13 条横肋 + 1 条壳缝、8 条斜刻线、5 条纵向孔行 | 123 |
| `triradiate` 三辐射 | 圆角三角形，3 次谐波 | 3 条辐条 + 6 条短肋、6 条内刻线、18 条孔行 + 2 圈孔环 | 131 |
| `stellate` 星形 | 7 臂，臂长带 3 次谐波调制 | 7 辐条 + 7 短肋、7 条臂孔行 | 124 |
| `bipolar` S 形 | 两端尖的 S 形长椭圆 | 15 条斜刻线 + 13 条反向排线 + 1 条中缝、4 条纵向孔行 | 129 |

- 每条轮廓 64 个点，内环取隔点采样的 32 个点（缩到 0.905）；所有路径都缓存成 `Path2D`。
- `segments`（验收用）= 轮廓点 + 内环点 + 肋 + 刻线 + 孔行；实测最大 153，预算 ≤ 400。
- 骨架在尺寸变化或新生时渲染成 sprite；形状本身不变，长大只是缩放 sprite。

### 3.2 孔阵：一条虚线画几百颗孔

条目要求"孔阵是精确的数学结构"，同时"每枚 ≤ 400 段 `Path2D`"。逐颗画圆会立刻用掉几百条命令，也无法画出真实的孔密度。做法：

- 把孔行组织成一个 `Path2D`：中心辐射是 36 条从 `0.10R` 到 `0.93R` 的径向线 + 3 圈同心圆；羽纹是 5 条纵向线；三辐射是 18 条径向线 + 2 圈；星形是 7 条沿臂的线；S 形是 4 条纵向线。
- 渲染时用 `lineCap = 'round'` + `setLineDash([0.007R, 0.043R])` 描两遍：宽而暗的一遍做孔缘，细而亮的一遍做孔芯。几千颗孔只花几十条命令。
- 孔行被 `clip()` 收在轮廓里，所以三角形、星形、船形的孔阵自然贴着壳形结束。
- 虚焦时孔阵随 sprite 一起模糊；另取 12 个壳内采样点作为 bokeh 锚点，越虚斑点越大越亮——"孔洞化成光斑"就是这 12 个点。

### 3.3 对焦与景深

- 焦平面：`focus = 0.5 + 0.2 · sin(2π t / 480 + φ)`，周期 480s（8 分钟一个往返），范围 0.30–0.70。
- 每枚个体有 `z`（0.12–0.98）。清晰度 `s = clamp(1 − |z − focus| × 3.2, 0, 1)`；远景层 `s ≤ 0.34`，前景层 `s ≤ 0.12`。
- 每枚个体预渲染两张 sprite：清晰版，以及用一次 `ctx.filter = 'blur(R × 0.085)'` 烘焙的模糊版（不在每帧做滤镜）。逐帧按 `s` 交叉淡入两张，外加：
  - 模糊版按 `1 + (1 − s) × 0.42` 放大，表现焦外扩散；
  - `s < 0.32` 时沿轮廓再勾一圈焦外亮环（0.04–0.115 透明度）；
  - `s < 0.86` 时撒 12 个预采样 bokeh 光斑，半径与亮度随虚焦加深。
- 手动对焦：滚轮、上下拖动、`↑`/`↓` 改变 `focusOffset`（限 ±0.42）。自动对焦开着时，14 秒无输入后偏移按 22s 时间常数回落，8 分钟的往返继续；关掉自动对焦则停在 `0.5 + offset`。
- 视场里永远至少有一枚可读的骨架：`z` 从 0.30 到 0.70 都有个体，焦平面扫到哪里都有东西进入焦点。

### 3.4 漂移、旋转与环绕

- 位置是时间的**纯函数**（不做积分），因此静止帧可以在任意 `t` 直接求出：
  ```
  u = u0 + A1·sin(ω1·t + p1) + A2·sin(ω2·t + p2) + driftU·t
  v = v0 + B1·sin(ω3·t + p3) + B2·cos(ω4·t + p4) + driftV·t
  u,v ∈ [−1, 1]（视场半径为 1），用 u − 2·round(u/2) 环绕
  ```
  中景个体的振幅 0.02–0.05、线性漂移 ±0.00035/s（10 分钟约 0.2 个视场半径）；远景 / 前景漂移 ±0.0006/s，更自由。
- 越靠近视场边缘越淡：`alpha = 1 − smoothstep(0.80, 1.04, √(u²+v²))`。出画后在方形域的另一侧淡入，视觉上就是"从对侧出现"。
- 台面漂移：`u += 0.010·sin(2πt/211) + 0.004·sin(2πt/97)`，`v` 用 173s / 79s 两个周期；另有 `1 + 0.007·sin(2πt/240)` 的呼吸缩放。视场与刻环不动，动的只是里面的一滴海水。
- 自转：每枚骨架 `angle = angle0 + spin·t + wobble·sin(ωt + p) + slideAngle`，`spin` 在 ±0.01 rad/s，约 5–20 分钟一圈；`slideAngle` 是用户拖动载玻片的角度，可正负无限旋转并归一化到 (−π, π]。
- 手动推水：点击处以 0.9R 为半径、`(1 − d/0.9R)^1.6` 衰减给每枚个体一个冲量（最大约 34 px/s，按个体大小加权）；位移按 26s、速度按 4.6s 指数衰减，约两分钟被漂移吸收。

### 3.5 分裂与种群

- 一次分裂（自动或手动）：
  1. 亲本从种群中移除，留下一枚 1.01 秒的残影（按 `(1 − age/life)^1.4` 淡出）；
  2. 在亲本位置沿随机轴两侧各偏 `0.34R` 放下两枚子体，目标半径 `0.8 × 亲本半径`，`z` 在亲本附近 ±0.03 抖动；
  3. 子体 `born = 分裂时刻`，半径按 `0.56 + 0.44·(1 − e^(−age/110))` 长大，约 6 分钟长到 80%；
  4. 分裂点起一圈 1.6 秒的闪光（0.55R 扩到 2.95R，亮度按 `(1−u)²` 衰减）；
  5. 若个体数超过 8，淘汰"最不重要"的一枚：优先背景层，其次最小的（2.6 秒淡出成残影）。**个体总数严格守恒在 8。**
- 自动分裂：间隔 `360 + 240·rng()` 秒（6–10 分钟），由 `seed` 决定；`split=0` 关闭。静态图（`still=1`）会按调度把 `t` 之前的分裂逐一回放，因此 `t=2400` 的静止帧与连续播放 40 分钟的结果一致。
- 手动分裂消耗同一条随机流，但不改变自动排程的时间。

### 3.6 载玻片细节

- **气泡**：常驻虚焦的一颗，半径 0.085R，位置随台面漂移并做 0.031 rad/s 的轻微摆动；画法是"边缘亮、中心几乎透明"的径向渐变 + 一段高光弧 + 一点蓝色错位，模拟气泡膜的干涉色。
- **划痕**：26 条，其中 5 条较长，24% 的概率带弯曲；透明度 1.2–4.2%。
- **尘点**：120 粒，亚像素大小，透明度 1.4–6.4%。
- **颗粒**：`min(14000, w·h/210)` 粒 1px 点，2–9% 不透明度，只在视场内。
- **刻环**：视场外 1.006R / 1.048R 两道细环、144 条刻度（每 2.5° 一条，15° 加长，45° 最长）、8 个罗马数字、四角定位标记、底部 50 µm 比例尺。

| 操作 | 行为 | 自动兜底 |

- **拖动轴锁定**：按下后第一次移动超过 7px 时，若横向位移大于纵向的 1.2 倍就进入"旋转"，否则进入"调焦"；一次拖动只做一件事，避免两种交互互相干扰。
- **指针移出**：取消拖动，不留下未完成的手势。
- 桌面宿主收不到鼠标时，上述所有自动行为照常，画面完整且可长时间观看。

## 5. 循环与时间

- 不做整体重置：位置、角度、分裂次数、残影、气泡都是连续状态。
- `480s`：焦平面一个完整往返（8 分钟）。
- `6–10 min`：自动分裂；单次分裂的残影 1.01s、闪光 1.6s、子体长大 6 分钟。
- `211s / 173s / 240s / 97s / 79s`：台面漂移与呼吸缩放的五个互不相同的周期。
- `5–20 min`：单枚骨架自转一圈。
- `2.6s`：淘汰个体的淡出；`3.2s`：推水涟漪；`1.6s`：分裂闪光。所有瞬时效果都有年龄上限，没有累积缓冲。
- 页面隐藏时停止调度；恢复时重置时间戳与累加器（时间本身连续，不跳帧）。

## 6. 渲染与性能

### 分层

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 视场 / 划痕 / 尘点 | `bgCanvas`（设备分辨率） | 尺寸变化时重建 |
| 暗角 / 刻环 / 刻度 / 数字 / 比例尺 / 角标 / 颗粒 | `overlayCanvas`（设备分辨率） | 尺寸变化时重建 |
| 每枚骨架 | `sharp` + `blur` 两张 sprite（≤ 1400px） | 尺寸变化或新生时重建；长大只缩放 |
| 个体 | 参数化位置/角度（纯函数） | 每帧计算 |
| 气泡 | 2 个径向渐变 | 每帧重画 |
| 闪光 / 涟漪 / 残影 | 小数组（≤ 4 / ≤ 3 / ≤ 3） | 每帧按年龄重画 |

### 预算

- 目标 30 FPS：`requestAnimationFrame` + 33ms 累加器，每个显示帧只累计，攒够一帧才 `update + render`；实测 Node 端 60Hz 回调 2.0 秒渲染 60 帧，Electron 离屏 1920×1080（禁用 GPU）约 29.9 FPS。
- 画布像素预算 ≤ 260 万；`dpr = min(devicePixelRatio, 1.5, √(2.6e6/(w·h)))`。实测：1920×1080 → 1.12（260 万）、390×844 → 1.5（74 万）、3440×1440 → 0.72（257 万）、3840×2160 → 0.56（260 万）。
- 个体 ≤ 8、残影 ≤ 3、闪光 ≤ 4、涟漪 ≤ 3；每枚骨架 ≤ 400 条 `Path2D` 命令（实测最大 153）。
- 每帧的绘制调用：1 次背景 `drawImage`、8–11 次骨架 `drawImage`（每枚 1–2 张）、≤ 132 次 bokeh 小图、1 次气泡、1 次覆盖层，以及少量闪光/涟漪。逐帧不做滤镜、不做全屏模糊、不重建路径。
- 大块开销都在"事件"上：尺寸变化重建背景/覆盖层与全部 sprite；分裂时新建 2 张 sprite（每张 ≤ 1400px，一次性 blur）。自动分裂 6–10 分钟一次，可以接受。

## 7. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、调焦、分裂；HUD 隐藏不影响场景。
- 减少动态效果时默认静止；HUD 保持可见，提供播放入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 8. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 载玻片种子：骨架、个体位置、漂移相位、分裂时刻 |
| `t=0` | 起始时间（秒，0–86400）；同一 `seed` 与 `t` 渲染同一帧；`t` 之前的自动分裂会回放 |
| `focus=0.44` | 固定焦平面（0.02–0.98），忽略自动往返与手动偏移 |
| `split=0` | 关闭自动分裂 |
| `autofocus=0` | 关闭自动对焦，焦点停在 0.5 + 手动偏移 |

静态海报：`wallpaper.html?still=1&t=0&seed=20261111&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 13. 已知取舍

- 个体数守恒在 8 意味着"一大变两小"之后总会有一次淘汰；淘汰优先选背景层，视觉上像是它漂出了视场，不会突然消失。
- 背景层永远虚焦（≤ 0.34），因此当焦平面扫到它的 `z` 时它也只是"比较清楚"，不会完全实焦。这是景深分层的代价。
- 孔阵密度受 `R` 与 `dpr` 制约：竖屏小个体（R ≈ 54px）的孔会合并成细纹，不再是一颗颗独立的孔；这是分辨率下的自然降级，不是刻意简化。
- 圆形视场在横屏会裁掉视场的上下弧，刻环顶部的罗马数字因此只在两侧可见；竖屏能看到完整的刻环。
