# 雨窗 · 夜行列车

一扇雨夜列车车窗：青蓝色远山、河岸村落、暖色灯光倒影与掠过的电线杆。玻璃上的雨滴折射窗外景物，汇合后变大、加速，留下细长水痕。车厢顶灯轻轻映在玻璃上。

列车经过轨道接缝时有轻微颠簸，叠加悬挂回弹和缓慢侧倾。迎面气流把雨滴向画面左下方吹斜，阵风改变滑落角度，水滴和水痕跟随运动方向；进入隧道后风力减弱。近处草丛、树木、电线杆和桥栏带有随车速增强的横向运动模糊，远山之间叠加更厚的雾气。

所有画面都由 Canvas 2D 程序绘制，没有图片、视频、字体或网络依赖，也没有音频。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「雨窗 · 夜行列车」并预览、应用。`preview.png` 是实际渲染截图。

- 右下角「旅途设置」：调整雨量、车速，或固定观看河岸、大桥、林地、隧道。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 开场文字约 14 秒后淡出；设置按钮保持低亮度，悬停或键盘聚焦时显示。
- 雨量调到零后停止生成新雨滴，已有雨滴继续沿玻璃滑落。
- 系统启用「减少动态效果」时默认静止，可手动继续播放。

自动旅程每 180 秒安排一次河岸 → 大桥 → 林地 → 隧道 → 河岸的环境转换，使用柔和过渡。窗外地形和房屋按照持续前进的世界坐标生成，不在切换环境时重置位置。默认车速为 1.5 倍，可调到 3 倍；车速同时影响接缝颠簸的频率、迎面风力与近景模糊，雨滴重力仍按自然时间运动。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题和设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` | 静止画面 |
| `still=0` | 显式播放，覆盖系统减少动态效果设置 |
| `t=80` | 初始场景时间，单位秒；默认 18，范围 0–86400 |
| `rain=1` | 雨量，范围 0–2 |
| `speed=1.5` | 车速，默认 1.5，范围 0.25–3 |
| `route=auto` | `auto`、`riverside`、`bridge`、`forest` 或 `tunnel` |
| `seed=72` | 雨滴随机种子；固定种子可复现初始玻璃效果 |

静态桥梁取景：`wallpaper.html?still=1&t=80&hud=0`。

固定河岸播放：`wallpaper.html?route=riverside&rain=1.4&speed=0.75&hud=0`。

`t` 设置场景位置和沿途环境；雨滴单独预演 3 秒，让静态取景也有自然水痕，并不重放从零到指定时间的全部雨滴模拟。设置只影响当前页面，长期预设可写入 URL。

## 运行预算

- 动画目标为 30 FPS，实际帧率取决于设备与宿主。
- 每张画布最多约 260 万渲染像素，像素倍率上限 1.5。
- 活动雨滴最多 240 个，每滴最多保留 18 个水痕节点；合并使用空间网格查找邻居。
- 静态细小凝水缓存到独立画布，避免每帧重复绘制。
- 页面隐藏时取消动画调度；恢复后重置时钟，避免后台时间造成突然跳跃。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-train.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-train.cjs --write-preview
```

脚本在四种尺寸下分别模拟 10 分钟，检查雨滴数量、数值稳定性、汇合、流出、路径长度、路段边界和隐藏页面调度。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查横屏、竖屏、超宽屏、桥梁与隧道渲染、动画更新、暂停与恢复、控件、减少动态效果、窗口缩放、离线运行，以及壁纸库的元数据与预览识别。

Electron 截图写入系统临时目录 `lumen-rainy-night-train-check/`。这些检查不等同于 Windows 原生 WebView2 桌面挂载测试。
