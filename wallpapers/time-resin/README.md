# 时间的树脂 · Amber, Keeping Time

气泡、植物残片和晶体悬浮在琥珀中，每一分钟活跃运行都会沉积一层日夜色泽，留存在本机。

这是一幅独立壁纸。打开本目录的 wallpaper.html 即可离线播放，也会作为独立条目被流光壁纸自动扫描。无外部字体、图片、音频或网络依赖。

- H：打开或关闭设置；空格：暂停或继续；E：晶体闪光；R：变换构图。
- 设置中可调流速和画质。系统“减少动态效果”默认显示静帧，可手动继续。页面隐藏时停止绘制，暂停及静帧状态调整窗口仍会重绘。
- 特殊事件也会按各作品的时间节奏自然出现。暂停时触发会显示事件中段；播放时触发从头开始。
- 支持 ?seed=42&t=30&still=1&hud=0&quality=low 参数；t 为动画秒数，still=0 可明确启用动画。
- 画布最多约 260 万像素（节能 120 万），目标 30 FPS；不依赖帧数推进动画。

琥珀使用本地存储记录真实活跃运行秒数，每分钟沉积一层；保留最近 240 层及累计时间。暂停、隐藏与关闭期间不计时，调速不改变沉积速度。文件路径或浏览器资料变化会形成不同的记录；存储不可用时继续运行并在设置中提示。变换构图保留时间记录。

源代码：scripts/dream-atlas/time-resin.js 与 runtime.js；运行 node scripts/dream-atlas/build.cjs 重新生成单文件 HTML。运行 node scripts/verify-dream-atlas.cjs 验证；加 --capture 更新预览和在线馆素材。
