## 1. 一句话概念

暗房里，一块被照亮的空气切片。风没有形状，但长曝光把它显影成十几条发光的银盐丝带；铁屑沿着同一套流线排成细小的短划，像磁场里刚刚落定的方向。指针划过，空气里留下一个慢慢散开的涡旋；什么都不做时，每 20–40 秒会有一阵自动的阵风经过。

它不是风洞演示，也不是粒子烟花，而是一张**会自己继续显影的银盐照片**。

### 设计原则

1. **先是一张好壁纸，才是一个流场。** 任何时刻截屏都要成立：左侧有来向，右上留出风去的方向，暗部干净，丝带不糊成一团。
2. **运动来自流场，不来自滤镜。** 丝带与铁屑都在同一张 64×36 速度网格里被输运；琥珀色只出现在真实速度最高的段落。
3. **慢，且不重复。** 丝带生命周期 30–60 秒，阵风 20–40 秒一次，流场相位缓慢旋转；没有全局重置，长时间播放不越积越亮。
4. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

- **横向 16:9**：丝带的视觉重心在 `(0.35w, 0.45h)`；12 条丝带从左侧 1/4 进入，向右上散开。画面右侧 18–22% 作为「风去的方向」留白，丝带在该区域逐渐减淡，不硬切。
- **竖向 390×844**：气流改为自下而上。视觉重心在 `(0.50w, 0.45h)`；丝带从底边 1/4 升起，向顶部消散；横向铺开收窄到 0.7w，避免在窄屏上像横放的乱线。
- **超宽 21:9**：沿用横向构图，重心略左移到 `0.36w`，丝带更舒展；最外侧的 2–3 条允许从上下出画。
- **边框感**：不做画框。用四角暗角、边缘消隐和一层离焦前景收边，保持全幅、无缝。

### 2.2 色彩与光

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 底色 | `#0e0e10` → `#242426` | 中心略亮，四角入暗 |
| 丝带主体 | `#d8d3c8` | 银盐灰白，95% 的画面靠它 |
| 受光边 | `#d08a3e` | 只出现在速度最高的段落；全部暖色像素约 0.5–2%（含暗房光） |
| 铁屑 | `#b9b3a7` | 比丝带暗一档，短划状 |
| 网格 / 刻度 | `#9d978c` | 透明度 2–11%，只在暗部可见 |
| 强调色（meta） | `#b8865a` | 与 HUD、库内强调色一致 |

- **亮度分布**：约 82–84% 像素落在暗部（L < 0.18）、16–18% 中间调、0.2–0.5% 高光。高光只出现在丝带核心、受光边和少量铁屑上，背景保持压暗。
- **银盐黑白**：整体饱和度低于 8%；除受光边与极少量暖灰外，全部走冷灰阶。
- **长曝光**：丝带用加色混合叠出柔边和亮芯；柔光先画进 0.4× 的离屏缓冲，再放大合成，得到光学晕边而不是硬描边。每条丝带的顶点数固定为 60，不使用累积型全屏缓冲，因此不会越跑越亮。
- **空气切片**：背景用径向渐变加边缘消隐，让画面像从一整块黑暗中切出来的一小片被照亮的空气。

### 2.3 层次

| 层 | 内容 | 更新 |
| --- | --- | --- |
| 背景 | `#0e0e10`–`#242426` 径向渐变、极淡网格与刻度、暗房灰尘、确定性银盐颗粒 | 尺寸变化时烘焙 |
| 中景 | 8–12 条丝带、300 枚铁屑、480 枚尘埃、流场本身 | 每帧 |

- 中景是唯一清晰层；背景只有细线与颗粒；前景全部离焦、透明度低于 10%，不遮挡丝带主体。
- 网格间距约 `min(w,h)/14`，主刻度每 4 格加深一次；不做可见的坐标数字，保留实验室的暗示即可。

## 3. 流场模型

### 3.1 坐标与速度

- 所有流场计算使用**屏幕像素坐标**，噪声频率按 `min(w,h)` 归一化，因此在横屏、竖屏和超宽屏上各向同性。
- 基础风：

```
landscape / ultrawide:  wind = normalize( 0.96, -0.28)   // 右上
portrait:               wind = normalize( 0.06, -0.998)  // 向上
baseSpeed = min(w, h) * 0.105                            // px/s
```

- 在基础风上叠加 **3 个倍频的 curl noise**：

```
psi_i = sin( k_i * (cos(a_i) * x + sin(a_i) * y) + omega_i * t + phi_i )
vx   += baseSpeed * w_i * sin(a_i) * cos(psi_i)
vy   += -baseSpeed * w_i * cos(a_i) * cos(psi_i)
a_i   = a_i0 + rot_i * t                  // 波矢缓慢旋转
k     = [5.8, 11.5, 22.0]
w     = [0.55, 0.32, 0.16]
omega = [0.180, -0.320, 0.620]
rot   = [0.020, -0.030, 0.050]
```

- 再叠加一组**沿风向传播的阵风带**：速度以约 5.5s 的周期起伏，像一阵一阵推过画面；再叠一层**横向高频抖动**（约 3.7s 周期），给丝带细碎的颤动。
- 三组倍频、阵风带与横向抖动都由 `seed` 与 `t` 驱动，组合周期远大于单次观看时长；不做整体重置。
- 风场先采样到 **64×36 网格**，粒子位置用双线性插值读取。网格每 0.2 秒重建一次；指针涡旋在采样时局部叠加，因此交互始终是即时反馈。

### 3.2 阵风

- 自动阵风每 `20–40s` 一次，由种子化序列决定；`gust=0` 关闭。
- 单次阵风持续 `6–9s`，包络为 `sin(πu)^1.5`，沿基础风方向把速度提高到约 2.1 倍，并叠加一点横向波动；最多同时存在 2 股。
- 阵风期间丝带速度上升，受光边的琥珀色自然出现在这些段落；阵风结束后颜色回落。事件本身不改变构图。

### 3.3 指针涡旋

- 指针是半径 **120px** 的涡旋源。涡旋强度 `energy` 由指针移动速度累积；按住拖动目标强度为 1，松手后按时间常数约 2.0s 衰减，**8s 内低于 2%**。
- 局部速度：

```
d = distance(p, pointer)
f = (1 - d / 120)^2 * energy * 420 px/s
v += (-dy/d, dx/d) * f + (dx/d, dy/d) * f * 0.18
```

- 涡旋同时作用于丝带头部、铁屑与尘埃；绘制丝带时对经过涡旋的点施加一个很小的切向位移，因此已经显影的丝带也会在指针附近轻微弯折，随 `energy` 衰减而复原。
- 按住拖动会持续增强；双击清空为一张静止构图（暂停 + 重新生成丝带与铁屑）。

## 4. 丝带

### 4.1 结构

- 12 条丝带，每条 60 个顶点，从尾部（旧）到头部（新）排列。顶点携带位置与该段的历史速度，用于决定线宽和琥珀受光边。
- 每条丝带的目标轨迹长度在 `0.55–1.15 × 布局长度` 之间波动；1920×1080 的布局长度约 925px，实际可见轨迹约 500–1060px。画面里读到的是约 5–10 秒的长曝光，而不是一条短拖尾。
- 生命周期 `30–60s`。头部跑出画面、或寿命耗尽时，不瞬间消失：先进入约 1.6s 的「定影」淡出，再从对侧（横屏左侧、竖屏底边）重生。
- 出生后 2s 淡入，死亡前 4s 淡出；任意时刻可见丝带 8–12 条。竖屏的头部整体下移，让上升气流的亮头避开标题区。

### 4.2 形状与笔触

- 头部每帧按当地流场前进；尾部按累计弧长裁掉，再重采样为固定 60 点。段数永不增长。
- 线宽：柔边更宽但透明度很低，主体约 2–9px，亮芯约 0.5–3.6px；丝带沿长度向两端收窄。速度越高的段落，亮芯越细越亮；慢速段落更宽、更灰，像银盐堆积。
- 每条丝带分四层笔触：
  1. **柔光**：画进 0.4× 离屏缓冲后放大合成，给出真实的晕边；
  2. **外主体**：银灰 `#d8d3c8`，很低的透明度，决定丝带的总宽度；
  3. **内主体 + 亮芯**：逐级收窄、提亮，形成银盐堆积的截面；
  4. **高光**：一条极细的偏移白线，只负责“刚曝光完”的那点亮。
- **虚线曝光**：亮芯用约 7–9px 的虚线画出，虚线沿丝带缓慢流动；主体仍是连续的银灰，因此像被风撕开的曝光，而不是一根实线。
- **受光边**：仅在段落速度超过阈值时，沿丝带一侧偏移约 `0.56 × 丝带基宽`（约 1.3–4.5px）画一条更细的琥珀线；一场阵风过去，会在丝带上留下几段短暂的暖色。
- **端部消散**：尾部最后 10–15% 的点逐级降低透明度，并在附近撒 1px 的确定性颗粒；头部保留一个 2px 的亮点，像曝光刚停住的地方。
- 右侧留白区（横屏 `x > 0.82w`、竖屏顶部 `y < 0.065h`）的段落透明度逐级降到 0，避免丝带顶到画框。

### 4.3 初始帧

- 启动时，丝带不是从零开始长：从种子化的头部位置沿**时间反向的负流场**回溯（每一步读取略微更早的流场相位），直接生成一条完整的长曝光轨迹；因此头部固定、轨迹会随 `t` 改变。
- 头部位置、线宽、透明度、寿命与相位由 `seed` 决定；流场相位由 `t` 决定。因此同一 `seed` 与 `t` 两次加载得到同一帧，静止截图也有完整构图。
- 12 条丝带的头部在画面内分散排布，不等待预热时间。

## 5. 铁屑

- 300 枚铁屑，沿流线分布：约 60% 在丝带轨迹附近抖动生成，40% 在画面内均匀撒开。
- 每枚铁屑是一个 `5–11px` 的短划，方向取当地流场方向；颜色为冷灰 `#c6c0b4`，透明度按 3 档分桶为 20% / 42% / 46%。
- 每帧用同一张速度网格推进；出画后从入风边重新生成，数量恒定。
- 约 18% 的铁屑固定带一点暖色，与丝带受光边呼应；其余保持中性灰。
- 另有 480 枚更细的尘埃（`detail` 可降低）：以约 1.3 倍流速沿流场推进，画成 1.4–4.8px 的短划；它们是“空气在动”的主要线索。
- 铁屑与尘埃不进入前景，不遮挡丝带亮芯。

## 6. 交互

| 操作 | 行为 |
| --- | --- |
| 指针移动 | 以移动速度累积涡旋强度，半径 120px；丝带与铁屑被卷向切线方向 |
| 按住拖动 | 涡旋目标强度升到 1，松手后约 8s 内衰减到 2% 以下 |
| 双击画面 | 清空涡旋、重新生成丝带与铁屑，并停在一张静止构图上 |
| `Space` | 暂停 / 继续；暂停时仍响应缩放与涡旋重绘 |
| `H` | 隐藏 / 显示 HUD；开场 16s 后自动淡出 |
| `F` | 全屏 / 退出全屏 |
| 设置面板 | 暂停、全屏、自动阵风、指针涡旋、清空构图、重新播种 |

- 桌面宿主收不到鼠标时，自动阵风、丝带重生和流场旋转照常运行，画面依然完整。
- 涡旋只在实际有指针输入时出现；没有输入时不留一个静止的圆圈。

## 7. 循环与时间

- 不做整体重置：流场相位、丝带年龄、铁屑位置都是连续状态。
- `20–40s`：自动阵风；单次持续 6–9s。
- `30–60s`：单条丝带寿命；出画或寿终后淡出并重生。
- `8s`：指针涡旋从满强度衰减到不可见的时间上界。
- `360s`：±1% 的镜头缩放呼吸（周期 6 分钟）。
- 约 5.5s：阵风带扫过；约 3.7s：横向抖动。三组倍频的相位旋转周期也互不相同，画面在数十分钟内不会重复。
- 页面隐藏时停止调度；恢复时重置时间戳，避免后台时间造成跳帧（时间本身连续）。

## 8. 渲染与性能

### 分层

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 背景 / 网格 / 刻度 / 灰尘 | `bgCanvas`（全分辨率） | 尺寸变化时重建 |
| 暗角 / 前景离焦 / 颗粒 | `overlayCanvas`（全分辨率） | 尺寸变化时重建 |
| 速度场 | `Float32Array(64×36×2)` | 每 0.2s 重建 |
| 柔光 | `softCanvas`（0.4× CSS） | 每帧重画，放大合成 |
| 丝带 | 顶点数组 | 每帧更新 12×60 |
| 铁屑 | 位置数组 | 每帧更新 300 |
| 尘埃 | 位置数组 | 每帧更新 480 |
| 前景尘埃 | 4–5 个渐变精灵 | 每帧轻移 |

### 预算

- 目标 60 FPS，逐帧渲染（`dt` 上限 0.05s）；30 FPS 是最低验收线。
- 画布像素预算 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退。
- 丝带 12 条 × 60 段 = 720 段（硬上限）；铁屑 300；阵风 ≤ 2；无累积型全屏缓冲。
- 每帧约 550–650 次绘制调用：12 条丝带各 4 个长段（每段 4 笔）+ 约 6 个细节块、300 枚铁屑与 480 枚尘埃各压成几条批量路径、1 次柔光放大、1 次背景、1 次覆盖层、少量前景与涡旋指示。
- 速度场 64×36 每 0.2s 重建，粒子读取为双线性插值；不在每帧重算全屏噪声。
- 实测离屏渲染（禁用 GPU）：1920×1080 约 50–60 FPS，p50 帧间隔 16.7ms；实际宿主启用 GPU 时通常更快。
- 丝带、铁屑、尘埃的速度都做约 0.12s 的指数平滑，避免 5Hz 网格重建造成方向跳变。
- 页面隐藏时 `cancelAnimationFrame`，恢复时重置时间戳；`prefers-reduced-motion` 默认静止。
- 所有随机数来自种子化 PRNG；网格、丝带初值、铁屑、阵风时刻都由 `seed` 决定，流场相位由 `t` 决定。

## 9. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、开关阵风与涡旋、清空构图、重新播种。
- 减少动态效果时默认静止；HUD 保持可见，提供手动播放入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 10. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 暗房种子；固定后复现丝带初值、铁屑与阵风时刻 |
| `t=60` | 起始时间（秒）；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=10` | 播放态启动前额外回溯多少秒的流场相位（0–30）；静止态直接使用完整回溯构图 |
| `gust=0` | 关闭自动阵风 |
| `vortex=0` | 关闭指针涡旋 |
| `detail=0.6` | 降低铁屑、尘埃、颗粒与刻度密度（0.55–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=60&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 12. 实现结构

```text
wallpapers/wind-development/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 流场）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、流场规则、交互、URL 参数、验证说明

docs/design/wind-development.md   本设计文档
scripts/verify-wind.cjs           模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、工具函数、构图；
2. 流动模型：基础风、curl noise、阵风带、横向抖动、64×36 网格、阵风、指针涡旋；
3. 静态层烘焙（暗房、网格、刻度、颗粒、前景离焦、柔光缓冲）；
4. 丝带生成、推进、裁切、重生；
5. 铁屑、尘埃生成与推进；
6. 每帧绘制（丝带、铁屑、尘埃、涡旋、前景）；
7. 主循环、输入、HUD、验证钩子。

运行时暴露调试入口 `window.__lumenWind`（快照、推进、涡旋、阵风、清空构图、重新播种），供 `scripts/verify-wind.cjs` 使用；不参与视觉，不影响普通播放。

## 13. 验证计划

1. **Node 模拟**：`node scripts/verify-wind.cjs`
   - 四种尺寸各模拟 10 分钟，检查丝带/铁屑数量、顶点数、坐标有限、速度上限、阵风次数、生命周期、缩放与像素预算。
   - 检查确定性复现、竖屏上升气流、涡旋增强与衰减、`vortex=0` / `gust=0`、阵风事件、清空构图、暂停、隐藏、缩放、减少动态效果与 URL 开关。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏 / 4K 截图，检查非空、尺寸正确、亮度分布、无控制台错误与网络请求。
   - 验证动画推进、暂停、暂停时缩放、指针涡旋、双击清空、HUD、面板、阵风、减少动态效果、种子复现。
   - `--write-preview` 时输出 `preview.png`，其余截图写入临时目录供人工复核。
3. **视觉复核**：逐张查看四种尺寸与静止构图，确认丝带可读、右侧留白成立、琥珀只在受光边、前景不遮挡主体。
