# 深空监听站

荒原尽头的一座射电监听站：抛物面天线朝着天顶缓慢扫过，星轨绕着天极转；每隔几分钟，某一段噪声忽然有了形状，天线转过去，前景接收机的波形亮起来。

整幅画面由 Canvas 2D 程序绘制，没有图片、视频、字体、音频或网络依赖。星表、银河、山脊、碎石、草、信号时刻都由 `seed` 决定；同一 `seed` 与 `t` 会得到同一帧。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「深空监听站」并预览、应用。`preview.png` 是实际渲染截图。

- **拖动画面**：手动调整天线方位 / 俯仰；松手后保持 2.5 秒，再用约 6 秒回到自动扫描。
- **← / →**：方位角 −2° / +2°；**↑ / ↓**：俯仰角 +1.5° / −1.5°。
- **L**：锁定当前指向 30 秒；再按一次提前解除。锁定期间忽略自动扫描与信号转向。
- **Space**：暂停 / 继续；**H**：隐藏 / 显示 HUD；**F**：全屏 / 退出全屏。
- 右下角「监听设置」：暂停、全屏、自动扫描、自动信号、锁定 30 秒、重新播种。
- 开场文字约 16 秒后淡出；设置按钮保持低亮度，悬停或键盘聚焦时显示。
- 系统启用「减少动态效果」时默认静止，设置面板和右下角的「播放」按钮可以手动开始。

桌面宿主收不到鼠标时，自动扫描、自动信号与波形照常运行；所有交互都有对应的自动行为。

## 天空与星轨

- 天极固定在画面偏上位置，星表围绕它旋转；完整一圈约 4 小时。这个速度比真实星空快约 6 倍，为的是在 10 分钟曝光里得到约 15° 的可读星轨。
- 2000 颗星点中，约 600 颗聚在银河带附近；最亮的 62 颗有极轻的闪烁，其余保持稳定的点状。
- 星轨取亮度最高的 280 颗星，画最近 600 秒的曝光弧；每条弧分成 12 段从尾到头渐亮，画在 0.5×、上限 960×540 的半分辨率缓冲上。曝光窗始终滚动，不做整屏清空，所以 `EXPOSURE` 读数归零时画面没有跳变。
- 相机偏航 ±0.8°（30 分钟周期）与俯仰呼吸 ±0.12°（10 分钟周期）只作用于天空和星轨；前景保持固定，避免画面边缘露出空白。
- 竖屏时银河带会绕天极额外转约 72°，让银河纵向贯穿画面；横屏与超宽屏保持斜向构图。

## 天线与信号

- 自动扫描 8 分钟一个周期：方位在 −75°…+35° 之间往返，俯仰在 38°…66° 之间呼吸。t=0 时指向约 (−20°, 42°)，抛物面开口朝左上。
- 指向使用临界阻尼平滑，最大角速度约 26°/s；停止输入后不会突然跳向目标。
- 信号事件间隔 120–300 秒，每次 24 秒：0–6 秒转向（SLEW），6–18 秒解码（DECODE），18–24 秒归位并淡出（RETURN）。事件来源偏向天线工作天区的左上银河，约四分之一来自右侧。
- 解码时前景接收机的屏幕亮起冷青波形，馈源顶端的接收指示呼吸；SNR 读数同时上升，归位后 6 秒内回落。
- 手动拖动或锁定时，天线不会追向信号；等手动保持结束或锁定解除后，如果事件还没结束，它会转向剩余的信号。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` | 静止画面 |
| `still=0` | 显式播放，覆盖系统减少动态效果设置 |
| `t=95` | 起始时间，单位秒；驱动星轨、扫描与信号事件 |
| `seed=20261110` | 星表、山脊、碎石、草与信号表的种子 |
| `signal=0` | 关闭自动信号；默认开启 |
| `scan=0` | 关闭自动扫描，天线保持当前位置 |
| `az=-42` / `el=62` | 固定初始指向（仍受自动扫描与信号影响，除非 `scan=0`） |
| `capture=1` | 在 `t` 处强制进入解码态，用于海报与验证 |
| `detail=0.6` | 降低碎石、草与颗粒密度，范围 0.5–1 |
| `warm=600` | 星轨曝光窗长度，默认 600 秒，范围 120–900 |

静态海报：`wallpaper.html?still=1&seed=20261110&t=95&capture=1&hud=0`

纯壁纸：`wallpaper.html?still=1&seed=20261110&t=95&hud=0`

固定指向：`wallpaper.html?scan=0&az=-42&el=62&signal=0`

## 运行预算

- 动画目标 30 FPS，实际帧率取决于设备和宿主。
- 每张画布最多约 260 万渲染像素，`devicePixelRatio` 上限 1.5，并按面积回退（4K 时约 0.56）。
- 星点 2000、星轨 280×12 段、碎石 420、草 88；全部数量固定，不随运行时间增长。
- 静态天空、地形、站房、栏杆、草丛、暗角与颗粒烘焙到离屏画布；每帧只合成这些层，并重绘天线、钠灯与波形。
- 星轨缓冲每 0.25 秒重绘一次，避免逐帧累积在 8 位画布上的量化过曝。
- 页面隐藏时取消动画调度；恢复后重置时钟，避免后台时间造成跳帧。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-listening.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-listening.cjs --write-preview
```

脚本先在 Node 中加载真实 HTML 的脚本，对四种尺寸各模拟 10 分钟，检查星数 / 星轨段数 / 骨架段数上限、信号间隔与四态、拖动 / 锁定 / 暂停 / 隐藏页面 / 缩放 / 减少动态效果 / URL 开关。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查横屏、竖屏、超宽屏与 4K 渲染、动画推进、指针拖动、锁定、键盘、HUD、强制信号、种子复现、离线运行，以及壁纸库的元数据与预览识别。

Electron 截图写入系统临时目录 `lumen-deep-space-listening-check/`。这些检查不等同于 Windows 原生 WebView2 桌面挂载测试。
