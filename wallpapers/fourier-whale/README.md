# 跃海之鲸

直接打开 `wallpaper.html`，或在本机壁纸库选择「跃海之鲸」。单文件离线运行。

## 姿态

原创巨鲸曲线被整体抬升约 24°，鲸首朝左上、尾柄没入海面，形成从水中腾跃而起的姿态。尾鳍持续缓慢摆动，海面有月光、波纹、泡沫与回落的水滴。

## 傅里叶绘制

720 点闭合轮廓经复数离散傅里叶变换分解为旋转向量。显示前 30 个主要圆环；每个圆环的半径是系数幅值，转速是频率项，所有向量的末端相加正好落在鲸鱼边缘。

## 光圈与循环

- 每 58 秒一个循环：前 34 秒逐段描绘，后 24 秒保持完整边缘光。
- 圆环在保持阶段继续走完额外一圈，因此循环接缝在相位上完全连续，不会跳帧。
- 完整边缘光会一直保留到下一轮描绘开始前，最后 2.2 秒随海面一起缓缓熄灭。
- 水面会遮暗没入水下的轮廓，但保留一层幽微的透光，让鲸尾仍然连着海面。
