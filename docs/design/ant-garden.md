# 微观文明 · 桌面蚁园 — 设计文档

> 对应 `TODO.md` 中「微观文明 · 桌面蚁国」条目。本文先确定概念、画面、生态规则与验收标准，再据此实现 `wallpapers/ant-garden/`。标题取用户指定的「蚁园」。
>
> 状态：实现完成 · 2026-11-10

---

## 1. 一句话概念

一幅「玻璃蚁园横截面」的微距静物：地表之上是苔藓、种子与虚化的暖光，地表之下是逐年挖出的隧道与巢室；工蚁用信息素在两者之间铺出一条发亮的路，把食物一点点搬进越来越深的城。

它不是一款需要赢的游戏，而是一个**会自己继续生活**的桌面生态。用户可以点击投食、加速发展，也可以完全不管它。

### 设计原则

1. **先是一张好壁纸，才是一个模拟。** 静止看也要有构图、层次和光；运动是第二层惊喜。
2. **所有变化都可解释。** 蚂蚁沿信息素走、食物被搬进粮仓、储粮转化为新工蚁、累计食物解锁新巢室；没有凭空的粒子特效。
3. **安静、缓慢、不打扰。** 无音频、无弹窗、无强提示；HUD 十几秒后淡出，画面自己运转。
4. **小体量、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材；同一种子生成同一座蚁园。

- **横向构图**：地表线在 `y ≈ 0.32h`；巢穴以入口为中轴，向左右与下方展开，占据画面下半部。空气层给标题、虚化光斑和玻璃反光留出呼吸位。
- **竖向构图**：地表线略上移到 `y ≈ 0.30h`；巢穴收窄、加深，像一口竖井。标题缩小，读数隐藏。
- **超宽屏**：保持中轴巢穴，左右留出更长的地表与更多苔藓，空气层加入两簇更远的虚化光斑，避免画面被拉空。
- **边框感**：不做实体木框。只在左右边缘画极细的玻璃高光与斜向反光，底部用暗角收边，保证作为壁纸时全幅、无缝。

### 2.2 色彩与光

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 空气暗部 | `#140d08` → `#2a180e` | 暖褐，不是纯黑 |
| 虚化光斑 | `#c99a55` / `#7f8a45` / `#5f7a5c` | 桌面台灯、室内植物、远处窗户 |
| 腐殖土 | `#2a1a10` / `#402817` | 近黑褐，带湿气 |
| 砂层 / 黏土 | `#7a5230` / `#a37644` | 让巢穴边界读得清楚 |
| 深层砾石 | `#2f2016` / `#1d130d` | 画面底部压重 |
| 苔藓 | `#4d622d` / `#7f9247` / `#b0b464` | 受光边缘偏黄绿 |
| 蚁体 | `#24140c`，边缘 `#c58a4e` | 逆光轮廓 |
| 信息素 | `#ffc069` | 唯一的自发光暖色 |
| 强调色（meta） | `#d9a261` | 与 HUD 一致 |

- **主光**：左上方偏暖的柔光（台灯），土壤剖面上沿受光、下沿入暗；巢穴内壁有极弱的暖色反射，让隧道不糊成黑块。
- **逆光轮廓**：蚂蚁、草叶、玻璃边缘都用 1px 暖色描边或高光，保证小尺寸下仍可辨认。
- **空气感**：空气层叠 3 层：静态虚化光斑、缓慢漂移的光晕、浮尘。玻璃前再叠一层极淡的竖向反光。
- **慢光呼吸**：整幅画面以约 7 分钟为周期做 ±3% 的色温与亮度起伏，不出现明显的昼夜切换，避免壁纸长时间使用后显得突兀。

### 2.3 地表

- 地形是确定性的高度函数 `ground(x)`：基线上叠 2–3 组低频正弦与 4–6 个苔藓隆起；入口处有一个小小的土丘和凹洞。
- 苔藓团块、三叶草、两片蕨叶、一枚半埋的落叶、几颗小石子、两根枯枝。草叶在微风里以不同相位轻摆；只有前景 8–12 片叶子在蚂蚁之后绘制，形成遮挡。
- 两颗露珠：一颗挂在草尖，一颗落在苔藓上；用高光、暗边和极小的环境反射表现，不折射整幅场景，控制成本。
- 细节尺度：在 1920×1080 下，一颗种子约 10–16px，一只工蚁约 9–13px，苔藓团 30–80px。远看是纹理，近看才认得出来。

### 2.4 地下巢穴

- **土层**：腐殖土、砂层、黏土、砾石四层，用低频曲线分界；约 7,000 颗确定性沙粒、50 颗卵石、12 条主根与须根；另埋 3 件「桌面考古」小物（蓝色玻璃珠、锈钉、白石子），给画面一个可被偶然发现的焦点。
- **隧道**：折线 + 圆角，宽 `clamp(min(w,h) × 0.011, 6px, 12px)`；三层描边表现「压实壁 / 空腔 / 底缘反光」，交汇处天然融合。
- **巢室**：椭圆空腔，`rx = clamp(w × 0.028, 18px, 54px)`，`ry ≈ 0.58 rx`；底部有碎屑堆，根须从壁面穿过，室内有极淡的暖色辉光。
- **巢室类型**：前厅、卧廊、育婴室、粮仓、王庭、菌圃、深厅、泉滴回廊。每种有不同的陈设与色彩点缀，不靠文字标签区分。

## 3. 生态模拟

### 3.1 世界尺度

- 模拟坐标全部归一化到 `0..1`；渲染时映射到像素。这样横竖屏、窗口缩放、不同 DPI 下同一座蚁园保持结构一致。
- 地表活动是一维地形上的行走：`y = ground(x)`，左右为主要方向。地下活动沿巢穴图（节点 + 折线边）行走。
- 单帧模拟步长上限 1/30s；页面隐藏时停止；帧率 30 FPS。

### 3.2 信息素

只在**地表**使用一维信息素场，对应“蚂蚁沿地面走”的事实，计算量极小：

- 512 个等宽槽位，覆盖整个画面宽度。
- 搬运食物的工蚁每 0.1s 在所在槽位及相邻槽位沉积，强度 +0.32；扩散系数 0.12，半衰期约 38s。
- 觅食工蚁在前后各 40px 内采样，比较左右两侧强度；有气味时沿气味更浓的一侧行走，无气味时相关随机游走。
- 渲染成贴着地表的一条暖色微光，而不是覆盖画面的雾。强度越高，光点越密、越亮；气味淡出时只剩零星的余烬。
- 信息素默认可见但克制；设置面板可关闭，用于纯画面欣赏，也用于排查路径。

### 3.3 食物

- 四种食物：**面包屑**、**葵花籽**、**叶片碎片**、**蜜滴**。形状、颜色、被搬运动画各不相同。
- 每份食物含 8–14 个单位；工蚁一次搬走 1 个单位，食物随之缩小、变淡，最后留下一点碎屑/糖渍。
- 投食：点击地表上方，食物从点击处上方落下，带轻微弹跳与阴影；落点取该 x 处的地表高度。
- 自动投食（默认开启）：食物少于 2 份时，每 55–95 秒随机落下一份。这样即使桌面层不接收鼠标，蚁园也会自己发展。
- 同时最多 6 份食物；食物总量、每份剩余量都参与存档吗？——不保存，只保存已经运回巢的累计量，避免页面关闭时留下悬空的食物状态。

### 3.4 工蚁状态机

```
            发现食物 / 被气味招募
  forage ────────────────────────► scout ──► carry ──► enter
     ▲                               ▲                    │
     │                               │                    ▼
     └────────────── exit ◄──────── rest ◄── inside ◄── deposit
```

- **forage**：沿地形游走，偶尔停下梳理触角；遇到食物或高浓度信息素时切换。
- **scout**：直接朝一份尚未被发现的食物走；食物被吃完则回到 forage。
- **carry**：用上颚夹住食物单位，朝入口走，沿途沉积信息素；到达入口后进入地下。
- **inside**：沿巢穴图前往粮仓，停留、卸货；一部分个体再去育婴室、前厅或王庭附近停留。
- **exit**：沿原图返回入口，回到地表继续觅食。
- **rest**：在巢室或入口附近静止 2–8 秒，身体轻微起伏；少量个体长期待在地下，形成“巢内人口”。
- 行走动画：三对足交替摆动，触角以不同频率轻点，身体随步频上下 0.3–0.6px；携带食物时头部略低、速度略慢。
- 数量上限 84 只（含女王与巢内个体）。尺寸有 ±18% 的个体差异，避免整齐划一。

### 3.5 发现与招募

1. 食物落地后 4 秒内若无人发现，系统从地表觅食者中挑一只作为“侦察蚁”，给它 8–14 秒的直达目标。
2. 侦察蚁取食后返巢，沿途留下信息素。
3. 其他觅食者离开入口后检测到气味，沿气味找到食物，形成第二条、第三条路径。
4. 食物搬空后，信息素在 1–2 分钟内淡去，路径消失；这使每一份食物都像一次短暂的“工程”。

### 3.6 巢穴与成长

巢穴由确定性的节点图构成。种子固定时，结构永远相同；每个阶段解锁一批新隧道和巢室。

| 阶段 | 名称 | 累计运回 | 工蚁上限 | 新增结构 |
| --- | --- | --- | --- | --- |
| 1 | 初建 | 0 | 16 | 入口、竖井、前厅、卧廊 |
| 2 | 育婴 | 24 | 28 | 育婴室、第二入口、右侧回廊 |
| 3 | 储粮 | 56 | 40 | 粮仓、左侧回廊 |
| 4 | 王庭 | 100 | 54 | 王庭、深井、女王与侍从 |
| 5 | 菌圃 | 160 | 68 | 菌圃、第三入口、贯穿根须 |
| 6 | 深厅 | 240 | 84 | 深厅、泉滴回廊、底部砾石层 |

- **挖掘动画**：新阶段触发后 7 秒内，隧道从旧节点向新节点逐段挖开，巢室半径由 0.1 倍长到 1 倍，边缘带碎屑；同时有少量土粒落下。HUD 显示一行短提示「巢室延伸 · 粮仓」，3.5 秒后淡出。
- **人口**：初始 8 只工蚁。巢内储粮 ≥ 4 且未达当前阶段上限时，每 14 秒孵出一只新工蚁（消耗 4 储粮），从育婴室出现。女王在第 4 阶段解锁后常驻王庭，腹部缓慢起伏，身边有 3 只侍从。
- **储粮**：每次运回 1 单位，`stored +1`；粮仓里的种子堆视觉数量取 `min(30, stored)`，让“仓库”真的有东西。
- **幼虫与卵**：育婴室的卵、幼虫、蛹数量与人口上限相关；有极轻的呼吸缩放，不逐只模拟。
- **菌圃**：第 5 阶段后出现乳白色菌簇，随“湿度”缓慢呼吸；这是画面里唯一的冷色点缀。

### 3.7 时间与节奏

- 开局：8 只工蚁、1 份食物、1 份在途；约 20 秒后第一次出现搬运路径。
- 一次完整的“发现—搬运—淡出”约 1.5–3 分钟；阶段 2 通常在前 5–8 分钟出现。
- 不玩的时候，自动投食维持低速发展；长时间停留能看到阶段 3–5。
- 不做离线结算：重新打开时精确恢复上次的累计量、人口与巢穴阶段。离线不替用户做决定，也不会在回来时突然多出一大截。

## 4. 交互

| 操作 | 行为 |
| --- | --- |
| 点击地表上方 | 在该 x 处投下一份食物；指针悬停时显示淡淡的落点环 |
| 点击「投食」按钮 | 在随机位置投下一份食物，方便键盘/触屏用户 |
| `Space` | 暂停 / 继续（暂停时仍响应缩放并重绘） |
| `H` | 隐藏 / 显示 HUD；开场 16 秒后 HUD 自动淡出 |
| `F` | 全屏 / 退出全屏 |
| 设置面板 | 投食、自动投食、信息素可见、暂停、全屏、重新开始 |
| 「重新开始」 | 二次确认：第一次点击变为「确认重来？」，3 秒内再次点击才清空存档 |

- HUD 采用海报式排版：左上角品牌与档案号，标题与一句副题；右上角显示当前阶段与「COLONY ACTIVE」呼吸点；左下角是蚁群 / 储粮 / 巢室 / 阶段四列读数；右下角是低透明度的设置按钮。
- 读数只在 HUD 可见时更新，避免壁纸模式下的无意义 DOM 写入。
- 移动端/竖屏隐藏右上状态与左下读数，只保留标题、设置和提示。

## 5. 存档

- 存储：`localStorage`，键 `lumen.ant-garden.v1`。
- 载荷：

```json
{
  "v": 1,
  "seed": 20261110,
  "stage": 3,
  "delivered": 58,
  "stored": 14,
  "population": 31,
  "born": 23,
  "savedAt": 1762779600000
}
```

- 保存时机：每 8 秒、页面隐藏、`pagehide`、手动重置前。
- 读取校验：版本、种子、数值范围；阶段与累计量不一致时以累计量重新计算；人口不超过当前阶段上限。
- URL 显式指定 `seed` 或 `stage` 时进入**演示模式**：不读取也不写入存档，保证截图、验证和分享链接可复现。
- 重置：清除键，以同一或新种子回到阶段 1；画面立即重绘，不刷新页面。
- 真机注意：预览窗口与桌面宿主的 `localStorage` 可能各自独立；这是引擎既有行为，README 中说明。

## 6. 动效与镜头

- **镜头固定**，不做推拉摇移。壁纸需要稳定；动态来自光、尘、草、蚁和巢穴生长。
- 虚化光斑以 0.03–0.06 px/s 漂移；浮尘在空气层内做正弦漂浮，遇到玻璃边缘缓慢折返。
- 光晕以 7 分钟周期做 ±3% 的亮度呼吸；不做昼夜。
- 挖掘、投食、孵化是仅有的“事件型”动画；其余都是连续、低频的运动。
- 减少动态效果：默认暂停在首帧，HUD 保持可见；用户可手动继续。缩放窗口时即使暂停也重绘。

## 7. 渲染与性能

### 分层

| 层 | 更新频率 | 说明 |
| --- | --- | --- |
| 空气 / 光斑 / 玻璃 | 静态缓存 + 每帧轻移 | 尺寸变化时重建 |
| 土壤剖面 | 静态缓存 | 尺寸变化时重建 |
| 巢穴隧道 | 静态缓存 | 尺寸变化或挖掘时重建 |
| 巢室陈设 | 每帧（少量形状） | 种子、卵、女王、菌簇 |
| 信息素 | 每帧（几百个光点） | 512 槽位，只画强度阈值以上 |
| 工蚁 | 每帧 | ≤ 84 只，每只 ~20 个路径命令 |
| 前景草叶 / 浮尘 / 暗角 | 每帧 | 数量固定 |

### 预算

- 目标 30 FPS；`dt` 上限 0.1s，分步积分。
- 画布像素预算 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退。
- 静态层全部缓存到离屏 canvas，不在每帧重绘沙粒与根须。
- 巢穴缓存只在挖掘的 7 秒内每 4 帧重建一次，之后停用。
- 页面隐藏时 `cancelAnimationFrame`；恢复时重置时间戳，避免跳帧。
- 半透明径向渐变数量受控；信息素光点复用预渲染的 64×64 光晕贴图。
- 所有随机数来自种子化 PRNG；同一种子、同一尺寸得到同一画面（浮尘相位也固定）。

## 8. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、投食、开关信息素、重置和全屏。
- 减少动态效果时默认静止；不自动播放任何突变。
- 画面文字只承担标题和读数，不承载唯一信息；不依赖颜色区分巢室类型。

## 9. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 蚁园种子；固定后可复现巢穴与地表细节 |
| `stage=4` | 演示模式：直接进入指定阶段（1–6），不读写存档 |
| `food=3` | 初始地表食物份数（0–6） |
| `warm=40` | 首帧前预演若干秒，便于静态截图出现路径与搬运状态 |
| `auto=0` | 关闭自动投食 |
| `phero=0` | 隐藏信息素 |
| `detail=0.6` | 降低细节密度（0.55–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&stage=5&warm=45&seed=7&food=3&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 11. 实现结构

```text
wallpapers/ant-garden/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 模拟）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、生态规则、存档、URL 参数、验证说明

docs/design/ant-garden.md   本设计文档
scripts/verify-ant.cjs      模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、工具函数；
2. 地形与巢穴蓝图；
3. 静态层绘制（空气、土壤、巢穴）；
4. 生态状态（食物、工蚁、信息素、成长、存档）；
5. 动态绘制（巢室陈设、蚂蚁、草叶、光尘）；
6. 主循环、输入、HUD、验证钩子。

运行时暴露调试入口 `window.__lumenAnt`（快照、投食、推进、存档、重置），供 `scripts/verify-ant.cjs` 使用；不参与视觉，不影响普通播放。

## 12. 验证计划

1. **Node 模拟**：`node scripts/verify-ant.cjs`
   - 四尺寸各模拟 10 分钟，检查数量上限、坐标有限、阶段推进、储粮与人口、信息素范围。
   - 投食、搬运、入巢、阶段解锁、挖掘进度、暂停、隐藏、减少动态效果、缩放重绘、存档恢复。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏截图，检查非空、尺寸正确、无控制台错误与网络请求。
   - 验证动画推进、暂停、点击投食、HUD、设置面板、信息素开关、重新开始、刷新后恢复。
   - `--write-preview` 时输出 `preview.png`，写入临时目录的其余截图用于人工复核。
3. **视觉复核**：逐张查看 3 种尺寸与 2 个成长阶段截图，确认蚂蚁可辨、隧道层级清楚、HUD 不遮挡主体。
