# 一城四时

一座真正以 WebGL 绘制的 3D 微缩城市沙盘。使用本地 Three.js r160，完全离线运行，无图片、字体、模型或网络请求依赖。模型由程序生成；窗招牌用本地 Canvas 绘制。

直接打开 `wallpaper.html`，或在流光壁纸本机库中找到「一城四时」并预览、应用。请保持 `vendor` 文件夹与 HTML 的相对位置不变。`preview.png` 是实际渲染截图。

## 城市内容

- 28 栋建筑：坡顶街屋、沿河小店、现代楼宇与带动态指针的钟楼。
- 建筑细节：窗框、烟囱、屋檐、遮阳棚、女儿墙、屋顶空调、太阳能板与店铺招牌。
- 河道、两座带栏杆和桥墩的桥、小船、水面波纹与河岸护栏。
- 城市道路、车道线、斑马线、停车位、交通灯、公交站、路灯、垃圾桶和护柱。
- 公园、花坛、长椅、咖啡桌、遮阳伞、秋千、滑梯、喷水池与转动的摩天轮。
- 38 棵树、13 辆沿道路环线行驶的车辆、38 位沿人行道活动的行人。
- 三节小火车、铁轨、轨枕、接触网和两端隧道；火车出入处裁切，避免驶出沙盘边界。

车辆、行人和火车采用循环路径营造城市生活，并非交通规则或人群避障模拟。

## 四季与昼夜

默认一天 180 秒，一年 720 秒；季节转换在每季后半段平滑混合，不替换整套场景。可以调整至 0.5、1、3、10 倍速度。

- 春：粉色花树、浅绿草地、飘落花瓣。
- 夏：浓绿树冠与绿地，空中飘落物消退。
- 秋：金黄、赭色树叶与飘落物。
- 冬：树冠缩小、枝干显露、地面和屋顶变白、河面变浅、持续飘雪。
- 昼夜：太阳方向、阴影、光色和背景连续变化；黄昏后窗灯、车灯、路灯及地面光圈亮起。

季节与时刻可分别固定。这是加速的艺术时间，不读取现实日期或当地日出日落。冬季河道保留船只运动，浅色水面并非可行走的物理冰层。

## 操作

- 拖动：旋转俯仰和环绕视角，拖动后停止自动环绕。
- 滚轮：缩放，查看街巷细节。
- 「时光设置」：选择季节、自动昼夜或固定时刻、速度、自动环绕、恢复初始视角。
- `Space`：暂停 / 继续所有时间动画。
- `H`：隐藏 / 显示整个界面。
- `F`：全屏；可用 `Esc` 退出。
- 系统启用「减少动态效果」时默认暂停并关闭自动环绕；可手动播放。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `season=0` | 固定春季；`1` 夏、`2` 秋、`3` 冬。省略则自动循环 |
| `hour=22` | 固定在 22:00；允许 0–24 的小数。省略则自动昼夜 |
| `t=240` | 初始动画时间，单位秒，0–86400 |
| `still=1` | 暂停；`still=0` 强制播放并覆盖系统减少动态效果 |
| `orbit=0` | 关闭自动环绕 |
| `hud=0` | 隐藏界面，按 H 恢复 |

例：`wallpaper.html?season=3&hour=22&orbit=0` 为固定冬季夜晚，仍有落雪和城市活动。设置只影响当前页面，长期预设可使用 URL。

## 性能与验证

目标为 30 FPS，像素比不超过 1.5，总渲染像素不超过 260 万；真实速度取决于设备和宿主。重复建筑及动态细节采用实例化，参考视角约 128 次主渲染绘制调用、7.2 万三角形。使用 2048 像素阴影贴图，页面隐藏时停止调度，暂停时只在交互或尺寸变化后重绘。需要支持 WebGL 的浏览器。

从仓库根目录执行：

```powershell
node wallpapers/seasonal-city/verify.cjs --write-preview
```

验证在 Electron 的真实 `file://` WebGL 环境运行，覆盖春夏秋冬与夜景、横屏/竖屏/超宽屏、动画与暂停、设置、缩放、全年循环、减少动态效果、离线请求和本机库识别。截图写入 `temp/seasonal-city/`。Windows WebView2 桌面挂载未在此验证中运行。
