# 风的显影

暗房里的一块空气切片。风没有形状，长曝光却把它显影成十几条发光的银盐丝带；铁屑沿着同一套流线排成细小的短划，像磁场里刚刚落定的方向。指针划过，空气里留下一个慢慢散开的涡旋；什么都不做时，每 20–40 秒会有一阵自动的阵风经过。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「风的显影」并预览、应用。`preview.png` 是实际渲染截图。

- 移动指针：以移动速度累积一个半径 120px 的涡旋，丝带与铁屑都会被卷向切线方向。
- 按住拖动：涡旋增强到满强度；松手后约 8 秒内衰减到不可见。
- 双击画面：清空涡旋、重新生成丝带与铁屑，并停在一张静止构图上（按 `Space` 可继续）。
- 右下角「显影设置」：暂停、全屏、自动阵风、指针涡旋、清空构图、换一张底片。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 16 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 系统启用「减少动态效果」时默认静止，可手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，自动阵风、丝带重生和流场旋转照常运行，画面依然完整。

## 显影规则

- **流场**：基础风（横屏向右上、竖屏向上）叠加 3 个倍频的 curl noise，以及 5 个缓慢漂移的涡旋，波矢与涡心随时间缓慢旋转。速度场先采样到 64×36 网格，再用双线性插值读取。
- **丝带**：12 条，每条 60 个顶点，目标轨迹长度在 0.55–1.15 个布局长度之间波动。头部随流场前进，尾部按弧长裁切；生命周期 30–60 秒，出画或寿终后先淡出 1.6 秒，再从对侧重生。
- **笔触**：丝带主体约 3–14px，柔光先画进 0.4× 离屏缓冲再放大合成，形成银盐晕边；亮芯只有 0.7–4.4px。
- **受光边**：线宽和亮度随当地速度变化；只有速度最高的段落会出现一条偏移的琥珀色受光边，其余保持银灰。
- **端部消散**：尾部最后一段透明度逐级降低，并撒出确定性颗粒；头部保留一个很小的亮点。
- **铁屑**：300 枚短划，约六成沿丝带轨迹分布，四成在画面内均匀撒开；每帧用同一张速度网格推进。
- **阵风**：每 20–40 秒一次，持续 6–9 秒，把基础风提高到约 2.1 倍；`gust=0` 可关闭。
- **镜头**：正面平视、正交，不做自由运动；只有周期 6 分钟的 ±1% 缩放呼吸。
- **不重置**：流场、丝带年龄、铁屑位置都是连续状态；画面在数十分钟内不会完整重复。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数和设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 暗房种子；固定后复现丝带初值、铁屑与阵风时刻 |
| `t=360` | 起始时间，单位秒；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=10` | 播放态启动前额外回溯多少秒（0–30），让第一帧的轨迹更自然；静止态直接使用完整构图 |
| `gust=0` | 关闭自动阵风 |
| `vortex=0` | 关闭指针涡旋 |
| `detail=0.6` | 降低铁屑、颗粒与刻度密度（0.55–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=360&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

固定种子的纯壁纸：`wallpaper.html?seed=20261110&hud=0&gust=0`

## 运行预算

- 动画目标 30 FPS；本机离屏验证为 1920×1080 与竖屏 30 FPS，4K 约 28 FPS，实际帧率取决于设备与宿主。
- 每张画布最多约 260 万渲染像素，像素倍率上限 1.5。
- 丝带 12 条 × 60 顶点 = 720 段（硬上限）；铁屑 300；阵风最多同时 2 股；没有累积型全屏缓冲。
- 速度网格 64×36 每 0.2 秒重建一次；粒子读取为双线性插值，不在每帧重算全屏噪声。
- 柔光缓冲为 0.4× CSS 尺寸；每帧只重画丝带与铁屑，背景、暗角、前景离焦与颗粒在尺寸变化时烘焙到离屏画布。
- 主循环按 1/40 秒阈值渲染，避免 30Hz 显示器上因时间戳抖动隔帧丢弃。
- 页面隐藏时取消动画调度；恢复后重置时间戳，避免后台时间造成跳帧。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-wind.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-wind.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查丝带数量、顶点数、坐标有限、速度上限、生命周期、阵风次数、5 个流场涡旋的数量、涡旋衰减、暂停、隐藏页面、缩放与确定性复现。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度分布、动画推进、指针涡旋、双击定影、设置面板、HUD、减少动态效果、无网络请求和无控制台错误。截图写入系统临时目录 `lumen-wind-development-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动阵风是必要的保底。

设计文档见 [`docs/design/wind-development.md`](../../docs/design/wind-development.md)。
