# 机械植物园

深夜的玻璃温室里，三株黄铜植物各自按发条节律生长。主株是一朵十三瓣的机械山茶，副株垂下三枚铃花并在枝下悬着一副摆轮，幼苗从低处的展台上顶开一枚小小的金属花苞。齿轮咬合处漏出暖光，月光斜穿过尘埃及蒸汽，落在大理石展台与失焦的黄铜栏杆上。

画面全部由 Canvas 2D 程序绘制：磨砂玻璃、丝绒、远景机械、展台、植物、花瓣、齿轮、尘埃、蒸汽、凝结水珠与暗角，没有图片、视频、字体、音频或网络依赖。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「机械植物园」并预览、应用。`preview.png` 是实际渲染截图（`t=100`，主株与副株盛开、幼苗闭合）。

- 悬停 / 按住某株：上发条。转速在 2 秒内提升到 1.4 倍，移开后约 20 秒回落到正常速度。
- 点击某株：让它开花或收拢。手动状态持续约 24 秒，之后交还自动花期。
- `1` `2` `3`：镜头对准主株 / 副株 / 幼苗，并给该株一次上链脉冲。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面。
- `F`：进入 / 退出全屏。
- 右下角「展台设置」：「检修」会让当前展台立即进入 40 秒检修；也可以切换展台、暂停和全屏。

自动运行时，每 15 分钟轮换一株进入 40 秒检修：整株向一侧折叠、花瓣收拢，阀口喷出蒸汽，然后重新展开。没有鼠标输入时，花期、齿轮、相机、蒸汽和检修都会照常进行。

## 三株植物

| 展台 | 名称 | 结构 | 花 | 周期 |
| --- | --- | --- | --- | --- |
| I | 黄铜山茶 `CAMELLIA MACHINA` | 直立五节套管主枝、三根侧枝、底盘压力表与上链钥匙 | 13 瓣外轮 + 8 瓣内轮，闭合时收成金属花苞 | 齿轮 47s / 花期 257s |
| II | 摆轮蕨 `PENDULUM FERN` | 向右拱起的弧形主枝、三枚垂铃、擒纵轮与摆锤 | 9 瓣顶花 + 3 枚六瓣铃花 | 齿轮 73s / 花期 311s |
| III | 发条幼苗 `SPRING SEEDLING` | 短茎、两片子叶、小发条盒与上链环 | 5 瓣小花 + 1 枚待放花苞 | 齿轮 101s / 花期 349s |

三株齿轮周期互质，画面在 12 小时内不会出现可辨认的重复；花期错开，任意时刻至少有一株处于开、合一的状态。

## 构图

- **横向（16:9 / 4K）**：主株在 `0.365w`、副株在 `0.705w`、幼苗在 `0.535w`；上方 35% 留给光柱与蒸汽。
- **竖向（390×844）**：三株改为三层壁挂石搁板，主株在上、副株居中、幼苗在底部，标题落在左上空白处。
- **超宽屏（21:9）**：三株拉开，左右各补一座更远、更暗的展台剪影，保留“标本柜”的纵深。
- **视角**：正面略俯 8° 的正交“标本柜”视角；俯角通过展台顶面的椭圆、齿轮面的压扁和地面光池表达，不使用透视缩放。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `still=1` | 静止帧 |
| `still=0` | 强制播放（覆盖系统「减少动态效果」设置） |
| `hud=0` | 隐藏标题、读数与按钮，适合纯壁纸或截图；按 H 可恢复 |
| `seed=20261110` | 场景种子；固定种子生成同一座温室 |
| `t=100` | 初始时间，单位秒，范围 0–86400；`t=100` 是默认首屏 |

示例：

```text
wallpaper.html?still=1&hud=0&t=100&seed=20261110   ← 预览图取景
wallpaper.html?t=620&hud=0                          ← 主株检修中（播放以看到蒸汽）
wallpaper.html?t=100&hud=0                          ← 默认播放
```

## 运行预算

- 目标 30 FPS；单画布渲染像素 ≤ 260 万，像素倍率上限 1.5。
- 每株花瓣 ≤ 120、齿轮 ≤ 40；当前三株合计 76 片花瓣、20 个齿轮。蒸汽 ≤ 60，尘埃 80。
- 背景（丝绒、磨砂玻璃、远景机械、噪声）与前景（栏杆、水珠、反光、雾点）在窗口尺寸变化时一次性烘焙到离屏画布。
- 齿轮轮廓、花瓣、叶片使用 `Path2D` 缓存；每帧只做变换与填充。
- 页面隐藏时取消动画调度；恢复后重置时钟，避免后台时间造成跳跃。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘一帧。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-garden.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-garden.cjs --write-preview
```

脚本在 Node 中用 VM 模拟 1920×1080、390×844、3440×1440、3840×2160 四种尺寸各 10 分钟，检查：

- 三株植物的开合值、折叠值、上链值与齿轮相位都在合法范围内，无 NaN；
- 花瓣、齿轮、蒸汽数量不超过上限；
- 每 15 分钟一次检修在 `600–640s` 内发生，单株折叠、蒸汽出现、之后恢复；
- 悬停上链会加快齿轮，松开后 20 秒内回落；点击开花/收拢与 `1–3` 对准展台生效；
- 暂停、隐藏页面、减少动态效果、窗口缩放、`still` / `hud` 参数正确。

随后用 Electron 离屏窗口加载真实 `file://` 页面，检查横屏、竖屏、超宽屏与 4K 视口渲染、同一 `seed` / `t` 的确定性、动画与暂停、键盘与面板、减少动态效果、窗口缩放、无网络请求与无控制台错误，以及壁纸库对 `meta.json` 与 `preview.png` 的识别。超宽屏与 4K 通过 0.5× 缩放的 CSS 视口验证构图与像素预算，实际画布按 260 万像素上限降采样；离屏宿主的帧率采样会低于真实 GPU 桌面层，只用于确认持续渲染。

Electron 截图写入系统临时目录 `lumen-mechanical-garden-check/`。这些检查不等同于 Windows 原生 WebView2 桌面挂载测试。
