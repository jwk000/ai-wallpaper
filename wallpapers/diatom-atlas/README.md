# 硅藻图鉴 · 暗场里的分裂

暗场显微镜下的一滴海水。圆形视场里浮着八枚硅质骨架，边缘一圈冷光，内部半透明、孔阵精确；它们以各自的周期缓慢漂移、旋转，孔洞随着焦平面忽而清晰、忽而化成光斑。偶尔有一枚从中间裂开，变成两枚更小的，小的再慢慢长回原来的大小。什么都不做时，载玻片也在动。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「硅藻图鉴 · 暗场里的分裂」并预览、应用。`preview.png` 是实际渲染截图（1920×1080，HUD 关闭）。

- 滚轮 / 上下拖动：调焦平面。手动对焦约 14 秒后开始缓慢回到自动的 8 分钟往返。
- 左右拖动：旋转载玻片，所有个体一起转；松手后保持角度。
- 轻点画面：推一下水滴，附近的个体向外漂开，约两分钟内被漂移吸收。
- 双击个体：让指针附近的那一枚分裂。选中的个体有一圈极淡的虚线环，4.5 秒后消失。
- 右下角「载玻片设置」：暂停、全屏、自动分裂、自动对焦、分裂选中、推一下水滴。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 16 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- `↑` / `↓`：微调焦平面；`Enter`：分裂选中的一枚。
- 系统启用「减少动态效果」时默认静止，可手动继续播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，自动漂移、8 分钟的对焦往返、6–10 分钟的自动分裂照常运行，画面依然完整。

## 载玻片的规则

- **视场**：圆形目镜视场。横屏与超宽屏半径取 `0.575 × 高度`，圆上下超出画面，四角留给纯黑；竖屏半径取 `0.46 × 宽度`，完整的圆居中，上下留黑给标题与读数。视场外不画任何东西。
- **构图**：主个体落在 `(0.52w, 0.47h)`；两枚副个体分别在 `0.25w` 与 `0.77w`（1920×1080 实测，条目写 0.78w），景深不同；第四枚暖黄个体在 `(0.45w, 0.67h)` 作点缀。背景两枚小而虚，前景两枚大幅失焦、压住视场下缘两角，另有一颗气泡。
- **骨架**：五类硅质壳——中心辐射（圆盘、同心环与径向孔行）、羽纹（船形、横向肋与壳缝）、三辐射（圆角三角、三组辐条）、星形（七臂）、S 形（两端尖、交叉排线）。轮廓、内环、肋、刻线、孔行由 `seed` 决定，同一 `seed` 得到同一套骨架。每枚骨架是若干条 `Path2D`，实测最多 153 条命令（预算 ≤ 400）。
- **孔阵**：不是逐点撒圆点，而是沿径向孔行与同心环画一条圆头虚线（`setLineDash`），外圈柔光、内圈亮芯两层叠加。远看是精确的数学孔阵，近看每一颗孔都有一圈暗边和一个亮点。
- **光**：暗场成像——骨架边缘被冷凝器侧光擦亮，内部半透明，孔洞是唯一的高光。每枚骨架先渲染成一张清晰 sprite 和一张一次性 `blur()` 烘焙的模糊 sprite；逐帧只做变换、缩放与加色合成，虚焦时再沿轮廓勾一圈焦外亮环、撒 12 个预采样的光斑。骨架上另有一点红/蓝错位的色差。
- **对焦**：焦平面 `0.5 ± 0.2`，8 分钟一个完整往返。每枚个体有 `z`（0.12–0.98），清晰度 `s = 1 − |z − focus| × 3.2`；背景层最高只到 0.34、前景层只到 0.12，永远虚着，用来分层。
- **漂移**：每枚的位置是时间的纯函数——两组不同周期的正弦叠加一条极慢的线性漂移，在 ±1 个视场半径的方形域里环绕；越靠近视场边缘越淡（0.80–1.04 之间淡出），出画后从对侧淡入。台面另有 211s / 173s / 97s / 79s 周期的缓慢漂移和 240s 的 0.7% 呼吸缩放，像有人在轻轻挪载玻片。
- **分裂**：一次分裂把亲本换成一枚 1.01 秒的残影和两枚 0.8 倍大小的子体，沿随机轴各偏 0.34R 分开，中心起一圈 1.6 秒的闪光。子体在约 6 分钟里长回 0.8 倍；总数恒定 8 枚——超过上限时优先淘汰背景层里最小的一枚（2.6 秒淡出）。
- **自动**：每 6–10 分钟自动分裂一次，间隔由 `seed` 决定；手动分裂不会打乱自动排程。
- **载玻片**：26 条极淡划痕、120 粒尘点、一颗缓慢漂移的气泡，一次性烘焙；视场内还有一层 1px 的细颗粒，让黑保留摄影的齿感。
- **不重置**：位置、角度、分裂次数、残影、气泡都是连续状态；没有累积型全屏缓冲，闪光、涟漪、残影都有年龄上限（1.6s / 3.2s / 2.6s），长时间播放不会越积越亮。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数与设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 载玻片种子；固定后复现骨架、个体位置、漂移相位与分裂时刻 |
| `t=0` | 起始时间，单位秒（0–86400）；同一 `seed` 与 `t` 渲染同一帧，`t` 之前的自动分裂会按调度回放 |
| `focus=0.44` | 固定焦平面（0.02–0.98），忽略自动往返与手动偏移 |
| `split=0` | 关闭自动分裂，只有双击 / 按钮才会分裂 |
| `autofocus=0` | 关闭自动对焦，焦点停在 0.5 + 手动偏移 |

静态海报：`wallpaper.html?still=1&t=0&seed=20261111&hud=0`

纯壁纸：`wallpaper.html?hud=0`

定焦观察：`wallpaper.html?focus=0.5&hud=0`

## 运行预算

- 目标 30 FPS：主循环用 `requestAnimationFrame` 加 33ms 累加器，只在累计够一帧时推进模拟并重绘；离屏（禁用 GPU）1920×1080 实测 29.8–30.0 FPS。
- 单画布 ≤ 260 万渲染像素；`devicePixelRatio` 上限 1.5，并按面积回退：1920×1080 → 1.12，3440×1440 → 0.72，4K → 0.56，390×844 → 1.5。
- 个体 ≤ 8，残影 ≤ 3，闪光 ≤ 4，涟漪 ≤ 3；每枚骨架 ≤ 400 条 `Path2D` 命令（实测最大 153）。
- 骨架在尺寸变化或新生时渲染成清晰 / 模糊两张 sprite（每张 ≤ 1400px），逐帧只做 `drawImage`、变换与加色混合；模糊是一次性 `filter: blur()` 烘焙，不在每帧做滤镜。
- 背景（视场渐变、冷凝器光环、划痕、尘点）与覆盖层（暗角、刻环、144 条刻度、罗马数字、比例尺、角标、≤ 14000 粒 1px 颗粒）在尺寸变化时烘焙。
- 页面隐藏时取消动画调度；恢复后重置时间戳与累加器，避免后台时间造成跳帧；暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-diatom-atlas.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-diatom-atlas.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查个体数量上限、每枚骨架的段数、坐标有限、环绕域、分裂次数与上限、对焦周期与清晰度变化、30 FPS 调度、手动对焦与回落、推水与衰减、载玻片旋转、暂停、隐藏页面、缩放、减少动态效果与种子复现。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度分布、帧率、像素级复现、滚轮调焦、拖动旋转、轻点推水、双击分裂、面板与 HUD、减少动态效果、无网络请求和无控制台错误，并核对壁纸库识别结果。截图写入系统临时目录 `lumen-diatom-atlas-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动漂移、自动对焦与自动分裂是必要的保底。

设计文档见 [`docs/design/diatom-atlas.md`](../../docs/design/diatom-atlas.md)。
