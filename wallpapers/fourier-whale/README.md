# 流光乐章

近黑色金属 G 高音谱号与压暗的背景融为一体，仅用微弱倒角和侧面投影保留立体感，主要靠边缘背光辨认形状。傅里叶行星轮描绘的蓝白边缘光位于实体背后，被不透明正面遮挡，形成背光效果。

## 傅里叶行星轮

- 从原创谱号的填充轮廓提取外缘和内部孔洞，去除交叉笔画产生的内部假边缘。
- 四条闭合轮廓按弧长均匀采样，各自计算复数离散傅里叶变换；内圈与外圈同时描绘、同时完成。
- 每条轮廓各有一组行星轮，绘制在谱号正面前方；每组最多显示 36 个主要圆环，圆环、连杆、中心点和描绘端点统一使用暗金色，所有项参与末端位置计算。
- 每 58 秒循环：前 34 秒同步描绘所有轮廓，后 24 秒保持完整背光，末尾 3 秒淡出。保持阶段行星轮继续运转。
- 每组行星轮持续沿自己的闭合轮廓运转，不在不同内圈之间跳转。

背景保留四层轻微起伏的五线谱，音符与小节线向左缓慢流动。每个音符具有不同的大小、基础亮度和独立的缓慢闪烁节奏，亮起时带有轻柔光晕与星芒，形成错落的星光效果。纯视觉动态壁纸，不播放音频。

直接打开 `wallpaper.html`，或在壁纸库中选择「流光乐章」。单文件离线运行，不依赖外部字体、图片或脚本。

支持横竖屏、系统“减少动态效果”和页面隐藏时暂停。`?still=1&t=0.64` 固定完整背光画面；`&clean=1` 隐藏文字。

运行 `node scripts/verify-music.cjs` 检查实际 Electron 渲染、动画启停、窗口缩放、傅里叶末端误差、真实轮廓边界与背光循环。

沿用 `fourier-whale` 目录标识，以保持现有壁纸库和下载链接的兼容性。
