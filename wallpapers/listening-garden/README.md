# 聽雨園 · 掌上江南

原創中式園林 3D 微縮沙盤動態壁紙。使用內嵌 Three.js r160 / WebGL，即時渲染可旋轉的建築、植物、池塘、人物、動物及厚底展臺，完全離線。

## 園景細節

- 主廳中央雙扇木門、格窗、月洞門、轉折游廊及臨水重簷亭。青瓦逐排搭接，具有獨立瓦口、飛簷翹角、角脊與廊下榫卯梁枋。
- 園路採用不規則暗青灰色碎拼青石；石拱橋有立體拱券、橋欄與欄柱。
- 樹木由分叉枝幹、曲面葉片和松針組成；84 條下垂柳枝與其葉片共同隨風彎擺，根部保持固定。太湖石具有貫通孔洞、風化紋理與苔色。
- 移除東側庭院的白色圓環砂紋底座和其中的小假山，原位種植 36 株高低錯落的向日葵。池塘北岸內側的淺水處增加 42 叢帶穗蘆葦，莖根位於池底，莖葉與穗頭一同隨風輕擺。
- 四隻小鳥停棲在實際樹枝上，偶爾轉頭。主廳簷下有泥築燕窩，一隻燕子間歇離巢，在園上空繞行三圈後沿廊下入口回巢。
- 七片花圃共 252 株花；四隻蝴蝶中有兩隻結伴，以較快速度在不同花叢之間穿梭，其餘兩隻自由飛行；蝴蝶體型縮至前版的 65%。池中 62 片荷葉、11 朵荷花與花苞，保留三隻蜻蜓。
- 六位行人為四位大人、兩位小孩，男女各三位；男女成人的身高差約 17%，男裝採用較窄的交領開衩長袍與褲裝，女裝採用較寬的層疊褶裙與披帛；四位成人組成兩對男女同行，男孩與女孩相伴。分組緩起緩停，間歇觀景或轉向同伴交談，各自沿有先後差的路線轉彎。立體眼瞼、鼻脣、髮髻、簪飾及淡妝參考漢服仙俠造型；交領、分層衣裙、寬袖、腰帶與髮帶具有織紋和隨風飄動。另保留一位垂釣者及兩位棋手，全園共九人；棋手石凳降低並縮窄，坐姿衣袍前垂，避免後擺與座面穿插。
- 垂釣者在木臺上持竿，另一手緩慢抬起旱煙管、停留吸煙再放下；淡煙升起、擴散，浮漂隨水輕動。
- 七盞紅色中式廊燈，含燈骨、金色箍圈及流蘇，隨風輕搖。
- 小狗與貓分別縮至前版的 65% 與 68%，以連續曲面塑造背線、胸腹、口鼻與漸細的四肢，附短毛紋理、耳內皮膚、眼瞼、鬚及細趾。小狗在東側庭院變速跑動，緩緩停下聞地、抬頭張望後再跑；每輪停留位置不同。虎斑貓蜷在主屋瓦頂，保留呼吸，偶爾輕動耳朵與尾尖。
- 池水以鏡像相機生成當前三維場景的真實平面倒影，亭臺、樹木、石橋等按視角與遮擋映入水中。程序水波輕微扭曲倒影，透明水層保留九尾錦鯉的紅白花紋、尾鳍和胸鰭，池底有微弱流動光紋。每尾錦鯉採用獨立曲線、方向和變化的游速，交會時相互避讓，減少同步並排游動。
- 牌匾、題字、控制界面及壁紙庫資料使用繁體字。

園林為藝術化微縮模型，並非特定真實園林的復刻。雨天蝴蝶與蜻蜓隱去；煙氣、動物、水波及植物動作均由場景時間驅動，暫停時一起停止。

## 開啟與操作

直接開啟 wallpaper.html，或在流光壁紙的本機壁紙庫刷新後找到「聽雨園 · 掌上江南」。preview.png 是實際渲染截圖。

- 拖動旋轉；滾輪或雙指縮放。
- 右下角「觀園」可調整天光、風力、時間流速與緩慢環繞。
- 「細看園景」有全園沙盤，以及檐下木構、松風花徑、太湖疊石、臨池垂釣、亭中對弈、荷塘蜻蜓、水榭倒影、庭犬嬉遊、瓦上眠貓、漢服遊園、葵田聽風、簷下歸燕十二種近景。
- 選擇亭中對弈會暫時隱藏亭頂；「顯示亭頂」可恢復。
- Space 暫停或繼續；R 復位；H 隱藏界面；F 全屏；Esc 關閉設定面板。
- 方向鍵轉動視角；＋ / － 縮放。

開場題字 16 秒後淡出。系統「減少動態效果」預設暫停；隱藏頁面時停止動畫排程。設定只作用於本次開啟。

## 維護與效能

來源位於 scripts/garden：scene.js 為場景與相機，architecture.js 為建築及鋪石，nature.js 為自然景物，life.js 為人物、昆蟲及廊燈，animals.js 為貓狗造型及行為，residents.js 為人物造型與結伴行為，birds.js 為停棲鳥、燕窩與出入巢飛行，willow.js 和 flora.js 為動態柳枝及花田蘆葦，water.js 為水面倒影及錦鯉，shell.html 為界面。vendor/three.min.js 為內嵌固定版本庫，授權見 THREE-LICENSE.txt。

在倉庫根目錄執行：

~~~powershell
node scripts/garden/build.cjs
node scripts/verify-garden.cjs --write-preview
~~~

重複物件使用實例化，固定部件按材質合併。主畫布最多約 280 萬像素、設備倍率上限 1.5，目標約 30 FPS。全園主畫面約 225 萬三角形、527 次繪製呼叫；倒影另需一輪場景渲染，最長邊限制 1024 像素，靜止鏡頭下最多每秒更新 15 次，水面波紋仍隨主畫面更新。暫停時重用倒影，轉動鏡頭立即更新。實際效能取決於 GPU 及宿主。

陰影貼圖為 2048 × 2048，靜態場景陰影快取，天光或亭頂可見性改變時更新；移動行人與小狗使用接觸陰影。預設視角按窗口比例完整容納沙盤，直向屏幕保留較多背景。

## 驗證

verify-garden.cjs 使用 Electron 的實際 file:// WebGL 渲染，涵蓋橫屏、超寬、直向、4K、三種天光、十二種近景、倒影紋理讀回與鏡像相機、水下錦鯉、吸煙及廊燈、雙蝶距離、動物縮放、聞地與張望停留、變速銜接、貓耳及尾尖間歇動作、人物年齡與男女比例、結伴轉彎、停步交談、錦鯉避讓與運動連續性、燕子回巢、暫停、拖動、縮放、低動態偏好、大時間值、離線請求及壁紙庫識別。

截圖存於系統臨時目錄 lumen-garden-check。Electron 檢查不等同於 Windows 原生 WebView2 桌面掛載驗證。
