## 1. 一句话概念

深夜的玻璃温室里，三株黄铜植物各自按发条节律生长、开花、收拢。齿轮咬合处漏出暖光，蒸汽在月光里散开，整座温室像在缓慢呼吸。

它不是一座需要操作的机关，而是一件**会自己运转的植物学标本**：静止看是一张十九世纪铜版植物插图，看久了才发现花瓣在开合、齿轮在走、光在呼吸。

### 设计原则

1. **先是一张好画。** 三株植物、三个展台、一束月光，任何一帧截屏都能独立成立；运动只负责让画面活起来。
2. **机械必须可信。** 每片花瓣都有铰链和厚度，每根枝条都有套管、轴节与配重；发光只出现在齿轮咬合、花心与仪表这些“该发热”的地方。
3. **静默、克制。** 无音频、无外部素材、无网络请求；HUD 十几秒后淡出，桌面层收不到鼠标也完整运行。
4. **可复现、可验证。** 单 HTML + Canvas 2D；同一 `seed` 与 `t` 渲染同一帧，关键状态暴露给验证脚本。

### 2.3 色彩与材质

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 温室暗部 / 丝绒 | `#07100c` → `#0d1a15` | 深绿近黑，不是纯黑 |
| 黄铜中调 | `#b98545` | 枝干、齿轮、展台包边 |
| 黄铜高光 | `#e3c07a` | 只出现在受光边与铰链 |
| 铜绿 | `#4e7a63` / `#6f9275` | 叶片与老枝，饱和度压低 |
| 月光 | `#f0d9a0` | 光柱、尘埃、花心 |
| 暗红宝石 | `#8f3f32` | 花心轴承与仪表针尖，唯一的暖红 |
| 强调色（meta） | `#c99b5c` | HUD 与卡片强调色 |

- **黄铜**：暗褐描边 + 中调填充 + 单侧高光；老枝与底座叠 2–3 块不规则铜绿。齿轮保持线稿感：外圈深线、轮辐细线、轴心一点高光，不铺金属贴图。
- **花瓣**：薄金属片。深色投影偏移 1–2px，主体 `#a8703a`，内侧提亮到 `#c08a4c`，边缘一圈 `#e3c07a` 的断续高光；背面能看到 2–3 条铰链刻线。
- **叶片**：铜绿薄片，叶脉用黄铜细线；一株里约 1/3 的叶子是黄铜色，制造“半植物半机械”的错位。
- **光**：唯一强光来自左上月光，花心与齿轮咬合点是次级暖光。所有辉光半径 ≤ 花径的 1.8 倍，不做全屏 bloom。
- **颗粒**：预生成极淡的丝绒噪声与玻璃雾点，避免大面积纯色渐变出现色带。

### 2.4 三株植物

| 展台 | 名称 | 结构 | 花 | 识别特征 |
| --- | --- | --- | --- | --- |
| I · 主株 | 黄铜山茶 `CAMELLIA MACHINA` | 直立五节套管主枝，三根侧枝，枝节处 3 组齿轮；底盘有压力表、上链钥匙与传动轮 | 13 瓣外轮 + 8 瓣内轮，直径约 `0.17` 株高 | 最高、最亮，花心是一枚暖光宝石 |
| II · 副株 | 摆轮蕨 `PENDULUM FERN` | 向右拱起的弧形主枝，三枚垂铃花，枝下悬一副摆轮与擒纵轮 | 3 枚六瓣垂铃 + 顶端小花 | 轮廓横向展开，摆锤每 3.7s 摆一次 |
| III · 幼苗 | 发条幼苗 `SPRING SEEDLING` | 短茎、两片子叶、一只小发条盒与上链环 | 5 瓣小花 + 1 枚待放花苞 | 最低、最暗，靠近栏杆，像刚从土里上紧发条 |

每株都有：爪形底座、套管枝干、黄铜/铜绿叶片、铰链花瓣、至少一组可见的齿轮传动。齿轮总数 ≤ 40，花瓣总数 ≤ 120。

## 3. 机械与生态规则

### 3.1 发条与齿轮

- 三株的齿轮周期分别取 **47s / 73s / 101s**（互质），每组齿轮按传动比反向旋转；周期只决定转速，不决定开花。
- 悬停 = 上发条：2s 内转速提升到 1.4×，移开后以约 20s 的时间常数回落到 1×。视觉上齿轮变快、漏光略亮、花心宝石更暖。
- 所有齿轮角度由累计相位驱动，暂停时冻结；页面隐藏时停止累计。

### 3.2 花期

- 每株有独立花期：主株 257s、副株 311s、幼苗 349s。一个周期里约 30% 闭合、8% 打开、32% 盛开、8% 收拢，其余时间静止。
- 花瓣开合由花心齿轮的凸轮驱动：外轮先张、内轮后张；闭合时花瓣叠成一枚金属花苞，不是简单缩小。
- 初始相位经过挑选：`t=100` 时主株与副株盛开、幼苗闭合，保证默认首屏有“开 / 合”的对照。

### 3.3 检修

- 每 15 分钟进入一次 40s 检修：轮换一株，6s 内整株折叠、花瓣收拢，阀口喷出蒸汽，约 30s 后重新展开。
- 自动检修窗口在每个 900s 周期的 `600–640s`；手动「检修」按钮可立即触发同一套动作。
- 蒸汽 ≤ 60 个半透明粒子，只在检修时出现，生命 2.5–5s，向上漂散后淡出。

### 3.4 循环

- 三株齿轮周期互为质数，画面在 12 小时内不会出现可辨认的重复。
- 相机每 180s 在三个展台间做一次 20s 的横移，其余时间停稳；镜头另有 ±0.8% 的呼吸式缩放与极缓的上下浮动。
- 所有累积状态（蒸汽、上链能量、相机位置）都有上限或衰减；不出现整屏重置。

## 4. 交互与 HUD

| 操作 | 行为 |
| --- | --- |
| 悬停 / 触摸按住某株 | 上发条，2s 内转速 +40%，20s 内回落 |
| 点击某株 | 手动开花 / 收拢；25s 后交还自动花期 |
| `1` `2` `3` | 相机对准主株 / 副株 / 幼苗，并给该株一次上链脉冲 |
| `Space` | 暂停 / 继续 |
| `H` | 隐藏 / 显示 HUD |
| `F` | 全屏 |
| 面板「检修」 | 对当前展台触发 40s 检修 |

- HUD 是博物馆标签：左上标题、右上开花读数、左下花期/摆轮/检修倒计时、右下「展台设置」。
- 16s 后标题与读数淡出，只留极暗的状态点；任何按键或指针移动可恢复。
- 桌面层收不到指针时，花期、齿轮、检修、相机、蒸汽全部自动运行。

### URL 参数

| 参数 | 含义 |
| --- | --- |
| `still=1` | 静止帧 |
| `still=0` | 强制播放（覆盖系统减少动态效果） |
| `hud=0` | 隐藏 HUD |
| `seed=20261110` | 场景种子 |
| `t=100` | 初始时间（秒，0–86400） |

减少动态效果：默认静止，并在面板提供「继续」；窗口缩放时仍重绘一帧。

## 5. 预算与实现

- 目标 30 FPS；单画布渲染像素 ≤ 260 万，像素倍率 ≤ 1.5。
- 背景（丝绒、磨砂玻璃、机械虚影、噪声）与前景（栏杆、水珠、反光、雾点）在 `resize` 时一次性烘焙到离屏画布。
- 齿轮轮廓、花瓣、叶片使用 `Path2D` 缓存；每帧只做变换与填充，不重建路径。
- 每株花瓣 ≤ 120、齿轮 ≤ 40；三株合计 ≤ 360 花瓣、120 齿轮。
- 蒸汽 ≤ 60；尘埃 ≤ 80；不在每帧创建大面积渐变。
- 页面隐藏时取消动画调度；恢复时重置时钟，避免后台时间造成跳跃。

## 7. 实现差异与验证记录

- **实现差异**：为了让三种屏幕比例都保持“标本柜”读法，竖屏没有复用横屏的柱式展台，而是改为带黄铜托架的壁挂石搁板；超宽屏在左右各加一座失焦展台剪影。花瓣的“厚度”用偏移暗影 + 内侧提亮 + 单侧断线高光表达，没有额外几何层。
- **验证脚本**：`scripts/verify-garden.cjs`。Node 内用 VM 模拟 4 种尺寸各 10 分钟，并覆盖上链、手动开花、检修、暂停、隐藏页面；随后 Electron 离屏加载真实 `file://` 页面，检查四尺寸渲染、确定性、动画与暂停、按键、面板、减少动态效果、窗口缩放、离线请求与壁纸库识别。
- **验证结果**：2026-11-10 全部通过。四种视口各 620s 模拟 + 90s 检修恢复；峰值蒸汽 54/60，花瓣 76/360，齿轮 20/120；`seed=20261110&t=100` 两次加载像素级一致；离屏服务帧 35 个蒸汽粒子、主株折叠 1.00；超宽屏与 4K 以 0.5× 缩放的 CSS 视口跑通 3440×1440 / 3840×2160 布局与像素预算；无控制台错误、无网络请求；壁纸库识别标题「机械植物园 / The Clockwork Botanic Garden」。离屏宿主帧率约 17–19 FPS，真实 GPU 桌面层目标为 30 FPS。
