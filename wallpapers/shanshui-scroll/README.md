# 山水长卷 · 四时流转

一卷会自己展开的水墨山水。镜头以每秒七像素缓缓右移，远山从雾里一层层推近；春的青绿、夏的石青、秋的赭石、冬的冷灰在二十四分钟里走完一轮。云、舟、雪、雨都从同一套墨色与笔法里长出来。

画面全部由 Canvas 2D 程序绘制，没有图片、视频、外部字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「山水长卷 · 四时流转」并预览、应用。`preview.png` 是实际渲染截图。

- 指针掠过江面：生成三圈涟漪，并惊起一只水鸟。
- 按住拖动：改变风向，芦苇、雾带、雨丝与松枝随之偏移；松手后慢慢回到自然风。
- 轻点画面：切到下一季；落在江面时同时留下涟漪。
- `←` / `→`：上一季 / 下一季。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示画面文字。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 右下角「观卷」：选择时令、天气、风向，或进入全屏。
- 开场标题与读数约十四秒后淡出；设置按钮保持低亮度，悬停或键盘聚焦时显示。
- 系统启用「减少动态效果」时默认静止，可点右下角播放按钮或按 `Space` 继续。

## 四季与天气

一轮 24 分钟，每季 6 分钟；白天 16 分钟、夜晚 8 分钟。春、夏为昼，秋由午后入暮，冬为月夜并在末尾回到黎明。季节用纸色、山体淡染、树叶与落花一起过渡，不做硬切。

天气由种子生成一条 24 分钟循环的表，状态为晴 / 雾 / 雨 / 雪，每段最短 90 秒，段间 12 秒交叉淡化；冬天才会落雪。`?weather=` 可强制天气，`?season=` 可直接跳到某一季。

- **春**：浅青绿、岸边桃花、薄雾。
- **夏**：石青与浓荫，雨后山骨更重。
- **秋**：赭石、夕照、枫叶与更长的江面。
- **冬**：冷灰、雪顶、月夜与冻水。

## 镜头与循环

- 横向展卷：正交无透视，镜头以 `7 px/s` 向右平移；每 5 分钟叠加一次 ±2.2% 的极缓推拉。
- 竖屏立轴：镜头锁在一座主峰上，以约 8 分钟为周期自上而下缓移，只保留一座主峰。
- 卷长 4800 世界像素，地形由整数周期的正弦与周期山峰叠加，横向取模；相机越过卷尾时画面无缝接回卷首。
- 江面三叶小舟以不同速度缓行；水鸟每 85–150 秒自发从江面起飞一次，不依赖鼠标。
- 页面隐藏时停止调度；恢复后重置时间戳，时间继续但不会跳帧。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数与设置按钮；按 H 可恢复 |
| `still=1` | 静止画面 |
| `still=0` | 显式播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 山形、树、天气表的种子 |
| `t=150` | 场景时间（秒），默认 150；超过 1440 会自动按轮取模 |
| `season=spring` | `spring`、`summer`、`autumn` 或 `winter`，跳到该季中心 |
| `weather=clear` | `clear`、`mist`、`rain` 或 `snow` |
| `wind=-0.4` | 初始风向，范围 -1–1 |
| `quality=0.7` | 细节密度，范围 0.45–1 |

静态海报：`wallpaper.html?still=1&hud=0&season=autumn&weather=mist`。

纯壁纸：`wallpaper.html?hud=0`。

固定春景：`wallpaper.html?season=spring&weather=clear&hud=0`。

## 运行预算

- 目标 30 FPS；实际帧率取决于设备与宿主。
- 渲染像素上限 260 万，像素倍率上限 1.5；4K 下自动降低后备分辨率并柔和放大。
- 4800×1280 的远中景卷轴、4800×520 的前景岸石各烘焙一次；每帧只重绘水、雾、舟、芦苇、松枝、天气与 HUD。
- 远山 3 层 × 12 峰；树 60；舟 3；雨丝 400、雪片 400；水鸟 ≤ 3；涟漪 ≤ 24。
- 页面隐藏时取消动画调度；暂停或减少动态效果时仍响应窗口尺寸变化并重绘。
- 相同 `seed` 与 `t` 得到同一帧。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-shanshui.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-shanshui.cjs --write-preview
```

脚本在四种尺寸下各模拟 10 分钟，检查季节权重、天气段长、粒子与对象上限、像素预算、卷轴首尾无缝、同种子复现、暂停/隐藏调度、减少动态效果与静态重绘。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查横屏、竖屏、超宽屏、4K、四季、雨雪、交互、HUD、窗口缩放、离线运行与壁纸库元数据。

Electron 截图写入系统临时目录 `lumen-shanshui-scroll-check/`。这些检查不等同于 Windows 原生 WebView2 桌面挂载测试。
