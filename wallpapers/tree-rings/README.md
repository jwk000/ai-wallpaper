# 年轮档案 · 一棵树的编年史

一段锯开的树干横截面占满画面。年轮从髓心一圈圈长出来：旱年窄、丰年宽，某几年带着火灾留下的黑疤；木射线像星芒射出，一道主裂纹从髓心斜向右下。侧光在一昼夜里极慢地换角度，光里的尘埃一直在翻。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「年轮档案」并预览、应用。`preview.png` 是实际渲染截图（1920×1080，HUD 关闭）。

- 移动指针：指针下的那一圈年轮浮起极淡的年份刻度，约 3 秒后自动淡出；右下角同时给出「第 087 年 / 1927 / 丰水 / 4.2 mm」。
- 单击画面：把当前截面导出成一张 1920×1080 的明信片 PNG，角落四行小字——日期、seed、标题、强调色。播放不中断。
- `←` / `→`：逐圈翻年，回看任意一年；选中态停留约 3.4 秒后淡出。
- `Esc`：清除当前选中的年轮。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 14 秒后自动淡出。
- `F`：进入 / 退出全屏。
- 右下角「档案设置」：暂停、全屏、自动生长、年轮刻度、换一段截面、导出明信片、生长节律（6 小时 / 1 小时 / 1 天一圈）。
- 系统启用「减少动态效果」时默认静止，可以手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，年轮继续生长、光继续换角度、尘埃继续翻，画面依然完整；年轮刻度只是加法。

## 年轮规则

- **气候序列**：种子由日期派生（默认取本地当天，`?day=` 可回看某天，`seed=` 可覆盖）。每圈年轮的气候值取自种子化序列：低频丰枯周期叠加逐年抖动，干旱年成簇出现。年轮宽度 = 幼年因子 × (0.30 + 2.30 × 湿润度) × 逐年抖动，因此旱年只有 2–3px、丰年可到 20px 以上。
- **一圈的材质**：每圈是一个从早材到晚材的径向渐变，晚材是外侧 30–40% 的低饱和深褐带；约五分之一的年轮会在某一侧断续消失，像真实的断轮。年轮边界带 2–3 个低频谐波，整片木头共享同一组弯曲，所以纹路平行而不会互相穿插；髓心附近另加一点幼年不规则。
- **导管孔**：4000 枚，按年轮宽度加权撒在早材带里；大部分是 1–3px 的深褐椭圆，14% 带一颗朝光一侧的亮点，像刚被照到的导管口。
- **木射线**：每个树种 92–154 条，从髓心附近射到树皮，越靠近受光侧越亮；另有一层切向的射线斑（浅色短弧）和很淡的纤维、径向纹、锯痕。
- **裂纹**：3–6 条，主裂纹从髓心斜向右下作引导线，其余较短。裂纹是带锥度的暗楔：越靠外越宽，干旱年经过的地方再宽一点；一侧留一条受光唇线，另一侧压一道软阴影。
- **火灾黑疤**：每个截面 0–2 处，用平滑随机边界的楔形焦痕表示，边缘有一圈浅色的愈合脊和散落的炭屑。
- **树皮与景深**：截面外圈是深褐树皮，有径向裂缝与切向棱；整块木盘烘焙后先做一次 0.6px 的镜头柔化，再叠上清晰的孔、纤维、裂纹和树皮，最后按半径做浅景深——越靠外越虚，像微距镜头。
- **光**：一盏侧光。24 小时里方位在左上方 ±0.55 弧度内缓慢摆动，另叠加 300 秒的细微呼吸；阴影侧用 multiply 压暗并偏冷，受光侧用 soft-light 加暖，再叠一条斜向高光和一块灯下的热斑。镜头每 24 小时做一次 1.00 → 1.06 的极慢推近，不旋转。
- **生长**：最外一圈永远是「正在长」的半圈，6 小时（可调 1 小时 / 1 天）走完一年；每闭合一圈，整块木盘重新烘焙一次，镜头做 1.4% 的回收。一轮结束后镜头拉远 4.5%，淡入另一段树截面，换树种与产地，不硬切。
- **日签**：默认 seed 由当天日期派生，当天完全稳定；跨天时（每 45 秒检查一次本地日期）用 2.6 秒交叉淡入换到新截面，并更新年份标签。`?day=2026-11-11` 可回看历史某天，`seed=` 仍可覆盖。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数、年轮卡片和设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 截面种子；固定后复现年轮宽度、裂纹、孔与射线 |
| `t=10800` | 起始时间，单位秒（0–30 天）；同一 `seed` 与 `t` 渲染同一帧 |
| `day=2026-11-11` | 日签日期，决定默认 seed 与年份标签；`seed` 优先 |
| `pace=6` | 每圈年轮多少小时长成（1–24，默认 6） |
| `grow=0` | 关闭自动生长，停在当前年轮 |
| `ticks=0` | 关闭悬停年份刻度 |

静态海报：`wallpaper.html?still=1&t=10800&seed=20261111&hud=0`

纯壁纸：`wallpaper.html?hud=0`

固定种子的纯壁纸：`wallpaper.html?seed=20261111&hud=0&pace=1`

回看某天的日签：`wallpaper.html?day=2026-11-11&hud=0`

## 运行预算

- 动画目标 30 FPS；主循环按约 30 FPS 节流（两次渲染间隔不足 29ms 就跳过），模拟用真实经过时间。
- 每张画布最多约 260 万渲染像素，`devicePixelRatio` 上限 1.5，并按面积回退；4K 下 dpr 约 0.56。
- 年轮硬上限 240 圈、每圈 256 个闭合点；一段截面的上限为 98–176 圈。导管孔 ≤ 4000，木射线 ≤ 160（每个树种 92–154 条再乘 0.86–1.16），裂纹 ≤ 6（硬上限 7），尘埃 210，悬浮木屑 60。
- 整块木盘（树皮、年轮、柔化）只在载入、尺寸变化、每闭合一圈（默认 6 小时）和换截面时烘焙；每帧只增量绘制最外 3 圈、全部射线与裂纹、生长前沿、光效、尘埃和覆盖层。
- 每帧约 400 次绘制：1 次背景 blit、1 次木盘 blit、3 圈年轮渐变、约 130 条射线、3–6 条锥形裂纹、2 条边材弧、3 次全屏光、约 270 个尘埃精灵、1 次覆盖层 blit。
- 背景、覆盖层与木盘各烘焙到离屏画布；环境层按 0.4–1 倍尺寸生成，木盘按渲染分辨率生成，模糊与景深只在烘焙时做。
- 页面隐藏时取消动画调度；恢复时重置时间戳，避免后台时间造成跳帧。暂停或减少动态效果时仍响应窗口尺寸变化并重绘。
- 年轮、导管孔、射线、裂纹全部来自同一个种子化 PRNG；同一 `seed` 与 `t` 两次加载渲染完全一致。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-tree-rings.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-tree-rings.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查年轮数量与上限、每圈点数、导管孔/射线/裂纹预算、坐标有限、像素预算、生长节律（6 小时 / 1 小时 / 1 天）、自动生长开关、截面到顶后的换段、手动换段、悬停年份刻度 3 秒淡出、左右翻年、明信片构图、日签派生与跨天交叉淡入、暂停、隐藏页面、缩放与确定性复现。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的实际渲染、像素分布、动画推进、悬停刻度与年轮卡片、翻年、点击导出 PNG、暂停、隐藏页面、HUD 自动淡出、减少动态效果、无控制台错误与无网络请求，并用 `scanWallpapers` 确认本机壁纸库能识别且无问题项。截图写入系统临时目录 `lumen-tree-rings-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动生长、日签与光线的变化是必要的保底。
