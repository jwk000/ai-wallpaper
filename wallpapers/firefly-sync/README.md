# 萤火同步 · 夏夜的耦合

夏夜草坡上，两千多个萤火各闪各的。它们只和身边一小圈同伴以及整片草坡的平均相位打交道，谁也不听指挥；可耦合一旦升起来，一整片山坡会先亮一下、再像潮水一样从一侧漫到另一侧，然后散开——十五分钟后，同样的呼吸再来一次。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「萤火同步」并预览、应用。`preview.png` 是实际渲染截图。

- 移动指针：惊扰 150px 内的个体，打散局部相位；这一小片会在几秒内重新被拽回队伍。
- 按住拖动：形成一阵风，把个体推开、把同步波推歪；松手后约 20 秒内衰减。
- 轻点画面：230px 内的一小片同时亮一次，随后重新并入整体的波。
- 右下角「夏夜设置」：暂停、全屏、自动微风、指针惊扰、换一片草坡、重新聚拢。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 16 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- 系统启用「减少动态效果」时默认静止，可手动播放，或在地址后加 `?still=0`。

桌面宿主收不到鼠标时，自动微风、耦合呼吸和同步波照常运行，画面依然完整。

## 夏夜规则

- **相位**：每个萤火的相位按 Kuramoto 方式演化，固有周期 5.3–9.7 秒（个体差异 ±29%）。它既耦合到所在网格单元（约 74×72px）的局部平均场，也以一个较小的权重耦合到全场的平均场；个体还各自带 0.55–1.0 的耦合增益，所以永远不会整齐得像机器。
- **去滞后相位**：单元里平均的是 `φ = θ + lag`，其中 `lag` 是随位置线性变化的相位偏移。这样"行进波"不会被当成无序，场才能真正锁定；锁定之后 `θ = φ - lag` 自然表现为一道从一侧扫到另一侧的波前。
- **耦合呼吸**：`K` 在 15 分钟里按余弦从 0.40 升到 0.90 再落回 0.40；同步波的空间跨度同时从约 0.5rad 拉到 2.4rad。K 高时全场连贯（R ≈ 0.9），K 低时散成几团（R ≈ 0.4）。
- **个体**：2200 个（竖屏 980；`detail` 可再降），40–90 秒一个生命周期，淡入 2.5 秒、淡出 4 秒，寿终后就地换一只新的，总数恒定。
- **分布**：40% 落在 (0.55w, 0.55h) 的高斯核里，34% 沿着草坡脊线漂成一条斜带，其余散在草坡上；三个景深层（远 26% / 中 56% / 近 18%）各有自己的尺度与亮度。
- **成像**：萤火是预渲染的暖黄绿光斑，带一点朝漂移方向的短拖尾；辉光先画进半分辨率缓冲，再叠两次放大的拷贝形成光晕。草叶全是纯剪影，前景左右下角是失焦的草与光斑，暗角与颗粒收边。
- **镜头**：机位固定，只有 ±1% 的横向漂移（周期 197 秒）与 95 秒一轮的焦点呼吸；不推拉、不旋转。
- **不重置**：相位、位置、生命周期都是连续状态；画面在几十分钟内不会重复。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数和设置按钮，适合纯壁纸或截图；按 H 可恢复 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 夏夜种子；固定后复现个体分布、尺寸、色彩与漂移相位 |
| `t=75` | 起始时间，单位秒；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=6` | 播放态启动前额外回溯多少秒（0–8），让第一帧的同步波更自然 |
| `breeze=0` | 关闭自动微风（指针交互仍然可用） |
| `touch=0` | 关闭指针惊扰与点按闪光 |
| `detail=0.6` | 降低萤火、星点与草叶密度（0.5–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=75&seed=20261111&hud=0`

纯壁纸：`wallpaper.html?hud=0`

安静的一夜：`wallpaper.html?seed=20261111&hud=0&breeze=0&touch=0`

## 运行预算

- 动画目标 30 FPS；本机离屏验证为 1920×1080、竖屏、21:9 均为 30 FPS，4K 约 26–28 FPS，实际帧率取决于设备与宿主。
- 每张画布最多约 260 万渲染像素，像素倍率上限 1.5；4K 时 dpr 自动降到约 0.56。
- 萤火硬上限 2200；空间网格 26×15（竖屏 13×28，上限 390 格）；辉光缓冲上限约 115 万像素，随尺寸退到 0.30–0.58 倍。
- 每帧只更新相位、亮度与位置；每帧绘制调用约 2800–5000 次（光斑、拖尾、单元辉光、亮核），无累积型全屏缓冲。
- 静态层（夜空、远山、草坡、草叶、前景、暗角、颗粒）在尺寸变化时烘焙到离屏画布，每帧只做两次整屏合成。
- 主循环按 1/30 秒节流；页面隐藏时取消动画调度，恢复后重置时间戳，避免后台时间造成跳帧。
- 暂停或减少动态效果时仍响应窗口尺寸变化并重绘。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-firefly-sync.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-firefly-sync.cjs --write-preview
```

脚本先在 Node 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查个体数量、网格上限、相位范围、耦合呼吸（0.40 ↔ 0.90）、同步度随耦合起落、密度峰位置、生命周期替换、指针惊扰与恢复、点按闪光、拖动风、自动微风、暂停、隐藏页面、缩放与确定性复现。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的渲染、亮度分布、暖色萤火、动画推进、指针惊扰、点按、暂停、缩放、HUD、减少动态效果、无网络请求和无控制台错误。截图写入系统临时目录 `lumen-firefly-sync-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动微风是必要的保底。

设计文档见 [`docs/design/firefly-sync.md`](../../docs/design/firefly-sync.md)。
