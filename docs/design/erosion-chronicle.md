## 1. 一句话概念

一张正在被雨改写的山。它不画写实光影，而是像十九世纪的地质调查图那样，用等高线、细排线、河流和冲积扇把地形「刻」在暖米色纸上：雨落下时沟谷加深、冲积扇摊开；六分钟后地壳抬升，山又长回去。

它不是地形演示，也不是粒子雨景，而是一张**会继续被制图的山**。

### 设计原则

1. **先是一张好地图，才是一套地形算法。** 任何时刻截屏都要成立：主峰在左三分之一，河从右上流向左下，冲积扇压在左下，右下留给直尺与铅笔。
2. **地形只通过制图语言表达。** 等高线、排线、网点、河流、扇面是唯一的明暗手段；没有照片纹理、没有塑料高光、没有写实投影。
3. **慢，且不重复。** 十分钟一轮，侵蚀 6 分钟、抬升 1 分钟、稳定 3 分钟；每轮换抬升种子，地形不会原样重播。
4. **可复现，且有硬预算。** 512×288 高度场、144 个屏幕图块、脏块按需重算、河流流量 10 秒一次；同一 `seed` 与 `t` 必须渲染同一帧。

## 3. 高度场与地形

### 3.1 网格

```
COLS = 512
ROWS = 288
CELLS = 147,456
MAP_W = 1.78          // 世界坐标宽（16:9）
TILT = cos(25°) = 0.9063
```

高度归一化在 `0..1`。世界坐标 `x ∈ [0, 1.78]`、`y ∈ [0, 1]`；屏幕投影为：

```
screenX = (x - view.x0) * view.k
screenY = (y - view.y0) * view.k * TILT
```

`view` 由尺寸与构图锚点决定；`TILT` 就是 25° 斜俯视的正交压缩，无透视、无旋转。

### 3.2 初始地形

`seed` 化 Perlin 噪声上的 ridged fbm，经三次处理：

1. **广域起伏**：扭曲坐标后取 4 个倍频的 ridged noise，叠加 `broad`、主山体椭圆掩膜、东南次峰和北侧远山；原始高度约 `0.05 + 0.30·ridge·(0.45+0.55·mask) + 0.20·mask + 0.10·broad + 0.075·mid + 0.085·topRange + 0.12·massif2·ridge`。
2. **两遍 3×3 平滑**：去掉一格一格的「群岛」，让等高线成片。
3. **峰、谷、扇**：
   - 主峰锥：`+0.42·exp(-d² / 0.0060)·(0.82 + 0.32·grain)`；
   - 峰顶钉：`+0.060·exp(-d² / 0.0018)`，保证主峰在 `(0.40, 0.40)`；
   - 两处肩峰：`+0.070·exp(...)` 与 `+0.045·exp(...)`；
   - 五条河道各按距离做 `−0.30 / −0.15 / −0.12 / −0.11 / −0.10` 的高斯刻蚀；
   - 左下冲积平原压平到 `0.048 + 0.012·grain`；
   - 细粒噪声 `+0.020·fbm(u·13, v·13, 3)`。

最后线性归一化到 `0.025–0.965`，记录初始均值 `initialMean`。`seed` 只决定初始地形与所有随机序列；`t` 只决定当前轮内的相位与显示高度。

### 3.3 每轮的两张纹理

每轮开始时（`cycleIndex` 变化）预计算两张与高度场同尺寸的纹理：

- **侵蚀纹理 `E`**：
  - 2,400 条雨滴路径，从高处随机出发，沿双线性梯度下坡 55–80 步，在 3×3 邻域累积重量；
  - 一次 3×3 盒式模糊；
  - 归一化到 `target·0.50`（`target = 0.060–0.076`）；
  - 高坡整体下削 `target·0.12·smoothstep(0.15, 0.95, base)`；
  - 五条设计河道用 `target` 的高斯截面重新盖印（主河 σ=0.022，支流 σ=0.016），保证「沟谷先加深」在地图上可见；
  - 截断到 `target`。每轮重算，不跨轮累积。
- **抬升纹理 `U`**：两个低频 fbm（2.35 与 1.25 倍频）叠加，乘 `0.35 + 0.85·base`（高处抬得更多），归一化到 0–1；每轮抬升幅度 `upliftAmpMax = 0.038–0.060`。

显示高度：

```
height(x,y) = clamp(base + upliftEff·U - pEff·E, 0, 1)
```

`pEff` 是量化到 120 档的侵蚀进度（每档 3 秒），`upliftEff` 是量化到 60 档的抬升（每档 1 秒）。量化既让等高线按图块重绘，又保证同一 `t` 的显示高度是确定值。

### 3.4 换轮与地壳均衡

第 600 秒把本轮末态写回 `base`：

```
base ← base + upliftAmpMax·U - E
```

随后：

1. 均值向 `initialMean` 回拉 50%（地壳均衡回补）；
2. 若最高点低于 0.80，按比例把起伏拉回约 0.92，防止山被削平；
3. 若最高点高于 0.955，整体压缩起伏到 0.955，防止山长到纸外；
4. 换新的 `cycleIndex`，重算 `E`、`U`、水系、雨序和测高点。

因此每一轮的地形都不同，但主峰位置与高度范围始终稳定。

## 4. 等高线与制图语言

### 4.1 等高线

- **36 级**，等高距 `1/36 ≈ 0.0278` 个高度单位；每 5 级一条计曲线。
- **marching squares** 在屏幕图块内运行：每个图块先取覆盖它的高度网格（含一格余量），再逐格判断四条边与 36 个级别中哪些相交；一个格子通常只跨 1–2 级。
- 所有首曲线合并成一条路径、所有计曲线合并成另一条路径，各用两笔画出：
  - 首曲线：`2.2px @ 12%` 的墨晕 + `0.76px @ 88%` 的实线；
  - 计曲线：`2.8px @ 15%` 的墨晕 + `1.24px @ 98%` 的实线。
- **线距**：高度场是等距场，线距随坡度变化。1920 宽的主峰坡面上实测约 7–12px，平均接近条目的 8px；平坦台地自然变疏。这是等距线图的正确行为，而不是固定像素间距。
- **标注**：每块图按 `(tx·2 + ty·3) mod 6` 选一个计曲线级别，在块内找一段接近水平的线段，用纸色小底把线打断，再写海拔（米）。每块最多一个，避免刷屏。
- **测高点**：每轮开始时找高度场最大值作为主峰，另在四处固定位置放次峰；画 4px 三角与海拔数字。主峰标注与真实最高点一致，误差小于 10m。

### 4.2 排线与网点

- 屏幕间距 `spacing = clamp(min(w,h)·0.0092, 6.5, 13)`；1920×1080 约 10px。
- 在间距网格上采样高度梯度；坡度 `< 0.60` 不画排线，只按概率撒网点。
- 排线沿最陡下降方向，长度 `3.2 + 6.8·min(1.6, slope)` px；坡度越大，线越长、越深。
- 排线分两档透明度（13% / 36%），每块图各合成一条路径，只画两次。
- 强坡（`slope > 0.95`）再补一条平行侧线，形成铜版画的「双线阴影」。
- 河流经过的格子（`riverMask`）跳过排线，避免河床被划花。

### 4.3 经纬网与图例

- 经纬网在**地图坐标**里，每 0.1 个世界单位一条，随图块一起缩放；线宽 0.55px、透明度 7.5%。
- 图例卡在屏幕右上：`LÉGENDE`、`FEUILLE VII · 1 : 50 000`、四种线样、比例尺。它先以 0.62× 采样再放大，形成虚焦；卡片底色 97% 纸色、边框 46% 墨色。
- 地图纸面另有一层 `rgba(185,160,119,.13)` 的手绘暖晕，中心在主峰，半径 0.66 个短边；它不随高度变化，只是「这张纸被手绘过」的暗示。

### 4.4 脏图块缓存

- 屏幕分成 `16 × 9 = 144` 块（与分辨率无关，4K 也是 144 块）。
- `pEff` 每 3 秒变一档、`upliftEff` 每 1 秒变一档，变化时把 144 块全部标脏。
- 每帧最多重绘 **10 块**（4K 等高倍率时降为 6 块）；一次完整烘焙 144 块。
- 单块重绘内容：经纬网、暖晕、排线/网点、等高线、计曲线、海拔标注、测高点。清空只清本块，绘制裁剪到块外扩 1px，避免接缝。
- 河流、冲积扇、雨、指针、前景不进入图块缓存。

## 5. 水文

### 5.1 设计河道

为了让构图可读，主河与四条支流先以归一化坐标写成折线：

```
RIVER_MAIN   (0.955,0.050) → (0.165,0.890)   右上 → 左下
RIVER_TRIB_A 从 (0.285,0.175) 汇入主河中段
RIVER_TRIB_B 从 (0.815,0.520) 汇入主河下段
RIVER_TRIB_C 从 (0.615,0.110) 汇入主河中段
RIVER_TRIB_D 从 (0.120,0.500) 汇入主河下段
```

这五条河道同时用于地形刻蚀、侵蚀纹理盖印、初始 `riverMask` 和最终水系；因此地图上的河谷与蓝色河线始终对齐。

### 5.2 D8 汇流与流量

- 在 `256 × 144` 的粗网格上取 2×2 高度平均；
- 用 256 个高程桶做 O(N) 排序，从高到低按 D8 最陡下降推送累积量；
- 每条设计河道按 7–10 段细分，采样粗网格累积量，得到河宽与流量；
- 另外从未被设计河道覆盖的高累积格出发，向上游追最多 110 步，补充最多 4 条支流；
- 每 **10 秒**重算一次粗网格高度与累积量，河宽在 `0.5–3.4px` 之间变化。

### 5.3 绘制

- 每条河三层：纸色描边（`width + 2.4px`，90% 纸色，切断等高线）→ 青灰主色（80–94% 不透明）→ 深青中心线（34% 宽，52% 不透明）。
- 暴雨时再叠一条沿河下行的虚线（`2.2 / 13px`，偏移 `-t·7.5`），表现水在流动。
- 主河上斜排一行 `Rivière de l'Érosion`，旋转角归一化到 ±90°，不会倒着写。
- 河流只画在相机变换内，随缩放同步。

## 6. 冲积扇

- 扇心在河口 `(0.180, 0.878)`；半径 `0.135 + 0.185 · pEff`，从 0.135 长到 0.32 个世界单位。
- 外缘不是标准圆弧：56 个采样角上叠加两组合成的半径扰动（±5.5% / ±3%），得到手绘感的扇缘。
- 扇面是无硬边的径向渐变：扇心 `rgba(181,154,111,.60)` → 中段 40% → 外缘 12%；外面再罩一层 7% 的羽化边。
- 内部九条辫状水道：每一条从扇心向外弯曲，走到 55% 处再分叉一次，线宽从 1.25px 收到 0.4px。
- 七圈断续同心弧，每圈分成三段；另有 300 个随进度生长的沙点。
- 扇口画一个小三角，标注 `Cône de déjection`（斜排、纸色底）。
- 扇面随 `pEff` 生长，因此十分钟循环里能看见它「摊开」。

## 7. 雨、侵蚀与抬升

### 7.1 天气

- 雨强基线：侵蚀期 0.30、抬升期 0.09、稳定期 0.19。
- 每轮由 `seed + cycleIndex` 派生 7–15 场阵雨（默认种子为 9 场），起始间隔 40–86 秒，持续 7–16 秒，峰值 0.24–0.80；包络 `sin(πu)^0.72`。
- 点击画面立即插入一场 10–14 秒、峰值 0.62 的阵雨；最多同时保留 3 场。
- 雨强上限 1.0；`rain=0` 时全部归零。

### 7.2 雨丝与落点

- 雨滴池 320 条；按 `(110 + 230·intensity)·areaScale` 取可见数量，`areaScale = clamp((w·h)/(1920·1080), 0.35, 1.15)`，竖屏与超宽屏密度一致。
- 雨滴位置是 `t` 的解析函数（相位 + 速度取模），不是累积模拟；因此静止帧也有完整的雨。
- 线长 17–50px，倾角约 16°，线宽 1.12px，三档透明度 34% / 54% / 72%。
- 24 个确定性落点涟漪：每个涟漪有固定相位与速率，位置由 `floor(t·rate)` 的哈希决定，半径 1.2–9.7px，椭圆压缩 0.52。
- 雨强 > 0.03 时叠一层极淡的湿蓝灰；不改变地形颜色。

### 7.3 侵蚀的实现方式（重要说明）

条目写的是「侵蚀 6 分钟（每帧 2–3 滴雨）」。实现采用**每轮预计算侵蚀纹理 + 量化进度播放**，而不是每帧真的改动 2–3 滴雨落点的邻域高度：

- 原因一：要满足「同一 `seed` 与 `t` 确定性复现」，逐帧粒子侵蚀会依赖帧时序；
- 原因二：512×288 高度场上每帧改局部高度并重算脏块，会把 6 分钟的预算打满，且容易累积漂移；
- 原因三：预计算纹理可以在每轮开始时一次完成，运行期只按 3 秒一档的进度播放，视觉上仍是「沟谷持续加深」。

雨滴的「2–3 滴/帧」在运行期由 `impacts` 计数表达：每个 1/30 秒模拟步累加 2–3 次撞击，调试接口 `snapshot().impacts` 可读。这是本作品唯一一处对条目字面速率的降级，已在此与 README 的「运行预算」中写明。

### 7.4 抬升

- 抬升期 60 秒：`upliftNorm = smoothstep(0, 1, (ct - 360)/60)`，`upliftEff = quantize(upliftNorm, 60) · upliftAmpMax`。
- 抬升场是低频 fbm × 高度权重，因此高处抬得快、河谷抬得慢，等高线会从山顶向外「长」。
- 抬升结束后保持到第 600 秒，再写回高度场并进入下一轮。
- 指针抬升是另一条路径：直接对 `base` 加一个半径 0.052 世界单位、二次衰减的局部隆起；一次拖动最多 0.45 个高度单位，松开 1.5 秒后重建水系。

## 8. 循环与时间

| 时间 | 阶段 | 行为 |
| --- | --- | --- |
| 0–360s | 侵蚀 | `pEff` 0→1（120 档，每 3 秒一档）；沟谷加深，扇面摊开 |
| 360–420s | 抬升 | `upliftEff` 0→最大（60 档，每 1 秒一档）；等高线向外扩张 |
| 420–600s | 稳定 | 地形静止；河流、雨、镜头继续 |
| 600s | 换轮 | 写回高度场、均衡回补、换抬升种子、重算纹理/水系/雨序 |

- 相机缩放周期 **300 秒**，`cameraZoom = 1.02 + 0.02·sin(2πt/300 + φ)`，范围 1.00–1.04。
- 阵雨间隔 40–86 秒；单场 7–16 秒。
- 河流流量 **10 秒**一次。
- 没有全局重置；`resetTerrain` 是显式用户操作，`R` 键也只回到初始种子地形。
- 页面隐藏时停止 `requestAnimationFrame`；恢复时把 `last` 清零，不补帧、不跳帧。

## 9. 相机与交互

### 9.1 相机

- 正交，25° 斜俯视；`TILT = cos 25° = 0.9063`。
- 三种构图视窗：
  - 横屏：`viewH = 1.0`，`viewW = aspect · viewH · TILT`，主峰锚 `0.40 / 0.40`；
  - 竖屏：`viewH = 0.94`，`viewW = aspect · viewH · TILT`，主峰锚 `0.50 / 0.34`；
  - 超宽：`viewH = 0.82`，`viewW = aspect · viewH · TILT`，主峰锚 `0.40 / 0.40`。
- 视窗被夹在纸面内，避免出现空白边；超宽时铺满全宽。
- 自动推拉用屏幕变换实现，不重新烘焙图块；用户缩放 1.0–1.35 也走同一路径。

### 9.2 交互

| 操作 | 行为 |
| --- | --- |
| 指针移动 | 显示 24–34px 的黄铜虚线环与十字 |
| 按住拖动 | 沿指针轨迹抬升地形，半径 0.052 世界单位，二次衰减；脏块立即刷新 |
| 单击 | 插入一场 10–14 秒的阵雨（`rain` 被关闭时自动打开） |
| 滚轮 | 以指针为中心缩放 1.0–1.35；暂停时仍重绘 |
| `Space` | 暂停 / 继续；暂停时先 flush 图块再重绘 |
| `H` | 隐藏 / 显示 HUD |
| `F` | 全屏 / 退出全屏 |
| `R` | 重置地形 |
| 面板 | 暂停、全屏、自动降雨、指针抬升、回到全图、重置地形、换一张图幅 |

- 所有交互都有自动兜底：不移动指针也有阵雨、抬升、河流流量和镜头呼吸；`rain=0` / `uplift=0` 只关闭对应的交互/视觉，不影响画面成立。
- 桌面宿主收不到鼠标时，自动循环和雨序照常运行。

## 10. 渲染与性能

### 10.1 图层与缓存

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 纸面 | `paper` 全分辨率 | 尺寸变化时重建 |
| 地图 | `map` 全分辨率 | 144 块脏块缓存，每帧最多 10 块 |
| 图例 | `legend` 全分辨率 + `legendSmall` 0.62× | 尺寸变化时重建 |
| 前景 | `fore` 全分辨率 + `foreSmall` 0.18× | 尺寸变化时重建 |
| 覆盖 | `overlay` 全分辨率 + `grain` 0.5× | 尺寸变化时重建 |
| 高度场 | `Float32Array(512·288)` × 4 | base / erosion / uplift / riverMask |
| 水文 | 256×144 | 每 10 秒重算一次 |
| 雾/河/扇/雨 | 无累积缓冲 | 每帧重画，数量封顶 |

### 10.2 预算

- 目标 30 FPS；逐帧渲染，`dt` 上限 0.05s。离屏 Electron（禁用 GPU）1280×800 实测 **约 31–32 FPS**，4K 约 30 FPS。
- 主画布 ≤ 260 万渲染像素；`devicePixelRatio` 上限 1.5，并按面积回退。1920×1080 时倍率约 1.12。
- 高度场 147,456 格；图块 144；每帧最多 10 块（4K 为 6 块）。
- 等高线 36 级；每块最多 1 个海拔标注；测高点 5。
- 河流 ≤ 14 条、每条 ≤ 220 点；实际约 9 条、340 点。
- 雨丝 ≤ 320；涟漪 24；扇沙点 300；扇水道 9。
- 每帧绘制调用：地图 1 次合成 + 纸面/图例/前景/覆盖各 1 次 + 河流约 27 条路径 + 扇约 330 次描边/填充（含 300 个沙点） + 雨 3 次批量描边 + 24 个涟漪 + 指针环。
- 侵蚀纹理每轮开始重算一次（2,400 条路径 + 五条河道盖印）；运行期不逐帧改高度场。
- 页面隐藏时取消调度；恢复时重置时间戳；暂停、减少动态效果和缩放时仍重绘。

## 16. 实现差异与降级

1. **侵蚀按轮预计算，不逐帧改动雨滴邻域。** 运行期用 3 秒一档的量化进度播放；`impacts` 计数保持 2–3 次/1/30 秒的节奏。这是为确定性、预算与防止累积漂移做的取舍，详见 7.3。
2. **等高线线距不是固定 8px。** 等距线图的线距由坡度决定；本实现主峰坡面约 7–12px，平均接近 8px，平坦处更疏。这是地图语义正确的做法。
3. **25° 斜俯视是正交 y 轴压缩（cos 25°），没有真正的 3D 投影。** 与条目的「正交、不旋转」一致。
4. **河网以五条设计河道为主，D8 支流为辅。** 设计河道保证构图（右上→左下），D8 汇流只负责流量与补充支流；因此河流不会像纯水文模拟那样偏离构图。
5. **冲积扇是实时矢量图形，不是高度场沉积。** 它的生长由侵蚀进度驱动，保证十分钟内可见地「摊开」。
6. **前景与图例的虚焦用降采样放大实现**（0.18× / 0.62×），不依赖 `ctx.filter`，在离屏 Electron 与桌面宿主上行为一致。
7. **雨丝数量随视口面积缩放**（0.35–1.15），避免竖屏雨过密、超宽屏雨过疏。
8. **`t` 限制在 0–3600 秒，预演最多 24 轮。** 条目没有要求日签或跨天机制，本作不实现 `day`；`seed` 与 `t` 即可复现全部状态。
9. **`rain=0` 是视觉/天气开关，不暂停侵蚀。** 侵蚀仍按十分钟循环推进；如果希望完全静止，请用 `still=1`。
