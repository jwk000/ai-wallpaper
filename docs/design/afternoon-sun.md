## 1. 一句话概念

一间极简的房间，一束带窗格形状的阳光落在木地板上，跟着窗外**此时此刻**的太阳慢慢爬。尘埃只在光里显形；日落后房间转蓝，台灯自己亮起来。它不播放循环动画，它查询时间。

### 设计原则

1. **先是一张照片，才是一个程序。** 任何时刻截屏都要成立：窗在左上、光斑压在左下的地板上、右侧大面积留白墙面、家具只是剪影、画面里没有人。
2. **光由太阳推导，不由时间轴播放。** 方位角/高度角来自本地时间、时区、经纬度；光斑是窗格顶点经太阳射线投到地板的四边形。改变日期，"同一个下午"的画面就不同。
3. **一个主角运动。** 只有光斑在移动；尘埃、窗帘、台灯都是呼吸。没有推拉摇移，没有镜头运动。
4. **慢，且不加速。** 1:1 真实时间，24 小时一轮；不做"一分钟看完一天"的演示模式。
5. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` / `t` / `day` 渲染同一帧。

- **超宽 21:9**：沿用横向相机，多出来的宽度全部给右侧留白墙；窗被推到 `0.14–0.30w`，光斑仍在 `0.35w`，家具在最右。

### 2.2 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 墙 | `#d8cbb8` | 基准值，实际亮度在 0.70–1.04 之间按位置与光照调制 |
| 地板 | `#8a5f3c` | 基准值，靠墙 0.46×，靠镜头 1.10× |
| 正午的光 | `#f2e6d0` | 冷白，`sin(alt) ≈ 0.58` 以上 |
| 黄昏的光 | `#e8a860` | 暖橙，`sin(alt) ≈ 0.04` |
| 天光（玻璃上沿/下沿） | `#c6dbe6` → `#f0e8d6` | 晴天；`sin(alt) ≈ 0.32` |
| 夜间房间 | `#1a2033` | `sin(alt) < -0.20`；实现取 `#1c2333` → `#161b28` 相邻两档 |
| 台灯 | `#d8a45e` | 灯罩纸与灯池 |
| 强调色（meta / HUD） | `#c9a15b` | 与库内强调色一致 |

- **色标**：墙面/地板/光/天光上/天光下/环境亮度五个量，在 9 个以 `sin(alt)` 为轴的色标之间用 smoothstep 插值：`-0.60 / -0.20 / -0.07 / -0.01 / 0.04 / 0.14 / 0.32 / 0.58 / 1.00`。因此色温是连续变化的，没有"白天模式/夜晚模式"的硬切。
- **明度结构**：玻璃是画面最亮的地方（正午接近纯白）；光斑次之（比周围地板亮 1.6–2.2 倍）；墙从中灰到浅米；地板最深。四级层次靠亮度而非颜色区分。
- **饱和度**：除黄昏的光斑与台灯外，整体饱和度压在 40% 以下；墙与地板始终是低饱和的暖灰。
- **颗粒**：烘焙一层约 1.6 万个 1 px 的亮/暗点（透明度 1–3%），这一层是"照片"与"渐变色块"的分界线。

### 2.3 层次

| 层 | 内容 | 更新 |
| --- | --- | --- |
| 背景 | 墙的竖向渐变、窗的光晕与方向性衰减、玻璃、窗棂与窗洞阴影 | 每帧（少量渐变） |
| 中景 | 光斑（12 个四边形）、地板木纹与板缝、踢脚线、家具剪影与台灯 | 每帧 |
| 前景 | 窗帘的 8 条正弦带、帘缘阴影、5 枚离焦光斑、暗角 | 每帧 |

- 中景是唯一清晰层；背景只有渐变与颗粒；前景的帘子略微柔化（三次偏移叠加）并压住左侧约 15%，不遮挡光斑主体。
- 家具（矮柜 + 台灯）只作为剪影：台面是透视四边形，两条腿，台灯是一个梯形灯罩加一根细杆；白天它比墙暗一档，夜里只留下灯罩这一点暖光。

## 3. 太阳与投影

### 3.1 太阳位置

输入：本地时间、时区偏移 `tz`（小时，东为正）、经度 `lon`（缺省 `15 · tz`）、纬度 `lat`（缺省 31.2°）、年积日 `doy`。

```
γ  = 2π/365 · (doy − 1 + (hour − 12)/24)
eq = 229.18 · (0.000075 + 0.001868cosγ − 0.032077sinγ − 0.014615cos2γ − 0.040849sin2γ)   // 分钟
δ  = 0.006918 − 0.399912cosγ + 0.070257sinγ − 0.006758cos2γ + 0.000907sin2γ − 0.002697cos3γ + 0.00148sin3γ
TST = hour·60 + eq + 4(lon − 15tz)                 // 真太阳时（分钟）
H   = (TST/4 − 180)°                               // 时角
sin(alt) = sin(lat)sin(δ) + cos(lat)cos(δ)cos(H)
cos(az)  = (sin δ − sin(lat)sin(alt)) / (cos(lat)cos(alt))，H > 0 时 az = 360° − az
```

- 日出/日落由 `cos(H₀) = −tan(lat)tan(δ)` 解出，得到当日日照长度与本地日出、日落时刻，显示在设置面板里。
- 验证：2026-11-11、31.2°N、120°E 时正午高度约 41.3°，日照 10.5 小时；实测 −76.2°–41.6°、10.54 小时，与手算一致。

### 3.2 相机

一台固定的针孔相机（不是 3D 引擎，只是把世界点投到屏幕的公式）：

```
世界：X 右、Y 上（地面 Y = 0）、Z 远离相机
相机位于 (0, E, 0)，俯角 p（向下为正）
F = (0, −sin p, cos p)   U = (0, cos p, sin p)   R = (1, 0, 0)
zc = P·F   yc = P·U   xc = X
sx = cx + f·(X − panX)/zc      sy = cy − f·yc/zc
```

| 布局 | f | E | 俯角 p | panX | 备注 |
| --- | --- | --- | --- | --- | --- |
| 横屏 / 超宽 | `1.6880·h`（≈35mm 等效，垂直视角 33°） | 0.95 m | 8.3° | 0 | 同一台相机，超宽屏只是更宽 |
| 竖屏 | `0.9800·h` | 0.95 m | 12.0° | −0.86 m | 转向窗，视场更宽以同时容下窗与光斑 |

反投影（屏幕点 → 墙面 / 地面）也有闭式解，用于把窗的屏幕矩形反推成世界尺寸，以及判断某一点是否被光斑照到。

### 3.3 窗

窗在后墙 `Z = 4.6 m` 上：世界中心 `X = −1.62 m`，宽 `1.0 m`，高 `0.55–1.43 m`（窗台 0.55 m，一个偏低的长窗），分 3 列 × 4 行，共 12 格、20 个顶点。它的屏幕矩形是投影的结果，不是写死的坐标：横屏落在 `0.051–0.269w`、`0.071–0.402h`。

### 3.4 光斑

窗格的每个顶点 `(u, h)` 按太阳方向抛出射线：

```
reach = (h / tan(alt)) · REACH_GAIN          // 沿太阳水平投影方向走过的水平距离
Z     = clamp(Zw − reach·cos φ, 1.05, Zw − 0.28)
X     = Xwin + (u − 0.5)·Wwin + reach·sin φ
φ     = az − WINDOW_AZ，clamp 到 ±75.7°
```

`REACH_GAIN = 0.600`，`WINDOW_AZ = 194.0°`（窗大致朝南偏西）。四角投影后得到光斑四边形，12 个格各自成为一个小四边形。

- **落点校准**：2026-11-11 15:12（高度 20.5°、方位 233.4°）时，光斑中心落在 `(0.370w, 0.732h)`，条目要求的是 `(0.35w, 0.70h)`。验证脚本对这一帧做 ±0.05w / ±0.05h 的断言。
- **随日移动**：正午光斑短、贴墙、偏左；下午向右滑并朝镜头方向拉长；日落前被拉成一条从窗下延伸到画面下缘的长斜线。
- **强度**：`smoothstep(0.014, 0.16, alt)` 让太阳贴近地平线时淡出，再乘上"光斑落在画面内的面积比例"，因此光斑滑出画面时会自然变暗，而不是硬切。太阳在地平线以下时光斑强度为 0。
- **绘制**：先画进 0.22× 的离屏缓冲（每格单独填充，格与格之间留 7–10% 的窗棂缝），再 `source-in` 染成当刻的光色，然后一次 blur 得到软边；合成时先以 `source-over` 把地板换成被照亮的地板（这一步让它"亮"而不是"发光"），再以 `lighter` 叠一层锐利的热芯。窗外还有一圈很淡的暖色光晕（半径约 1.25 倍光斑尺寸）。

## 4. 窗帘

- **8 条正弦带**，每条有独立的振幅 `0.35–1.10`、频率 `1.6–4.0`、相位与漂移速度；带的和决定帘子右缘的位置：

```
edge(t) = baseEdge + Σ bandSway(i, t) · unit · 0.42 + push · 0.085w
bandSway(i,t) = ampᵢ · sin(t·kᵢ·2.4 + phaseᵢ + τ·wᵢ) · (0.32 + 0.68t)
```

- `τ` 是当日秒数，所以窗帘摆动与尘埃一样是时间的纯函数；`push` 是指针推动量，按时间常数 3.4 秒衰减。
- 帘面用三次偏移叠加模拟浅景深，再叠 8 条"圆管"状的明暗梯度形成褶皱；底部有一条悬挂阴影，右缘有一条硬一点的投影，让它确实站在房间前面。
- 帘子压在窗的左半边上，所以**帘缘的位置直接决定哪几格窗格透光**：绘制光斑时，每一格的透明度取该格在**窗面**上的覆盖值（不是地板上），指针推开帘子时光斑就跟着缺一块。这一条是交互能有"物理感"的关键。

## 5. 尘埃

- **200 枚**，位置是时间的纯函数：

```
x = u·w + sin(τ/41 + px)·ax·w + sin(τ/17 + 1.7px)·0.35ax·w
y = v·h + sin(τ/33 + py)·ay·h + sin(τ/13 + 1.3py)·0.30ay·h
```

周期 27–41 秒，全部有界，没有任何累积量。

- **只在光里被点亮**：把屏幕点反投影到地板平面，再解析地反解出它在窗面上的 `(u, h)`，落在 `[0,1]²` 内即被照亮，边缘用 `smoothstep(0, 0.12, inset)` 柔化。因此"哪里亮，尘埃就在哪里出现"，不需要跟踪光斑形状。
- **初始分布**沿光斑一天的路径撒点：每枚尘埃随机取一个 7:12–17:36 的时刻，算出那一刻的光斑，落在里面。密度于是跟着光走，而不是均匀铺满房间。
- **亮度**：`(0.055 + 0.945·lit) · gain · twinkle`，按 3 档批量成路径一次填充；光斑外的尘埃透明度约 5%，几乎不可见。
- **前景**：5 枚半径 34–118 px 的离焦光斑，作为前景的"空气中的大颗粒"，透明度随环境亮度变化。

## 6. 家具与台灯

- **矮柜**：世界坐标 `X 0.58–1.42 m`、`Z 3.62–4.42 m`、高 `0.46 m`，8 个角点经开方投影得到梯形台面与两条腿，所以它的透视与房间一致，不是贴上去的。台面用木色（暗于地板一档），远边有一条受光高光。地面有接触阴影。
- **台灯**：灯罩是 `0.62–0.92 m` 的梯形，灯杆细，白天是暖白的剪影。
- **开关逻辑**：`lampAuto` 为真时跟随太阳——环境亮度 `amb < 0.42`（约太阳贴地平线）就亮；点击或面板开关则进入手动状态并保持到页面重载。`?lamp=1/0/auto` 可在 URL 层强制。
- **夜间的光**：灯罩自发光，加一圈半径 `0.55 × max(w,h)` 的暖色径向光晕，落在地板上形成一道光池。肖像布局里台灯在画框外，但光晕的边缘仍然从右侧渗进画面。

## 7. 交互

| 操作 | 行为 | 自动兜底 |
| --- | --- | --- |
| 指针移动 | 拨动窗帘（推动量 ±1，帘缘最多移动 0.085w），光斑随之缺角 | 窗帘按 8 条正弦带自己摆动 |
| 点击 | 开 / 关台灯（进入手动状态） | 日落后自动亮，天亮自动灭 |
| `Space` | 暂停 / 继续；暂停时仍响应缩放与重绘 | — |
| `H` | 隐藏 / 显示 HUD；开场 12 秒后自动淡出 | — |
| `F` | 全屏 / 退出全屏 | — |
| 设置面板 | 暂停、全屏、台灯、指针拨帘、日出日落读数 | — |

- 每个交互都有自动对应物，所以桌面宿主收不到鼠标时画面完全成立。
- 手动台灯状态不会自己跳回去（那不像现实中的开关），但房间本身的色温、窗外的天光仍然完全跟随太阳，所以夜里手动关灯也不会"卡"在一张死画面上。

## 8. 循环与时间

- **没有人为循环**：`tOfDay` 与真实时间 1:1 前进，24 小时一轮；跨过午夜时日期与年积日一起更新（若 `day` 未在 URL 固定）。
- 时间尺度：窗帘 9–27 秒一个来回；尘埃 27–41 秒；尘埃闪烁 11–29 秒；台灯亮度过渡 0.45 秒；指针推动 3.4 秒衰减；光斑随太阳移动的时间常数是"小时"级。
- 稀有事件由**真实天象**提供：蓝调时刻、日落、日出、季节变化，一小时到几个月一次，不需要额外脚本。
- 页面隐藏时停止调度；恢复时重置时间戳，避免后台时间造成跳帧（时间本身连续）。

## 9. 渲染与性能

### 分层与缓存

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 灰泥颗粒、大尺度斑驳、木纹、板缝、板色、踢脚线 | `texCanvas`（设备分辨率） | 尺寸变化时重建 |
| 暗角、顶部压暗、胶片颗粒 | `vigCanvas`（设备分辨率） | 尺寸变化时重建 |
| 光斑掩膜 | `pbuf`（0.22×） | 每帧重画 12 个四边形 |
| 光斑柔化 | `psoft`（0.22×） | 每帧一次 blur |
| 离焦光斑 sprite | `bokehSprite`（128×128） | 一次 |
| 尘埃 / 窗帘 / 光斑顶点 | 数组 | 每帧更新 |

### 预算

- **30 FPS**：`requestAnimationFrame` 里用 33.3 ms 的帧闸门；`dt` 取真实经过时间，上限 0.12 s。验收时 1.2 秒内帧数应在 10–42 之间。
- 画布像素预算 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退（4K 时 0.56）。
- 每帧绘制调用约 90–140 次：墙 3–4 次、地板 2 次、纹理 1 次、窗 10–14 次、光斑 12 次填充 + 2 次合成、家具 8 次、尘埃 3 次（批量）、窗帘 6 + 8 次、离焦 5 次、暗角 1 次。
- 两次全屏合成（纹理、暗角），没有累积型全屏缓冲。
- 太阳位置每帧重算；光斑 20 个顶点每帧重投影；不做全屏噪声。
- 所有随机数来自种子化 PRNG；颗粒、木纹、尘埃初值、窗帘相位由 `seed` 决定，光斑与色温由 `t` / `day` 决定。
- 页面隐藏时 `cancelAnimationFrame`，恢复时重置时间戳；`prefers-reduced-motion` 默认静止。

## 10. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、开关台灯、开关指针拨帘。
- 减少动态效果时默认静止在当前时刻；HUD 保持可见，暂停按钮即手动播放入口。
- HUD 在浅色墙上是深墨色，进入夜间自动切换成浅色（`body.dim`），对比度始终足够。
- 画面文字只承担标题与读数，不承载唯一信息。

## 11. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261111` | 种子；决定尘埃初值、窗帘相位、颗粒 |

## 13. 与条目规格的差异 / 降级

如实记录，不做静默忽略：

1. **光斑落点做了构图补偿。** 严格的物理投影在 4.6 m 深的房间里会把下午的光斑推到镜头脚下甚至画外（`tan(alt)` 越小越远）。实现中用 `REACH_GAIN = 0.720` 把落点收进画面，并用"画面内面积比例"衰减强度。这不是物理精确的尺度，而是把真实方向、真实位移趋势保留下来、把距离压进构图的折中。正午偏短、黄昏拉长、左右随方位滑动这些**行为**都是真的。
2. **低太阳时直射光斑会退出画面。** 太阳低于约 8° 时，物理光斑已经跑到镜头身后；真实情况下光会打到对面墙和天花板上，而画面里没有那面墙。实现让光斑淡出、整室转为暖环境光与蓝色时刻——这是有意为之的取舍，不是遗漏。
3. **窗外的景只做了一层极淡的地平线雾**，没有树、建筑或天空细节：条目要求"尘埃是唯一的高光粒子"，窗外保持过曝的空白更符合极简房间的调子。
4. **竖屏是重新取景而非裁切。** 相机俯角、焦距、横向 pan 都变了；代价是竖屏里窗与光斑的世界间距在窄画幅中无法同时完整容纳，所以窗的左缘被裁掉一小部分、光斑的右端越出画框——条目里"对着窗的局部"本身就允许这样。
5. **台灯手动状态不会自动恢复自动模式**，直到页面重载或再次点击。理由是"灯被打开又被自动关掉"不自然；房间本身的色温仍然完全跟随太阳。
6. **没有云与直射遮挡模型**：任何白昼时刻窗都是直接受光的，阴天不会变暗。
7. **帧率上限 30 FPS**（共用规格要求），不是"尽力跑满刷新率"。光斑移动本身是小时级的，30 FPS 对尘埃与窗帘也足够。

## 14. 实现结构

```text
wallpapers/afternoon-sun/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 太阳/投影）
├─ meta.json          标题、副题、描述、标签、强调色、排序（6.7）
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、日光规则、URL 参数、验证说明

docs/design/afternoon-sun.md   本设计文档
scripts/verify-afternoon-sun.cjs  模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、URL、工具函数；
2. 色标表与 `gradeAt(sinAlt)`；
3. 太阳位置与日出日落；
4. 相机、布局（横/竖/超宽）、窗与家具的世界坐标投影；
5. 尘埃与窗帘带的初始化（沿光斑路径撒点）；
6. 静态层烘焙（灰泥、木纹、板缝、踢脚线、暗角、颗粒、离焦 sprite）；
7. 光斑计算与 `patchLightAt()`；
8. 每帧绘制（墙、地板、纹理、窗、光柱、光斑、家具、尘埃、窗帘、离焦、暗角）；
9. 主循环、输入、HUD、调试接口。

运行时暴露调试入口 `window.__lumenSun`（`snapshot` / `audit` / `advance` / `setClock` / `toggleLamp` / `setLamp` / `stirCurtain` / `releaseCurtain` / `sampleIllum` / `render` / `togglePause`），供 `scripts/verify-afternoon-sun.cjs` 使用；不参与视觉，不影响普通播放。
