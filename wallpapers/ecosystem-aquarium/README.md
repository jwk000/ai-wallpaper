# 澄屿 · 生态鱼缸

一个完全离线的 WebGL 3D 动态壁纸。鱼缸外部采用柔和的天青色背景与同色地面，保留轻微落地阴影。相机位于鱼缸外，近距离观察一个带椭圆开口的横向椭球形玻璃鱼缸。连续曲面玻璃带弧面反光、加厚缸口、环形水位线和小型椭圆底座；椭圆沙床上分布着岩石、水草、分枝珊瑚和沉木。生物与造景组合是艺术创作。

## 使用

在流光壁纸库中找到「澄屿 · 生态鱼缸」，或直接用支持 WebGL 的浏览器打开 `wallpaper.html`。HTML 已内嵌 Three.js 0.160.1，无需联网或启动服务器，也不依赖相邻资源文件。

- 相比此前球形版本，横向扩大 48%、前后加深 18%、高度压低 14%，按几何比例内部容积约增加 50%。鱼、鳐鱼、乌龟和螃蟹保持原有身体比例，游动轨迹映射到扩大的椭球空间。
- 默认 42 条鱼，四种外观；设置中可切换为 24 / 42 / 64 条。鱼群在椭球版本基础上放大 35%，保留不同种类的体型差异，并按体型扩大缸壁转向净空和个体避让距离。
- 沙床表面位于缸体自底部向上约五分之一处，石头、水草、珊瑚、沉木与螃蟹同步抬高；沙层填充至椭球壳底部。水位约为缸体高度的 78.5%，顶部保留明显的空气空间。
- 鱼群从初始帧即分布于上、中、下三个水层，每条鱼有不同的巡游高度与缓慢升降。靠近椭球形缸壁时会向内转向，并保留身体长度所需的安全距离。
- 鱼群采用三维位置和速度，包含同类聚集、方向协调、个体分离、边界转向与岩石回避。鱼身由连续曲面构成，带收窄尾柄、嘴部、鳃盖、细鳞片、背腹色差与湿润反光；半透明尾鳍、背鳍、臀鳍与成对胸鳍带有鳍条。身体后段随尾部推进弯曲。每条鱼有独立巡游速度，随时间缓慢加减速；身体和尾鳍摆动频率随实际速度变化，避免鱼群整齐地以同一速度推进。转弯时始终保持背部朝上，水平朝向与俯仰分别平滑变化；上浮和下潜时最多轻微抬头或低头约 12.6°，不侧翻或翻滚。
- 两只乌龟改为沿沙地缓慢爬行，体型分别放大约 45% 和 60%；连续圆润的龟甲带嵌入式甲片细缝与生长纹，补充皮肤颗粒、眼睛高光、鼻孔、嘴线和脚爪。四肢交替迈步，头部轻微摆动；两只螃蟹在底部缓慢横行。
- 两只半透明水母分别呈浅蓝色与淡粉色，在不同高度缓慢漂游。伞体周期性收缩，带放射状管纹和裙边；细长触须与四条褶皱口腕随水流摆动，两只使用不同的收缩相位。
- 保留一只蓝灰色鳐鱼：闭合的背腹曲面具有中央肉质厚度、圆润的胸鳍边缘、细斑点、背侧眼睛、呼吸孔和腹部鳃裂；尾根加粗并连续收窄成长尾。胸鳍以柔和的行进波起伏，沿鱼缸内侧外围绕行，交替经过前景、两侧和后景；路径连续升降，前侧较低、后侧较高，转弯时轻微侧倾，身体朝向跟随路线切线。默认约 114 秒一圈，独立于鱼群数量设置。
- 水草重新塑造成长带状苦草、沿茎轮生的细叶水草和少量带叶柄的椭圆阔叶。长叶上端弯垂，茎叶随水流缓慢摆动，两翼继续延伸到椭圆沙床外侧。岩石使用平滑不规则表面与细颗粒、藻色纹理。
- 中央设置完整的环形假山，具有不均匀厚度、风化凹凸、岩层与藻斑，底部连接支撑山石。部分鱼群会在洞口前后循环穿行，其余鱼群保持分层巡游；鱼群转向及碰撞净空包含环形岩体。
- 椭圆水面使用不同方向、速度和振幅的细波，叠加连续噪声与气泡出口的局部涟漪；环境灯光反射随水面法线变化。沙地与岩石上的焦散来自独立运动、扭曲变形且亮度不均的光斑，不使用规则正弦网纹。全部在本地生成。
- 沙床增加不规则藻斑、细碎沉积物与 280 粒砾屑；8 枚带放射状凸纹和生长纹理的双壳贝静置在沙地；小虾从 14 只减少为 8 只，活动触须、步足并偶尔短距离跃游。气泡使用光滑圆球，独立于椭球鱼缸缩放，边缘反光而中心透明，在水位线下结束；悬浮微粒限制在椭球体内部。
- 相机始终在缸外，按椭球形轮廓自动贴近并居中，优先占满约 96% 屏幕宽度或 94% 高度。横屏下更充分地利用屏幕宽度，其他屏幕比例保持完整轮廓。玻璃采用透明混合与简化反射，水面反光为程序化近似，并非光线追踪的物理折射。
- 鼠标移动产生轻微视角偏移。右下角提供速度、数量、光照控制；空格暂停/继续，H 显示/隐藏界面。标题在 12 秒后淡出。
- 浏览器启用减少动态效果时默认显示静帧；点击「继续」可主动播放。页面隐藏时暂停更新；恢复后不补算隐藏时间。
- 渲染目标为 30 FPS，像素总量上限为 300 万，设备像素比上限 1.7。性能依显卡而异。

查询参数：`?hud=0` 隐藏界面；`?still=1` 静帧；`?still=0` 主动播放。

## 修改与验证

源文件位于 `scripts/aquarium/scene.js` 和 `scripts/aquarium/template.html`。从仓库根目录运行：

```powershell
node scripts/aquarium/build.cjs
node scripts/verify-aquarium.cjs --write-preview
```

验证覆盖 Electron 的本地文件渲染、横屏/竖屏/超宽屏、缸外相机与完整椭球形轮廓取景、静态造景和鱼/龟/鳐鱼的椭球壳边界、鱼/水草/水面/鳐鱼/缸底生物/气泡/水母/乌龟近景、光斑变化、鱼身法线方向、圆气泡等轴缩放、完整穿过环形洞口、贝壳静置及小虾运动、鱼群实际巡游速度差异、逐帧背部朝上与转弯连续性、十分钟确定性模拟及实际水柱内持续分层、鳐鱼完整外围巡游及高低变化、变形后的胸鳍与长尾逐顶点边界、假山及沙床/水面净空、水母数量、漂游与水柱边界、乌龟贴地行走与迈步、有限数值、几何体数量稳定、动画与暂停、调整尺寸、数量和光照控制、减少动态效果、离线请求检查和壁纸库识别。测试截图输出至 `temp/aquarium-check/`。
