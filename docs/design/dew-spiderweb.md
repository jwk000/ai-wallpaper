## 1. 一句话概念

逆光清晨，一张挂在草茎之间的圆网。蛛丝细到几乎看不见，是露珠把它显影；虫撞上来，整张网抖出一圈高频的波，露珠弹落、丝松弛又绷紧；蜘蛛从网心沿辐丝爬到破洞，一圈一圈把捕虫丝补回来。

它不是“蜘蛛网素材”，也不是粒子 demo，而是一张**会自己修补的逆光微距照片**。

**唯一焦点**：被露珠显影的圆网。
**最惊艳的那一秒**：补丝进行到一半，破洞内侧是刚铺上的、还带暖白新丝光的一段弧，外侧还是空的；蜘蛛停在新旧交界处，露珠正从它的步足旁边重新凝结。

### 设计原则

1. **先是一张照片，才是一张网。** 任何时刻截屏都要成立：网有明确的圆心与留白，背景是奶油般的逆光 bokeh，前景一角被虚化的草叶压住。
2. **丝靠露珠显影。** 丝本身只有 0.5–1px、低透明度；真正让网出现的是 214 颗露珠和丝上的露尘。丝在亮背景前是暗的，在暗背景前是亮的。
3. **慢，且不重复。** 露珠 3 分钟一轮，阵风 20–40 秒一次，破损 8–12 分钟一次，机位 2 分钟一次焦点呼吸；没有全局重置。
4. **单文件、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

- **镜头薄雾**：一层以右上日晕为中心的暖色径向辉光（`rgba(255,244,206,0.10)`）与暗角、颗粒一起在尺寸变化时烘焙，让露珠、丝和日晕在空气里散开；逐帧 bloom 因为要做一次全画布回读、在软件渲染下吃掉一多半帧预算，已改为烘焙。

## 3. 蛛网几何与振动

### 3.1 几何

- 24 根辐丝：角度 `i·15° + 抖动(±2°) + 0.16rad`，半径 `0.13R → R`。
- 捕虫丝：对数螺旋

```
r(u) = R · 0.15^u,      θ(u) = θ0 + 2π · 15u,    u ∈ [0, 1]
```

  按**弧长**均匀重采样成 780 个点（`uForArc` 是解析反解），因此外圈点密、内圈点疏，不会在网心糊成一团多边形；绘制时用二次曲线过中点平滑。
- 不规则：半径再乘三层缓慢起伏（`±1.8% sin(2.3θ)`、`±1.0% sin(5.1θ)`、`±0.5% sin(9.7θ)`）、每圈间距 `±4.5% / ±2.2%` 的抖动，并在相邻辐丝之间减去 `0.65%R · sin(π·f)^1.4` 的下垂（f 是两根辐丝之间的归一化角度）。这三样让网不像印刷的靶纸。
- 段数：780 + 24×4 + 6×2 = **888**（≤ 900）。

### 3.2 振动

- 96 个节点：24 个外圈锚点（r = R）+ 3 圈关键节点（0.30R / 0.55R / 0.80R），每圈 24 个。
- 每个捕虫丝采样点在建造时就算好它落在哪两个环带、哪两根辐丝之间（`n00/n01/n10/n11 + wA/wR`），运行时只做 4 次查表 + 双线性插值。
- 环境风：每个节点沿风向做 0.7–4.8px（乘 `unit`）的慢摆（8.6s / 13.7s 两个正弦），振幅随半径 `r^1.3` 增大，阵风时再多 35% 的高频抖动。
- 撞击波：闭式阻尼行波

```
d = |p - p_hit|,  k = 1/(0.135R),  ω = 27 rad/s
a = A · e^(-age/1.45) · e^(-d/0.66R) · sin(k·d - ω·age + φ)
p += tangent(a) + 0.16 · radial(a)
```

  只在 96 个节点上求值；3 个同时存在的撞击事件共 288 次三角函数求值/帧。因为它是时间的闭式函数，任意 `t` 都能直接算出这一帧，静止截图与像素级复现都不需要回放。

## 4. 露珠

- **数量与分布**：214 颗 = 196（捕虫丝）+ 12（辐丝）+ 6（草茎）。沿螺旋每 3–4 个采样点放一颗，尺寸三档：14% 为 13–20px 主珠，38% 为 5–10px，其余 2–5px（1920 基准，随 `unit` 缩放）。
- **生长周期**：每颗一个 168–204 秒的周期：

```
p = fract((t + φ) / period)
p < 0.84 :  scale = 0.26 + 0.74·smoothstep(0, 0.72, p)
p ≥ 0.84 :  q = (p-0.84)/0.16,  scale = 1 - 0.85q, α = (1-q)·0.9, 下落 46q² px
```

  周期互不相同，所以整张网不会同步闪烁；露珠消失后按同一周期从最小重新凝结。
- **材质**：sprite 96×96，含外圈光晕、亮心到暖边的径向渐变、左下暗边（`#3a3a2c`）、右上硬高光、右下小块环境反光；冷白与暖金两版轮换。主珠（≥ 1.3× 阈值）额外叠一层加色辉光。
- **弹落**：撞击时 0.55R 内约四成露珠（种子决定哪些）被弹开：沿撞击方向飞散 `90·unit·age²`，再加 `260·unit·age²` 的重力下落，2.2 秒内淡出。
- **露尘**：丝上另画一层虚线高光（1.0px 实 / 3.4px 空，慢速移动），读作丝线本身的细小水珠；它是纹理，不占 214 颗的预算。
- **破洞里的珠子**：随丝一起消失；补好的丝立刻重新记录到这些珠子，等各自的生长周期把尺寸带回来。

## 5. 破损与修补时间线

| 阶段 | 时间 | 表现 |
| --- | --- | --- |
| 巡网 | 一直 | 蜘蛛在 0.15–0.45R 之间沿缓慢旋转的辐丝来回，268 秒一个周期 |
| 撞击 | 每周期第 22–126 秒（或点击） | 一圈行波、断丝、露珠弹落、一个破洞张开、一只小虫弹开掉出画面 |
| 醒来 | 撞击后 5–12 秒 | 蜘蛛停下，转向破洞所在的辐丝 |
| 爬行 | 26–48 秒（合计 31–60 秒抵达） | 沿辐丝向外爬，步足按走过的距离摆动 |
| 补丝 | 55–95 秒 | 从破洞内缘向外推进，逐圈补回捕虫丝；新丝在 78 秒内带暖白新丝光 |
| 返回 | 42 秒 | 爬回网心，重新开始巡网 |

- **破洞形状**：半径半宽 8.5–14.5%R、角向半角 0.38–0.68 rad，横跨 3–6 圈；外缘留 4 根松松垂下的断丝（`drawTearDetail`）。
- **推进**：`frontier = r_center - rHalf + 2·rHalf·p`，采样点半径小于 frontier 的就算补好了；每段新丝的生成时间由半径线性反推，用来算“新丝光”的年龄。
- **排队**：`spiderFreeAt` 记录蜘蛛下一次空闲的时间；连续撞击时后来者排队，同一时刻只修一个洞。
- **不重置**：整条时间线由 `seed` 与周期序号哈希出来，8–12 分钟一轮，没有整体重播。

## 6. 风与镜头

- **风向**：自动分量 `0.10 + 0.30·sin(2πt/431 + φ)`；拖动时把用户方向按 `manual`（0–1）混进去，松手后以 55 秒时间常数衰减回自动风向。
- **风力**：`0.30 + 0.14·sin(2πt/214) + gust·0.95`，夹在 0.10–1.50；阵风每 20–40 秒一次、持续 5–9 秒、包络 `sin(πu)^1.5`，最多同屏 2 股。
- **机位**：微距平视、正交，不推拉。横向漂移 = `sin(2πt/95)·8px` 与 `cos(2πt/137)·4px`；按 1920 宽、网径 96mm（7.3px/mm）折算峰值约 0.07mm/s，低于 0.2mm/s 的上限。
- **焦点呼吸**：`raw = 0.5 - 0.5cos(2πt/120 + φ)`，`focus = raw^5`，每 2 分钟一次短促的峰值。`focus` 同时驱动三件事：丝的主笔画透明度乘 `1-0.74f`、0.42× 辉光宽度乘 `1+6.6f`、前景大露珠从柔版渐变到锐版。

## 8. 循环与时间

| 周期 | 内容 |
| --- | --- |
| 5–9 秒 | 单次阵风持续 |
| 20–40 秒 | 阵风间隔 |
| 95 / 137 秒 | 机位横向漂移的两个正弦 |
| 120 秒 | 焦点呼吸（rack focus） |
| 168–204 秒 | 单颗露珠的生长–滑落–再凝结 |
| 268 秒 | 蜘蛛巡网一个来回 |
| 431 秒 | 自动风向摆动 |
| 480–720 秒 | 一次完整的破损 → 巡网 → 补丝 → 恢复 |

- 没有整体重置：露珠相位、蛛网形变、蜘蛛状态、风向都是连续的；破洞位置每轮由种子派生，不会重播。
- 页面隐藏时停止调度；恢复时重置时间戳，避免后台时间造成跳帧（时间本身连续）。

## 9. 渲染与性能

### 分层

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 背景 / 日晕 / 薄雾 / 远景草茎 / 浮尘 / 静态 bokeh | `bg`（全分辨率） | 尺寸变化时重建 |
| 背景亮度图 | `lumaCanvas` 56×32 + `Float32Array` | 随背景重建，供丝选亮/暗 |
| 前景草叶 / 暗角 / 颗粒 / 暖色薄雾 | `overlay`（全分辨率） | 尺寸变化时重建 |
| 蛛丝柔光 | `soft`（0.42× CSS） | 每帧重画，放大合成 |
| 暖色镜头薄雾 | 与 `overlay` 一起烘焙 | 尺寸变化时重算，不占每帧预算 |
| 丝 / 露珠 / 蜘蛛 | 顶点数组与 sprite | 每帧更新 |
| bokeh | 12 张 256×256 sprite | 15 张烘焙进背景，5 张每帧漂移 |

### 预算

- 目标 30 FPS；渲染阈值 26ms，`dt` 上限 0.12s。
- 画布像素 ≤ 260 万；`devicePixelRatio` ≤ 1.5，并按面积回退。
- 丝 888 段（上限 900）；露珠 214（上限 220）；节点 96（上限 120）；同时存在的撞击事件 ≤ 5（实际最多 2 个未修的洞）。
- 每帧约 400 次绘制调用：丝 30 个弧段 ×（柔光 2 + 主笔画 2 + 露尘 1）、24 根辐丝 × 2、6 根吊丝、214 颗露珠（其中约 60 次辉光）、蜘蛛约 20 笔、5 块动态 bokeh、3 次全屏合成（背景 / 柔光 / overlay）。
- 无累积型全屏缓冲，也没有逐帧全画布回读；连续运行数小时不会过曝或越来越慢。实测（软件离屏）1920×1080 与 390×844 为 30 FPS，3440×1440 约 28 FPS，3840×2160 约 24 FPS；4K 是唯一低于 30 FPS 的尺寸，代价来自 260 万像素的三次全屏合成，已按像素预算回退到 dpr 0.56。
- 同一 `seed` 与 `t` 的像素哈希一致（Electron 实测）。

## 10. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容与正在发生的事。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、开关自动破损与焦点呼吸、催补丝、换网。
- 减少动态效果时默认静止；HUD 保持可见，提供手动播放入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 11. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 蛛网种子；固定后复现蛛网、露珠、破损位置与时间 |
| `t=60` | 起始时间（秒）；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=8` | 播放态启动前额外回溯多少秒（0–30）；静止态忽略 |
| `damage=0` | 关闭自动破损 |
| `focus=0` | 关闭焦点呼吸 |

## 15. 实现差异与降级说明

Canvas 2D 没有真实的景深、色散与镜头光学，以下条目是**最接近的可控降级**，都经过实测确认“看起来对”，而不是静默忽略：

1. **景深**：背景 bokeh 用 12 张预渲染的软边 sprite 代替真实散景；前景草叶用 9 遍由宽到窄的低透明度描边模拟失焦；大露珠预先烘两版（44px 源放大 = 柔版、320px 源 = 锐版），焦点呼吸时在两者之间交叉淡入。没有逐像素的 CoC（弥散圆）计算。
2. **色散**：不是 RGB 通道分离。丝的高光做 ±0.7px 的暖/冷两次偏移描边，sprite 内部预烘冷暖分离的高光；烘焙的镜头薄雾只做暖色化，不做光谱展开。
3. **振动模型**：不是弹簧–质量数值积分，而是 96 个节点上的闭式阻尼行波。好处是任意 `t` 都能直接求值、静止帧与像素哈希完全确定；代价是波在节点之间是线性插值，网心附近（0.15R 内）整片随第一圈一起动。
4. **焦点呼吸的模糊**：真正的散焦是卷积；这里用“主笔画变淡 + 0.42× 辉光变宽 + 大露珠换 sprite”三件事合起来表达，网不会真的变糊成一团，但焦点确实从网心挪到了前景。
5. **露珠生长**：168–204 秒的周期是分段函数，不是湿度场；每颗露珠的相位由种子决定，因此“3 分钟一轮”在整张网上是错开的，看起来像湿度在变。
6. **捕虫丝圈数**：15 圈（条目未规定圈数，只要求对数螺旋）。再多圈会让 780 个采样点在内圈过密、外圈反而变疏，15 圈是“外疏内密”与采样预算之间的平衡点。
7. **蜘蛛的腿**：8 条腿用二次曲线两段式绘制，按行走距离摆动；没有 IK，脚端偶尔会轻微离丝，在 30 FPS 与 19px 体长下不可见。
8. **前景大露珠的滴水**：每 236 秒滴一次，位置由时间闭式推进，不是流体；它只是画面右下角的一个小事件。
9. **镜头 bloom**：最初实现过逐帧的 1/8 分辨率 bloom（把整帧降到 1/8、暖色化、再 `lighter` 叠回）。它在软件渲染下要做一次全画布回读，单帧成本约 20ms，直接让 1920×1080 掉到 27 FPS、4K 掉到 17 FPS；因此改为“尺寸变化时烘焙的暖色薄雾 + 露珠自带的辉光 sprite”。观感上仍有一层晨光散开的感觉，但不再有整帧级别的光晕扩散——这是为 30 FPS 预算做的明确取舍。

以上降级都不影响八项规格中可验证的部分：四面尺寸、30 FPS、像素与数量预算、页面隐藏停帧、减少动态效果、确定性复现、四种 URL 参数、Space/H/F、交互自动兜底。
