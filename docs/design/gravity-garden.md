## 1. 一句话概念

深空里的一座轨道花园：十八颗天体沿各自的椭圆轨道绕中心星运行，身后拖出长曝光的光丝；这些光丝在几分钟里互相编织，缓慢开成一朵会呼吸的花。偶尔一颗彗星穿过，把花瓣拨乱，再看着它们自己收拢。

它不是星图，也不是天体物理演示，而是一张**会自己继续生长的天文摄影**。用户可以用指针做一枚弱引力透镜、点一颗小行星，也可以完全不管它。

### 设计原则

1. **先是一张好壁纸，才是一个模拟。** 任何时刻截屏都要成立：有清晰的花心、可读的花瓣、干净的深空留白。
2. **运动来自轨道，不来自特效。** 光丝是天体真实走过的位置；彗星真的把天体推开，再被弹簧拉回。没有凭空的粒子爆炸。
3. **慢。** 以分钟为尺度设计循环；不做秒级闪烁，不做整体重置，长时间播放不越积越亮。
4. **小体量、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材与网络；同一 `seed` 与 `t` 渲染同一帧。

- **亮度分布**：以 1920×1080 预览图实测为 **82.8% 暗部 / 16.5% 中间调 / 0.7% 高光**（阈值 0.18 / 0.55），平均亮度 0.141，p99 0.486。比条目里「72 / 20 / 8」更暗：这是一个深空夜景，高光只保留在花心、天体本体与光丝最密处；中间调比例与库内参考作品 `moonlit-fireworks`（78 / 18 / 3.4）接近。竖屏因花占画面更大，实测为 73 / 24 / 2.9。
- **长曝光**：光丝用加色混合累积，越早的段落越暗；拖尾的时间常数 8s，12s 后残差约 22%，30s 后低于 3%，因此视觉上的尾巴约 12–25s，且不会越播越亮。
- **铜版画**：轨道以极细的虚线椭圆、刻度环与确定性颗粒留在背景里，像一本旧天文图谱；花瓣本身是「一束细丝 + 一层羽化尘光」的编织，而不是霓虹管。

### 2.3 层次

| 层 | 内容 | 更新 |
| --- | --- | --- |
| 背景 | 深空渐变、暖色尘晕、两团离焦星云、约 1650 颗静态星点、极淡的刻度环 | 尺寸变化时烘焙 |
| 中景 | 轨道虚线、花瓣光丝、天体本体、中心星、光丝拖尾 | 每帧 |
| 前景 | 3–5 个离焦光斑、尘埃划痕、四角暗角、确定性颗粒 | 光斑每帧轻移；其余烘焙（半分辨率） |

- 中景是画面唯一的清晰层；背景只有点与雾，前景全部离焦且不压过花心。
- 光斑以每帧几十分之一像素的速度漂移，振幅 5–16px、周期 4–8 分钟，只压住画面边缘。

### 2.4 花的结构

- **花瓣**：5 瓣，每瓣由 3 颗天体共用同一瓣朝向、不同半长轴的椭圆轨道组成（内 `0.38–0.46`、中 `0.63–0.74`、外 `0.90–1.00` 花半径）。
- **花瓣的绘制**：每瓣 19 条弯曲的轨道光丝，向心收束、向瓣尖轻微散开；另有一层沿瓣轴拉长的羽化尘光（半径 1.2A × 0.61A 的软椭圆）和一条极淡的发丝轮廓。光丝颜色暖金 7 : 冷青 3，内侧一段更亮、外侧一段自动降为 58%。
- **花心**：正中一颗中心星（半径 `clamp(0.025R, 5, 15)`，暖白圆盘 + 日冕 + 衍射星芒 + 0.42R 的暖色呼吸）；外围 3 颗小半径、低偏心率的快天体织出花蕊。
- **呼吸**：两组构型 A（收拢、偏圆）与 B（张开、偏尖）之间以 300s 为周期插值：半长轴、偏心率、花瓣张角一起变化，整朵花缓慢开合，不做整体重置。
- 花瓣的「张角」由 `bow`（0.36–0.50 rad）与瓣尖散开（0.10–0.15 rad）共同决定；相邻花瓣之间留出 72° 的间隙，其中正对标题的那个间隙被刻意对准左上。

## 3. 轨道模型

### 3.1 世界尺度

- 世界坐标以花半径 `R` 为单位，花心为原点；渲染时映射到 `R × zoom` 像素。横竖屏只改变 `R`、花心位置与构图，不改变轨道结构。
- 每颗天体的轨道由 `(A, e, θ, M0, T)` 描述：`A` 为远心点半径（`0..1`），`e` 为偏心率，`θ` 为花瓣（远心点）朝向，`M0` 为初始平近点角，`T` 为周期。
- 位置由开普勒方程解出：

```
a = A / (1 + e)                     半长轴（焦点在花心）
M = M0 + 2π t / T                   平近点角
E - e·sin E = M                     牛顿迭代 5 次
x = a(cos E - e), y = a√(1-e²) sin E
p = Rot(θ + π) · (x, y)             近心点朝 θ+π，远心点朝 θ
```

- 中心星固定在原点。天体数量 18 颗（5 瓣 × 3 + 花蕊 3），上限 24。
- 平均运动取固定值，不随构型插值改变：这样相位不会在两组构型之间跳变，任何时候 `seed` 与 `t` 都能直接算出同一帧，拖尾也能用解析轨道回放。

### 3.2 呼吸与镜头

- 构型插值 `bloom = 0.5 - 0.5·cos(2π t / 300)`，周期 300s；`A`、`e`、`θ` 各自在 A/B 两组数值间线性插值。
- 相机：正交俯视，无透视。整幅画面以 `0.4°/min` 绕花心缓慢自转；叠加 `±1.5%` 的呼吸式推拉，周期 420s。
- 不做自由环绕、不做俯仰；镜头转向与推拉都是时间的纯函数，因此任意 `t` 都能直接复现。

### 3.3 扰动（速度 Verlet）

天体在解析轨道上运行，另外维护一个相对轨道的小位移 `offset`，由指针透镜、彗星与小行星驱动：

```
a = -k·offset + 外部加速度
k = 7.0,   阻尼按速度乘 1 / (1 + 2.2·h)
```

- 以 `1/120s` 固定子步长做速度 Verlet 积分；`offset` 长度上限 `0.05`（花半径的 5%），速度上限 `0.35/s`，保证扰动不会破坏构图。
- 撤去外力后 2–4s 内回到轨道，最长 8s 内完全收拢。
- 小行星自身是对中心质量做速度 Verlet 的积分体（软化半径 `0.02`，`μ = 0.0006`），寿命 112–172s，最多 10 颗。

## 4. 光丝与拖尾

- **半分辨率加色拖尾缓冲**：`0.5 × dpr` 的离屏画布，每帧先按 `1 - exp(-dt / 8)` 衰减旧像素，再把每颗天体这一帧走过的线段以加色混合补画上去。
- 每帧只做「衰减 + 补线」，不遍历历史点；光丝总段数按 18 条 × 约 360 段估算（6480），远低于 12k 上限，且不会随时间增长。
- 线宽 `1.0–1.45px`，暖色 `255,188,104`、冷色 `122,208,252`；单帧沉积透明度 0.44–0.48，只有重叠处才亮，避免霓虹管观感。
- **首帧可复现**：初始化时用解析轨道回放最近 12s 的画面，把拖尾缓冲填满，因此静止截图与运行画面一致，不存在「刚开始是空的」。窗口缩放时先回放 8s，等缩放停止后再补足到 12s。
- **花瓣光丝**是直接画在主画布上的独立结构（不进入拖尾缓冲），因此不会被累积放大：每瓣 19 条、每条分 2 段（内亮外暗），合计约 190 次描边/帧。

## 5. 彗星

- 自动彗星每 `90–180s` 一颗；有输入时也照常出现。事件时间由种子化的确定性序列生成。
- 轨道：从 `1.7R` 外以直线（带 `0.16` 的轻微弧）穿过，最近距离 `0.20–1.00R`，全程 9–13.5s；一半概率贴近花朵，形成明显扰动。
- 外观：明亮彗核 + 冷色离子尾 + 暖色尘埃尾，尾长 `0.38–0.54R`；彗核进入拖尾缓冲，留下长曝光划痕。
- 扰动：彗星经过时对 `0.42R` 内的天体施加向外的冲量（按距离递减），花瓣被「拨乱」；冲量结束后弹簧把天体拉回，8s 内收拢。实测一次贴近事件的最大位移为 0.028–0.05R（受上限约束），14s 后回落到 0.0000。
- 同时最多 2 颗彗星；彗星不计入天体数量上限。

## 6. 交互

| 操作 | 行为 |
| --- | --- |
| 指针移动 | 指针成为半径 180px 的弱引力透镜：光丝与天体被轻微吸向指针 |
| 按下 | 透镜强度 0.4 → 1.0；松手后按 `τ = 1.3s` 回落到悬停水平，4s 内基本稳定；指针停住 7s 后完全归零 |
| 轻点（不拖动） | 在点击处投放一颗小行星，带切向速度进入轨道，112–172s 后消失；最多 10 颗 |
| `Space` | 暂停 / 继续（暂停时仍响应缩放并重绘） |
| `H` | 隐藏 / 显示 HUD；开场 16s 后自动淡出 |
| `F` | 全屏 / 退出全屏 |
| 设置面板 | 暂停、全屏、自动彗星、引力透镜、投放小行星、重新播种（二次确认） |

- 桌面宿主收不到鼠标时，所有交互对应的自动行为照常运行：彗星自动来、轨道自己在呼吸、光丝自己编织。
- 透镜在指针最近 2.5s 内有输入时可见（画一圈极淡的虚线），离开或停住后自然消失。

## 7. 循环与时间

- 不做整体重置：轨道、光丝、彗星都是连续状态。
- 300s：构型 A ↔ B 的呼吸。
- 420s：镜头推拉的呼吸。
- 90–180s：彗星事件；单次扰动不超过 8s。
- 12s：拖尾回放窗口；拖尾本身按 8s 时间常数淡出。
- 0.4°/min：画面自转，15 小时一圈，单帧内几乎不可察觉，但连续看不会觉得是死图。
- 页面隐藏时停止调度；恢复时重置时间戳，避免后台时间造成跳帧（时间本身连续）。

## 8. 渲染与性能

### 分层

| 层 | 缓存 | 说明 |
| --- | --- | --- |
| 深空 / 星云 / 星点 | `bgCanvas`（全分辨率） | 尺寸变化时重建 |
| 暗角 / 划痕 / 颗粒 | `overlayCanvas`（半分辨率） | 尺寸变化时重建，最后一次合成 |
| 光斑 | 5 张精灵（冷暖光晕、冷暖天体盘、尘光） | 一次生成，每帧 `drawImage` |
| 光丝 | `filmCanvas`（0.5×） | 每帧衰减 + 补线 |
| 天体 / 中心星 / 花瓣光丝 | 无 | 每帧约 250 次绘制调用 |

### 预算

- 目标 30 FPS；`dt` 上限 0.1s，按 `1/30s` 推进，内部 `1/120s` 子步长。
- 实测 CPU 帧预算 **0.6–1.1 ms / 帧**（`advance(1/30)` + `render()`，1920×1080，软件渲染的 Electron 离屏窗口）；离屏合成器本身只跑到约 17 fps，这是无显示环境的限制，不代表真实桌面的刷新率。
- 画布像素预算 ≤ 260 万；`devicePixelRatio` 上限 1.5，并按面积回退。
- 天体 ≤ 24（实际 18），小行星 ≤ 10，彗星 ≤ 2；光丝不随运行时间增长。
- 每帧绘制调用约 100–260 次：1 次背景、1 次拖尾合成、18 个天体、1 个中心星、5 条瓣形尘光、95 条花瓣光丝、≤5 个光斑、1 次半分辨率覆盖层。
- 页面隐藏时 `cancelAnimationFrame`，恢复时重置时间戳；`prefers-reduced-motion` 默认静止。
- 所有随机数来自种子化 PRNG；星点、星云、花瓣角度、彗星时刻都由 `seed` 决定。

## 9. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面内容。
- 设置按钮有 `aria-expanded` / `aria-controls`；开关使用原生 checkbox，焦点有清晰描边。
- 键盘可完成暂停、全屏、开关彗星与透镜、投放小行星、重新播种。
- 减少动态效果时默认静止；HUD 保持可见，提供手动播放入口。
- 画面文字只承担标题与读数，不承载唯一信息。

## 10. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏 HUD，适合纯壁纸与截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 花园种子；固定后复现轨道花瓣、星点与彗星时刻 |
| `t=95` | 起始时间（秒）；同一 `seed` 与 `t` 渲染同一帧 |
| `warm=12` | 首帧前回放多少秒光丝，默认 12，最大 30 |
| `comet=0` | 关闭自动彗星 |
| `lens=0` | 关闭指针引力透镜 |
| `detail=0.6` | 降低星点与颗粒密度（0.55–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&t=95&seed=20261110&hud=0`

纯壁纸：`wallpaper.html?hud=0`

## 12. 实现结构

```text
wallpapers/gravity-garden/
├─ wallpaper.html     单文件实现（HTML + CSS + Canvas 2D + 轨道模拟）
├─ meta.json          标题、副题、描述、标签、强调色、排序
├─ preview.png        Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md          操作、轨道规则、交互、URL 参数、验证说明

docs/design/gravity-garden.md   本设计文档
scripts/verify-gravity.cjs      模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、工具函数、构图；
2. 轨道参数与开普勒求解；
3. 静态层烘焙（深空、星云、星点、暗角、颗粒）；
4. 光丝拖尾缓冲与首帧回放；
5. 扰动、彗星、小行星、指针透镜；
6. 每帧绘制（花瓣光丝、天体、中心星、光斑）；
7. 主循环、输入、HUD、验证钩子。

运行时暴露调试入口 `window.__lumenGravity`（快照、审计、推进、投放小行星、触发彗星、镜头状态、重新播种），供 `scripts/verify-gravity.cjs` 使用；不参与视觉，不影响普通播放。

## 13. 验证计划

1. **Node 模拟**：`node scripts/verify-gravity.cjs`
   - 四种尺寸各模拟 10 分钟，检查天体坐标有限、数量上限、扰动与速度上限、彗星次数、光丝段数。
   - 检查确定性复现、`t` 驱动的镜头自转与呼吸、彗星扰动收拢、指针透镜衰减、小行星生命周期、5 分钟呼吸、暂停、隐藏、缩放、减少动态效果与 URL 开关。
   - `GRAVITY_STRESS=1` 时追加 60 分钟压力模拟（彗星数、自转角度、坐标有限）。
2. **Electron 实渲染**：同一脚本自动启动 Electron
   - 横屏 / 竖屏 / 超宽屏 / 4K / HUD / 彗星事件截图，检查非空、尺寸正确、亮度分布、像素级确定性、无控制台错误与网络请求。

   - `--write-preview` 时输出 `preview.png`，其余截图写入临时目录供人工复核。
3. **视觉复核**：逐张查看四种尺寸、HUD 与彗星事件截图，确认花心清晰、花瓣可读、深空留白成立、标题不被花瓣压住。
