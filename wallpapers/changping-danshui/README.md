# 长平 · 丹水烽烟图

双击 `wallpaper.html` 即可离线运行。HTML 内含全部样式、Canvas 绘制与模拟程序，不需要安装依赖、联网、图片素材或构建。原有的 `index.html` 金鱼壁纸独立保留。

## 画卷内容

- 秦军：玄色札甲、带缨盔、方盾、“秦”字军旗；赵军：赭红甲衣、束发、圆盾、“赵”字军旗。配色和服饰用于清晰辨别阵营，作艺术化演绎。
- 长矛兵、戈戟兵、盾兵、刀兵、持锤兵、弓手、弩手、持长枪/刀/锤的骑兵、双马战车（车上两人）、鼓手。
- 两侧秦赵营帐、秦垒与赵营木栅、军旗、战鼓、拒马；后景丹水、木桥、上党山林，近景车辙与焚毁的粮车。
- 寻敌、行军、挥击、拉弓、弩射、马腿交替、车轮转动、旗面摆动、火光、烟尘。
- 箭矢按抛物线飞行，落点接近目标才判定命中；近战按距离造成伤害。单位受击、身上留箭、洒血、倒地，地面留下尸体、折旗、掉落武器和战车残骸。
- 一部分秦军骑兵、战车绕过交战正面，迂回至赵军粮道方向再投入战斗；秦军从后方补入，赵军从包围圈内的预备队位置补入，形成断粮与突围的持续交锋。
- 遗留物逐渐消退并限制数量，可持续循环。画卷聚焦长平之战后期战斗，不按真实兵力比例或地理比例复原；循环补员用于动态壁纸，不代表史实中的赵军得到外援。

## 故事背景

公元前260年，秦赵争夺上党。长平战局由廉颇坚壁相持，转为赵括出击；秦将白起以奇兵切断赵军后路和粮道，赵军被围后反复突围。本卷选择“断粮 · 突围”作为持续展开的战斗场景。

叙事依据：[《史记》卷七十三·白起王翦列传](https://zh.wikisource.org/wiki/史記/卷073)；丹水及周边山地构图参考：[香港教育局《长平之战》教学资料](https://www.edb.gov.hk/attachment/sc/curriculum-development/kla/pshe/references-and-resources/chinese-history/war1_sc.pdf)。营垒、道路和单位位置为长卷构图服务。

## 操作

| 操作 | 功能 |
| --- | --- |
| 拖动 / 单指拖动 | 移动画卷；会停止自动漫游 |
| 滚轮 / 双指缩放 | 1–3 倍缩放，查看线描细节 |
| 空格 / 暂停按钮 | 暂停、继续 |
| 漫游 | 镜头缓慢往返 |
| 调卷 | 调整兵力（130/230/340，另有两名鼓手）、时速、血迹和画质 |
| H / 净览 | 隐藏或显示题签与控件；移到屏幕右下角可重新显示工具栏 |
| F / 全屏 | 浏览器全屏 |
| Esc | 退出净览、关闭设置；全屏由浏览器处理 |
| 还原视角 | 回到初始视角 |
| 重新布阵 | 重置战场 |

横屏适合观察全景。竖屏默认展示中央交战区域，可向两侧拖动查看营地。画质控制像素倍率；节能模式适合长时间作为壁纸使用。页面切到后台时停止推进模拟。

## 用作桌面动态壁纸

在支持本地网页的动态壁纸软件中导入 `wallpaper.html`，开启“净览”即可。浏览器打开只负责预览；本文件不会更改 Windows 桌面设置，也不输出视频。

## 验证

运行 `node verify-battlefield.cjs`：对横屏、竖屏、超宽屏的三种兵力各模拟五分钟，检查数值与单位数量、各兵种、持续伤亡与补员、多处交锋、遗留物上限、血迹开关及镜头缩放拖动。
