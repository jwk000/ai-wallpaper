# 侵蚀纪 · 山的一万年

一张正在被雨改写的山。画面不画写实光影，只用等高线、细排线、河流和冲积扇说话，像一页十九世纪的地质调查图：`512 × 288` 的高度场被刻成三十六级等高线，主峰落在画面 `(0.40w, 0.40h)`，一条河从右上流向左下，冲积扇在左下角慢慢摊开。雨落下时沟谷加深、扇面变大；六分钟后地壳抬升，山又长回去。

整个画面是单文件 HTML + Canvas 2D 程序化生成的，没有图片、视频、字体、音频或网络请求。

## 打开与操作

直接打开本目录的 `wallpaper.html`，或在流光壁纸的本机壁纸库中找到「侵蚀纪」并预览、应用。`preview.png` 是实际渲染截图（1920×1080，HUD 关闭）。

- 按住拖动：在指针附近抬升一块地形，等高线会立刻向外扩张；一次拖动最多抬升约 0.45 个高度单位。
- 单击画面：立刻开始下一场雨（持续 10–14 秒）；自动模式下每 40–86 秒本来就有一场。
- 滚轮：在 1.0–1.35 倍之间缩放看等高线细节；面板里的「回到全图」复位。
- `Space`：暂停 / 继续。
- `H`：隐藏 / 显示界面；开场文字约 16 秒后自动淡出。
- `F`：进入 / 退出全屏；浏览器也可按 `Esc` 退出。
- `R`：重置地形，回到第二轮之前的状态。
- 右下角「制图设置」：暂停、全屏、自动降雨、指针抬升、回到全图、重置地形、换一张图幅。
- 系统启用「减少动态效果」时默认静止；按 `Space` 或把地址改成 `?still=0` 可手动播放。

桌面宿主收不到鼠标时，自动降雨、十分钟循环、河流流量和镜头呼吸照常运行，画面依然完整。

## 制图规则

- **相机**：25° 斜俯视的正交制图台，只把南北方向按 `cos 25° = 0.906` 压缩，不旋转、不俯仰；每 5 分钟做一次 ±2% 的极缓推拉（缩放落在 1.00–1.04）。
- **高度场**：`512 × 288`（147,456 格）。主山体由扭曲的 ridged fbm、主峰锥、两处肩峰和北侧远山叠加，再做两遍 3×3 平滑；随后刻出五条设计河道、压平左下冲积平原，归一化到 `0.025–0.965`。
- **等高线**：36 级，每 5 级一条加粗的计曲线；marching squares 在屏幕空间的图块内运行，每条等高线用一笔半透明「墨晕」加一笔实线画出。主峰坡面上的线距约 7–12px，接近条目要求的 8px；平坦处自然变疏。
- **排线**：坡度超过 0.60 的地方按约 10px 的屏幕间距撒短排线，方向沿最陡下降方向，坡度越大越密越深；另有手绘网点补在缓坡上。河流经过的格子会跳过排线。
- **水文**：`256 × 144` 的粗网格上做 D8 汇流，桶排序后按高程从高到低累积；除五条设计河道外，再取最多四条 D8 支流。每 10 秒重新累积一次流量，河宽随流量在 0.5–3.4px 之间变化。河流用纸色描边切断等高线，再叠青灰 `#4a6a72` 与更深的中心线；暴雨时加一段沿河下行的虚线。
- **冲积扇**：扇心在 `(0.180, 0.878)` 的河口，半径随侵蚀进度从 0.135 长到 0.32（世界单位）；边界带轻微起伏，内部有九条会分叉的辫状水道、断续同心弧、约 300 个沙点，以及一条斜排的 `Cône de déjection` 标注。
- **雨与侵蚀**：侵蚀期（0–360s）雨强约 0.30，抬升期降到 0.09，稳定期 0.19；每轮另有 7–15 场 7–16 秒的阵雨，雨强峰值 0.24–0.80。画面上最多 320 条雨丝、24 个落点涟漪；雨丝数量按视口面积缩放，竖屏不会比横屏更密。
- **循环**：侵蚀 6 分钟 → 抬升 1 分钟 → 稳定 3 分钟，共 10 分钟。每轮结束把「抬升 - 侵蚀」写回高度场，再换一个抬升种子；均值向初始值回拉 50%，峰顶被限制在 0.955 以下，所以山不会消失也不会长到框外。
- **不重置**：河网、冲积扇、雨序与镜头都是连续状态；同一 `seed` 与 `t` 两次加载得到同一帧。

## URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题、读数和设置按钮，适合纯壁纸或截图；按 H 可恢复。图例属于纸面图层，不会隐藏 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 图幅种子；固定后复现地形、水系、雨序与冲积扇 |
| `t=294` | 起始时间，单位秒，范围 0–3600；同一 `seed` 与 `t` 渲染同一帧 |
| `rain=0` | 关闭降雨（侵蚀仍按十分钟循环推进，只是不画雨） |
| `uplift=0` | 关闭指针抬升 |
| `detail=0.6` | 降低雨丝、排线和网点密度（0.45–1），用于低配设备 |

静态海报：`wallpaper.html?still=1&seed=20261110&t=294&hud=0`

纯壁纸：`wallpaper.html?hud=0`

固定种子的纯壁纸：`wallpaper.html?seed=20261110&hud=0&rain=0`

## 运行预算

- 单文件 HTML + Canvas 2D + 原生 JS；无外部素材、字体、音频、网络请求。
- 主画布像素 ≤ 260 万；`devicePixelRatio` 上限 1.5，超出按面积回退。1920×1080 时实际倍率约 1.12。
- 高度场 `512 × 288`；等高线 36 级；屏幕图块 16 × 9 = 144 块，每帧最多重绘 10 块（4K 等高倍率时降到 6 块）；整图重烘焙只在启动、尺寸变化和缩放窗口切换时发生。
- 河流 ≤ 14 条、每条 ≤ 220 点（实际约 9 条、340 点）；雨丝 ≤ 320；涟漪 24；冲积扇沙点 ≤ 300；测高点 5 个。
- 侵蚀纹理在每轮开始时用 2,400 条雨滴路径预计算，运行期只按量化进度（3 秒一档）播放；河流流量每 10 秒累积一次。
- 目标 30 FPS；离屏 Electron（禁用 GPU）1280×800 实测约 31–32 FPS，4K 约 30 FPS；四种尺寸的离屏截图与交互验证均通过。
- 页面隐藏时取消 `requestAnimationFrame`；恢复时重置时间戳。暂停、减少动态效果与窗口缩放时仍正确重绘。
- 所有随机数来自种子化 PRNG；侵蚀、抬升、水系的每轮结果只由 `seed + cycleIndex` 决定，显示高度只由种子与 `t` 决定。

## 验证

在仓库根目录运行：

```powershell
node scripts/verify-erosion-chronicle.cjs
```

生成或更新实际预览图：

```powershell
node scripts/verify-erosion-chronicle.cjs --write-preview
```

脚本先在 Node 的 `vm` 中模拟横屏、竖屏、超宽屏和 4K 各 10 分钟，检查高度场与侵蚀纹理有限、主峰位置、等高线与图块预算、水系长度、雨量、冲积扇生长、十分钟换轮、抬升、`seed/t` 复现、暂停、隐藏页调度、缩放与像素预算。随后用 Electron 离屏窗口加载真实 `file://` 页面，检查四种尺寸的实际渲染、亮度与纸/墨比例、动画推进、拖动抬升、点击降雨、Space 暂停、暂停时缩放、面板与开关、减少动态效果、无网络请求、无控制台错误，以及 `scanWallpapers` 识别。截图写入系统临时目录 `lumen-erosion-chronicle-check/`。

这些检查不等同于 Windows 原生 WebView2 桌面挂载测试；桌面宿主是否接收鼠标取决于系统与引擎版本，因此自动降雨与自动抬升是必要的保底。

设计文档见 [`docs/design/erosion-chronicle.md`](../../docs/design/erosion-chronicle.md)。
