## 1. 一句话概念

一座摆在米色纸面上的等距小镇模型：电车沿着闭环街道一圈圈绕行，水渠里的水一级级往高处流，广场中央的阶梯首尾相接、永远走不到头；每隔一会儿，一栋建筑原地转身九十度，街道和轨道便悄悄改道。

它不是解谜游戏，也不需要用户理解规则。它首先是一张**可以长时间凝视的埃舍尔铜版画**，其次才是一个会动的模型。

### 设计原则

1. **先成立一张画。** 静止帧必须有完整的构图、层次与明暗；转动、流水、电车是第二层的惊喜。
2. **悖论要具体。** 不用抽象发光粒子表示「不可能」，而是用四条能指认的规则：首尾相接的阶梯、往高处流的水、闭环的电车、会转身的街区。
3. **一套透视。** 全镇使用 2:1 等距正交投影；悖论只发生在「遮挡关系」和「连接处」，不靠混乱的透视糊弄。
4. **安静、可离线、可复现。** 单 HTML、Canvas 2D、无外部素材；同一 `seed` 与 `t` 画出同一帧。
5. **桌面优先。** 没有鼠标也完整运转；所有交互都有自动替代行为。

- **模型台**：小镇坐在一块浅色薄板上，板下有 12% 冷灰投影与一道窄石缘；纸面与网格不随镜头晃动，只有模型台轻微摆动。

### 2.2 相机

- 2:1 等距正交，方位角固定 45°，无透视、无俯仰变化。
- 模型台以 120 秒为周期做 ±0.55° 的极缓自转，叠加 60 秒周期 ±5px 的上下浮动与 ±1% 的呼吸式推拉；任何时刻截屏都成立。
- 拖动可平移，限制在 ±1 格内；滚轮缩放 0.8–1.2×，松手后回到缓慢呼吸，不保留自由环绕。
- 不做景深；所有建筑与人物保持同一清晰度，像一张印刷品。

### 2.3 美术

- **埃舍尔铜版画 + 构成主义海报**：平涂色块、细密排线阴影、深墨勾边；纸面叠加极淡的 risograph 网点与套色偏移感。
- 建筑边缘用 1–1.4px 深墨线，转角处再压一条更细的亮线；不用渐变、不用高光贴图、不用辉光滤镜。
- 阴影只有一层：12% 冷灰，统一从左上打向右下；阴影形状必须与建筑轮廓一致，保证「不可能」只在连接处，不在光照上。
- 屋顶、檐口、窗、拱门、烟囱、水塔、天线、晾衣绳、藤蔓都用几何图形绘制；远处看是节奏，近看有细节。
- 纹样只使用三种：斜排线（阴影面）、点阵（纸面）、等距网格（街道与蓝图）。

### 2.4 层次

1. **纸面层（不随相机移动）**：米色纸、极淡蓝图网格、四角远山灰影、装订/折痕痕迹、标题文字。
2. **模型台层**：薄板侧缘、板下投影、铺地、道路、水渠、轨道、建筑阴影、喷泉池。
3. **中景主体**：约 40 栋建筑、钟塔、市场、温室、水磨、桥、彭罗斯阶梯、喷泉。
4. **动态层**：两列电车、十二个行人、阶梯上的攀登者、水渠流线、水车、喷泉、旗帜、鸽子。
5. **前景层**：左下角被裁切的屋檐、瓦片、藤蔓与一只猫，压住约 15% 画面；右上一小段垂下的枝条。

### 2.5 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 纸面 | `#e9e0cc` | 主底色，略暖 |
| 纸面暗部 | `#ded2ba` | 模型台侧缘、远山 |
| 墨线 | `#2b2a26` | 所有轮廓与文字 |
| 砖红 | `#b4553c` | 屋顶、电车、主要强调，约 25% |
| 青灰 | `#5f7f86` | 水、玻璃、阴影面，约 15% |
| 黄铜 | `#c9a15b` | 窗光、轨道、装饰，约 15% |
| 米粉 | `#f2ead8` | 受光面、纸面高光 |
| 库内强调色 | `#b4553c` | 与砖红一致 |

- 比例约 纸 60 / 砖红 25 / 青灰 15；黄铜只做点状提亮，不铺大面积。
- 阴影统一 `rgba(70,84,92,0.12)`；不使用第二种阴影色。
- **晨昏循环**：以 10 分钟为周期，在「清晨」（纸面偏冷、阴影偏青）与「黄昏」（纸面偏琥珀、窗光更暖）之间连续往返；通过全屏薄色层与窗光亮度实现，不做硬切。

## 3. 四条不可能规则

> 实现回填：最终主景是彭罗斯三角 + 基座螺旋阶梯，不再环塔；水梯位于西侧运河，不再注入喷泉。详见第 13 节。

### 3.1 彭罗斯阶梯

- 广场中央的塔楼外包一圈四段阶梯，每段 6 级，四段首尾相接；行人沿顺时针方向不断向上走，却回到同一高度。
- 画法：四段阶梯各自沿菱形的一边上升，在四个转角用**比阶梯更高的转角墩**遮住高度差；近端转角墩压在最后一段的顶端与第一段的底端之间，让眼睛自动把两段接起来。
- 阶梯外侧有连续的女儿墙，内侧是塔身；攀登者走到转角时被墩子挡住 0.4 秒，再从下一段的低处出现。这是唯一允许的「瞬移」，且必须被遮挡。
- 塔顶有一只黄铜球与风向旗，作为全镇的视觉制高点。

### 3.2 往高处流的水

- 一条闭合水渠环绕广场，水面低于街面 0.15 格；在西侧接一组四级「水梯」，每级比前一级高 0.18 格，最后注入比渠面高 0.7 格的喷泉池。
- 水面流线（短横线 + 人字纹）沿水渠顺时针移动；到了水梯，流线一级级**向上**爬，并在每级边缘翻出白色小水花。水车被这股向上的水流带动，转向与水流一致。
- 不解释动力来源；在最高一级的拱洞里塞一块刻着 `AQUA ADVERSA` 的黄铜小牌，作为唯一文字彩蛋。
- 水梯与喷泉之间的落差用两孔石拱遮挡，水流在拱后「消失」，再从喷泉口出现。

### 3.3 闭环的电车

- 两列电车沿广场外环的闭合轨道运行，一圈 90 秒；在车站各停 4 秒。
- 轨道在广场后方从彭罗斯阶梯背后穿过，车头先被塔身遮住，再从另一侧出现；从任何视角看都像一条首尾相接的环。
- 轨道本身画在铺地上，不抬高；电车用屏幕空间的车身沿切线旋转，车轮藏在车底阴影里。
- 车顶弓形受电杆、黄铜车灯、车窗里的乘客剪影与路线牌 `7` 是唯一会动的「机械细节」。

### 3.4 会转身的街区

- 约 40 栋建筑中，除地标外都可以点击；建筑绕自身竖轴旋转 90°（0.6 秒，带 8% 弹性回弹），在转到侧面时宽度压到 0，再以新的长宽比重建轮廓。
- 每次转身后，轨道与步行路线重新采样：靠近该建筑的路点横向偏移 ±0.35 格，电车与行人以 1.2 秒的缓动滑到新路线。路线不是瞬移，而是像被建筑「挤」开的墨线。
- 自动模式每 45–90 秒随机挑一栋建筑转身；地标（钟塔、教堂、水磨、温室）不参与自动转身，避免构图散架。

## 4. 小镇蓝图

- 世界网格 22×22 格，原点在左上（屏幕后方），广场中心 `(11, 11)`。
- 外环 16 个街区，每块 3–4 格见方，街区之间留 1–2 格街道；广场半径 5.2 格，外圈是水渠，内圈是电车轨道，中心是阶梯塔与喷泉。
- 建筑总数 40（含 8 栋地标/边缘小屋）：
  - 北侧：大教堂（穹顶 + 玫瑰窗）、钟塔（拱门 + 尖顶）、图书馆；
  - 西侧：市场大厅（条纹雨棚 + 锯齿屋顶）、面包房、排屋；
  - 东侧：天文台（黄铜浑仪）、印刷所、温室；
  - 南侧：水磨（水车）、车站雨棚、仓库；
  - 外圈：低矮排屋、作坊、鸽舍、屋顶花园。
- 每栋建筑由 `footprint(w,d) + height + style + roof + features` 描述；`seed` 只改变高度、窗光、屋顶物件与色彩微差，不改变地标位置。
- 街道：外环石板路、四条放射路、广场铺地；水渠上的四座石桥在放射路与渠相交处。
- 前景屋檐固定在左下角，不参与世界投影；竖屏时改为底部横向屋檐。

## 5. 动态元素与循环

| 元素 | 数量 | 周期 | 说明 |
| --- | --- | --- | --- |
| 电车 | 2 列 × 2 节 | 90 秒/圈 | 车站停 4 秒，两列相位差 45 秒 |
| 行人 | 12 | 40–110 秒/圈 | 5 条步行线，转身事件后重新选线 |
| 阶梯攀登者 | 4 | 36 秒/圈 | 转角处被墩子遮挡；不累积高度 |
| 水渠流线 | 26 组 | 6 秒 | 顺时针，向上爬水梯 |
| 喷泉粒子 | 72 | 6 秒 | 抛物线珠链，落回池面 |
| 水车 | 1 | 6 秒/转 | 与水流同向 |
| 旗帜 / 晾衣绳 | 6 / 3 | 8–14 秒 | 轻摆，不抢主体 |
| 鸽子 | 3 | 18–30 秒 | 偶尔从塔顶掠过 |
| 建筑转身 | 1 次/45–90 秒 | 0.6 秒 | 自动模式 |

- 晨昏色温 10 分钟一轮；小镇本身不做整体重置。
- 所有动态都由 `clock` 解析式驱动，暂停即停在当前帧；打开页面时按 `t` 直接落到正确相位。

## 6. 交互

| 操作 | 行为 | 自动替代 |
| --- | --- | --- |
| 点击建筑 | 该建筑转身 90°，路线重排 | 每 45–90 秒自动转身 |
| 拖动 | 平移模型台，限 ±1 格 | 120 秒周期的 ±0.55° 自转 |
| 滚轮 | 缩放 0.8–1.2× | ±1% 呼吸推拉 |
| `Space` | 暂停 / 继续 | — |
| `H` | 隐藏 HUD | 标题 14 秒后自动淡出 |
| `F` | 全屏 | — |
| 设置面板 | 自动转身开关、暂停、全屏 | 默认开启自动转身 |

- 建筑命中测试用屏幕包围盒 + 顶面多边形，不要求像素级精确；点击空白处不产生反馈。
- 拖动超过 4px 才视为平移，避免与点击冲突；点击后短暂高亮该建筑的墨线 0.4 秒。
- 触屏同样支持拖动与点按。

## 7. URL 参数

| 参数 | 含义 |
| --- | --- |
| `hud=0` | 隐藏标题与设置按钮，适合纯壁纸/截图 |
| `still=1` / `still=0` | 强制静止 / 强制播放，覆盖系统减少动态效果设置 |
| `seed=20261110` | 小镇种子；固定后可复现细节 |
| `t=113` | 初始时间，单位秒；默认 113，范围 0–86400 |
| `auto=0` | 关闭自动转身 |
| `zoom=1` | 初始缩放 0.8–1.2，仍可滚轮调整 |
| `paused=1` | 以暂停状态打开（等同于 still） |

静态海报：`wallpaper.html?still=1&t=113&hud=0`。

纯壁纸：`wallpaper.html?hud=0`。

## 8. 性能预算

- 单 Canvas，2D context；画布渲染像素上限 260 万，DPR 上限 1.5，按视口面积反算。
- 30 FPS 节流；页面隐藏时取消 `requestAnimationFrame`，恢复时重置时钟。
- 建筑按 `id + 朝向 + 缩放档` 缓存到独立离屏画布；转身时只重烘一栋。
- 纸面、铺地、水渠、轨道、建筑阴影烘焙到两张离屏画布（纸面层 + 模型台层），缩放/尺寸变化后重烘。
- 每帧只画：1 张纸面、1 张模型台、≤ 45 张建筑精灵、≤ 30 个动态对象、1 层纸纹/暗角。
- 动态对象上限：建筑 48、电车 4 节、行人 12、攀登者 4、水粒子 72、鸽子 3、水车 1。
- 任何累积效果都不保留历史：水面、喷泉、旗帜全部由当前相位解析计算，不叠帧。

## 9. 可访问性

- `<canvas role="img" aria-label="…">` 描述画面：等距小镇、环形电车、向上流的水渠、首尾相接的阶梯。
- 设置按钮有 `aria-expanded` / `aria-controls`；自动转身是原生 checkbox；焦点有 2px 黄铜色描边。
- 键盘可暂停、隐藏 HUD、全屏；点击建筑也可用键盘聚焦后按回车切换（提供「选中的建筑」提示）。
- 减少动态效果时默认静止，并可手动继续；静止时仍响应缩放与窗口尺寸变化。
- 颜色不是唯一信息：水梯有阶梯轮廓与刻字，路线有轨道与车灯，不依赖色相区分。

## 11. 实现结构

```text
wallpapers/impossible-town/
├─ wallpaper.html      单文件实现（HTML + CSS + Canvas 2D）
├─ meta.json           标题、副题、描述、标签、强调色、排序
├─ preview.png         Electron 实际渲染截图（1920×1080，HUD 关闭）
└─ README.md           操作、悖论说明、URL 参数、验证说明

docs/design/impossible-town.md   本设计文档
scripts/verify-impossible.cjs    Node 模拟 + Electron 实渲染验证、预览图生成
```

代码分区（同一 `<script>` 内）：

1. 参数、种子、工具函数、调色板；
2. 世界蓝图（建筑、街道、水渠、轨道、路线）；

## 13. 实现差异与验收结果

状态：实现完成 · 2026-11-11。

### 13.1 与设计稿的差异

1. **主景**：中央从「环塔的彭罗斯阶梯」改成「彭罗斯三角 + 环绕基座的螺旋阶梯」。三角是远景第一眼能读出的不可能符号；基座保留四段上升阶梯、铜栏杆与四名攀登者，接缝藏在北角矮塔后。原设计中的高塔与四个角楼在实现中反复试错后取消，因为它们会遮住阶梯，且让画面读成城堡。
2. **水梯**：从「通往喷泉」改为西侧运河上的四级水梯，流向与运河顺时针一致，最高一级没入桥洞；不再与喷泉池相连。喷泉仍在三角基座外圈。
3. **电车**：改为真正的 3D 等距箱体（沿轨道切线取世界坐标，再投影），不再用屏幕空间旋转，过弯时不会倾倒。
4. **数量**：36 栋主建筑 + 1 座车站（共 37 栋）+ 超宽屏 6 栋纸面卫星屋；地标 6 座。原稿的 40 栋目标以主建筑 + 卫星屋计。
5. **水车**：取消。水渠的「向上流」由水梯流线承担；水车在试作中像摩天轮，删除后画面更干净。
6. **树与家具**：广场外圈补了 8 棵树，作为尺度参照；没有添加长椅/路灯，避免小尺寸下变成噪点。
7. **交互命中**：按最前面的建筑判定，不用精灵包围盒兜底；钟塔、天文台、市政厅三处地标单独验证。
8. **自动转身**：地标和车站不参与自动轮转；其余建筑按 seed 生成 45–90 秒的确定性事件序列。
9. **相机**：实现为 120 秒 ±0.55° 自转、60 秒 ±4.5px 浮动、180 秒 ±0.8% 呼吸；拖动限制 ±1.05 格，滚轮 0.8–1.2×。
10. **配色**：纸 `#e7ddc6`、墨 `#24231f`、砖 `#a94b35`、青灰 `#4f747b`、黄铜 `#bc8f45`；比原稿略深，以抵消纸面浅色带来的发灰。
11. **彭罗斯三角**：几何比例参考公开的 `Penrose-dreieck.svg` 示意图，在 Canvas 中按本作配色重绘，不加载外部文件。
